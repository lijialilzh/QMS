# 用户操作说明书（六）测试管理、图表文件、追溯总览与对比

> 适用范围：测试、配置、追溯核对人员。

---

## 1. 测试集与测试用例（菜单：测试管理 → 测试集，`test_set/TestSets.tsx`）

### 1.1 适用范围
按「产品 + 测试阶段」组织测试集，通过 Excel 导入用例。阶段：单元测试、集成测试、系统测试、用户测试。

### 1.2 筛选
- 产品（完整版本）+ 阶段（可清空）→ 搜索。

### 1.3 列与操作
- 列：产品名称、完整版本、阶段、创建时间、操作。

| 操作 | 说明 |
|------|------|
| 新建 | 弹窗：选产品、阶段、上传 Excel |
| 编辑 | 可改产品、阶段、重传 Excel |
| 删除 | 标准确认；级联删该集所有用例 |
| 查看测试用例 | 宽弹窗（标题=阶段名），只读用例表 |
| 导出测试用例 | 导出 Excel（行 loading） |

### 1.4 新建 / 编辑字段
| 字段 | 必填 | 说明 |
|------|------|------|
| 产品 | 是 | |
| 阶段 | 是 | 同产品+阶段唯一 |
| Excel 文件 | 新建通常需上传 | `.xlsx`，用于导入用例 |

### 1.5 导入测试用例（Excel 操作步骤）
测试用例不支持逐条手工录入，统一通过 Excel 批量导入：
1. 在测试集列表点「新建」（或对已有测试集点行内「编辑」），打开弹窗。
2. 选择产品，选择测试阶段（单元测试 / 集成测试 / 系统测试 / 用户测试）。
3. 在「Excel 文件」处上传用例文件（仅 .xlsx）。
4. 点「确定」提交，系统按 Excel 内容导入用例。
   - 对已有测试集“编辑”并重新上传文件时：会先清空该测试集原有用例，再按新文件导入（非增量合并）。
5. 导入完成后，在该测试集行点「查看测试用例」即可查看导入结果（只读用例表）。

导入对 Excel 的要求：
- 首行为表头，需包含用例编号、需求编号、测试类型等列（系统扫描前 30 行识别表头）。
- 用例编号需以字母或数字开头、且包含“-”，长度不超过 64；不符合规则的行不会被导入。

### 1.6 测试用例（只读，`TestCases.tsx`）
- 在测试集弹窗内展示，**无单条编辑入口**（维护走 Excel 导入）。
- 列：用例编号、SRS 编号、测试类型、阶段、功能、描述、前置条件、测试步骤、预期结果、备注。

### 1.7 边界测试
| 场景 | 预期 |
|------|------|
| 同产品同阶段再建 | 「数据已存在」 |
| 用例编号不含 `-` 或不合规则 | 该行不被导入 |
| 编辑时重传 Excel | 旧用例被清空后重新导入 |
| 用例编号全局重复 | 后端按全局唯一校验 |
| 删除测试集 | 用例一并删除 |

## 2. 图表文件（菜单：文件管理）

同一页面（`doc_file/DocFiles.tsx`），三类按菜单区分：

| 类型 | 菜单 | 文档版本来源 |
|------|------|--------------|
| 物理拓扑图(img_topo) | 物理拓扑图 | SRS 版本 |
| 体系结构图(img_struct) | 体系结构图 | SRS 版本 |
| 网络安全流程图(img_flow) | 网络安全流程图 | **SDS** 版本 |

### 2.1 上传图表（物理拓扑图 / 体系结构图 / 网络安全流程图）
物理拓扑图、体系结构图、网络安全流程图三类图表的上传操作完全相同，分别从「文件管理」下对应的菜单进入：
1. 选择产品。
2. 选择文档版本（网络安全流程图选“详细设计文档版本”，物理拓扑图与体系结构图选“需求规格说明文档版本”；未选会有相应占位提示）。
3. 点「新建」，在弹窗中选择产品并上传图片文件（仅 .png / .jpg / .jpeg，单个文件）。
4. 点「确定」上传：成功后列表新增一行图表记录，文件名显示为“产品名_图类型.扩展名”，并展示文件大小、创建时间等。
5. 已上传的图表行可进行：编辑（重新上传替换）、下载、删除；勾选多行后可批量删除（未勾选时批量删除按钮不可用）。

### 2.2 列
产品名称、型号、完整版本、文档版本、文件名（展示为「产品名_图类型.扩展名」）、文件大小、创建时间、编辑/删除/下载。

### 2.3 新建 / 编辑字段
| 字段 | 必填 | 说明 |
|------|------|------|
| 产品 | 是 | |
| 图片 | 是 | `.png/.jpg/.jpeg`，单文件 |

### 2.4 联动说明
- 列表会从文档节点自动回填图片（拓扑/结构取 SRS 章节 2.2/2.3，流程图取 SDS 节点）。
- 上传/更新后会反向写回文档节点的图片地址。
- 「无图节点不覆盖已手工上传的图」。

### 2.5 下载
点「下载」在新窗口打开文件。

### 2.6 边界测试
| 场景 | 预期 |
|------|------|
| 上传非图片 | 不允许选择 |
| 未选产品 | 列表显示全部产品图（图表列表不强制按产品过滤） |
| 删除引用图表的产品 | 产品删除被阻止 |

## 3. 产品追溯总览（菜单：产品追溯总览 → 追溯总览，`overview/ProdTraces.tsx`）

### 3.1 产品追溯总览操作步骤
1. 进入「产品追溯总览 → 追溯总览」。
2. 在搜索框输入产品名称进行模糊搜索，回车或点搜索按钮。
3. 表格按产品展示：产品名称、型号、完整版本、版本追溯（该产品的 SRS + SDS 版本组合）、追溯文档（SRS / SDS 版本列表）、操作。
4. 点某产品行的「导出」，导出该产品的完整追溯 Excel（含需求、设计、风险、测试的追溯关系）。

### 3.2 适用范围
用于快速核对某个产品的 SRS / SDS 版本配对与追溯覆盖情况。

## 4. 产品对比（菜单：产品追溯总览 → 文档对比，`overview/ProdComparison.tsx`）

### 4.1 步骤
1. 选**文档类型**：需求规格说明（SRS）/ 软件详细设计（SDS）。切换会清空左右选择与结果。
2. 左侧：产品 A + 文档版本（选产品后加载去重版本）。
3. 右侧：产品 B + 文档版本。
4. 点「开始对比」。

### 4.2 结果
表格列：对比项名称、产品 A 值、产品 B 值、对比状态（相同 / 不同）。
- 对比项含产品名/型号/版本/UDI/适用范围、SRS（或 SDS）版本、功能增删。
- **功能增删按需求编号集合差集判断**，改名不计为增删。

### 4.3 边界测试
| 场景 | 预期 |
|------|------|
| 未选齐 | 「请选择…（select_both）」 |
| 左右选同一文档 | 「请选择不同的文档（select_different）」 |
| 无差异 | 全部显示「相同」 |
| 无数据 | 结果区显示「-」 |

## 5. 追溯链说明（核对依据）

完整追溯链：
```
产品 → SRS 文档 → SRS 需求(编号) ─┬─→ SDS 追溯 / SDS 设计条目 → SDS 文档
                                  ├─→ RCM(风险控制) → 产品 RCM
                                  └─→ 测试用例(srs_code 字符串关联)
```
- 测试用例通过 `srs_code` **字符串**关联需求，不是数据库外键。
- 产品 RCM 的 SRS / 测试追溯由系统按编号规则自动计算并展示。

### 5.1 端到端核对建议
1. 在「SRS 文档追溯」查看每条需求是否有对应 SDS、RCM、各阶段测试。
2. 在「产品 RCM」确认控制措施是否关联到 SRS 与测试证据。
3. 在「追溯总览」导出 Excel 留档。
4. 版本升级时用「文档对比」核对功能增删。
