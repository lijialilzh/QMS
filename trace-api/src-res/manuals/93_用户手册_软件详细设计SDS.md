# 用户操作说明书（四）软件详细设计（SDS）

> 适用范围：编写 / 维护软件详细设计的人员（`sds_doc_view` / `sds_doc_edit`）。前置：该产品已有 SRS 文档（SDS 须绑定 SRS 版本）。

---

## 1. SDS 文档列表（菜单：创建管理 → SDS 文档，`/sds_docs`）

### 1.1 筛选
选择产品 + 文档版本（选产品后加载该产品 SDS 版本）→ 搜索。

### 1.2 新建 SDS 文档与工具栏
- **导入**：打开「导入 Word 详细设计」弹窗（见第 2 节）。
- **新建 SDS 文档**：点「新建」进入新建页，操作主线如下：
  1. 在 SDS 文档列表页点「新建」，进入新建页。
  2. 选择产品、选择要关联的 SRS 需求文档版本，填写本次 SDS 版本号。
  3. 点「初始化模版」加载标准目录结构。
  4. 在目录树中编辑各章节的标题、正文，维护设计条目、追溯等内容。
  5. 点顶栏「保存」保存整个文档；新建保存成功后会进入该文档的编辑页。

### 1.3 表格列
产品名称、产品版本、关联 SRS 版本、SDS 版本、文件编号、变更说明、创建时间、操作。

### 1.4 行内操作
| 操作 | 行为 |
|------|------|
| 查看 | `/sds_docs/view/{id}` 只读 |
| 编辑 | `/sds_docs/edit/{id}` |
| 复制 | 确认框 → 「复制成功」 |
| 导出 | 行级 loading，失败提示 |
| 删除 | 标准删除确认 |

### 1.5 文件编号行内编辑
单击单元格输入，失焦/回车保存（保存中禁用），成功「文件编号已保存」。

---

## 2. 导入 Word 详细设计

### 2.1 导入 Word 详细设计操作步骤
1. 点「导入」。
2. 填写：

| 字段 | 必填 | 说明 |
|------|------|------|
| 产品 | 是 | 变更后重载「关联需求文档」列表 |
| 关联需求文档(SRS) | 是 | 无 SRS 列表时禁用 |
| SDS 版本 | 是 | 文本 |
| 变更说明 | 否 | 多行 |
| 导入前清空该产品历史详细设计 | 否 | 勾选则先删该产品全部 SDS 再导入 |
| Word 文件 | 是 | 仅 `.docx`，单文件 |

3. 确定上传。

### 2.2 结果
- 成功：关闭弹窗、刷新列表。
- 失败：「导入失败」（`res.msg` 或「Word导入失败，请检查文档格式后重试」/「导入请求异常，请稍后重试」）。

### 2.3 边界测试
| 场景 | 预期 |
|------|------|
| 未选关联 SRS | 下拉禁用，无法提交 |
| 指定 SRS 找不到匹配版本 | 「导入失败：未找到匹配的需求文档版本，请重新选择」 |
| 产品下无 SRS | 「导入失败：当前产品下未找到需求规格说明，请先导入需求规格说明」 |
| 未选文件 | 「请选择文件」 |
| 同 SRS 版本下 SDS 版本重复 | 「数据已存在」 |

---

## 3. SDS 文档详情页

### 3.1 顶栏（非只读）
| 按钮 | 条件/行为 |
|------|-----------|
| 返回 | 回 `/sds_docs` |
| 导出 | 未保存（新建未存）时**禁用**，提示「请先保存文档」 |
| 初始化模版 | 新建加载标准目录；编辑恢复进入页时的树 |
| 保存 | 保存整文档（树+元数据） |

### 3.2 基础信息
- 已绑定 SRS：展示产品、需求文档（只读）+ 当前版本可改。
- 需重绑 SRS：产品、需求文档、版本**均必填**；SRS 下拉无数据时禁用。
- 未绑定 SRS 会警告「该详细设计未绑定需求规格说明版本，请先绑定…」。
- 保存校验：版本必填、产品必填、需求文档必填。

### 3.3 版本变更说明
点「编辑变更说明」→ 弹窗多行输入 → 确定保存。

### 3.4 目录结构（树）
顶栏（编辑态）：
- **获取SRS追溯**：全页同步（Spin「正在同步 SRS 追溯与章节…」），成功「已从SRS获取追溯数据」。
- **添加根菜单**：追加空根节点。

树节点操作（编辑态）：
| 操作 | 说明 |
|------|------|
| 展开/折叠 | 左侧箭头 |
| 标题 | 输入框 |
| SDS 编码 | 含 sds_code 字段的节点显示输入框 |
| 正文 | 多行（图片引用类节点除外） |
| 上传图片 | 1–2 级节点，`image/*`，有图显示「重新上传」 |
| 设计列表 | `sds_reqds` 节点 → 只读弹窗 |
| 获取SRS追溯 / 需求追溯表 | 追溯节点：未同步显示「获取SRS追溯」，已同步显示「需求追溯表」 |
| 前/后添加同级 | `+` 图标 |
| 添加下级菜单 | 仅 level<2 |
| 表格 / 导入表格 | 非图片/设计/追溯节点；表格支持 `.xlsx/.xls/.csv` |
| 删除 | 标准确认 |

- 图片引用节点（拓扑/结构/流程图）：只展示图，来自图表文件管理映射。

## 4. 设计条目（设计列表）

### 4.1 两种入口
- **详情页树内**：`sds_reqds` 节点点「设计列表」打开**只读**弹窗。
- **独立页 `SdsReqds.tsx`**（设计条目）：可编辑。

### 4.2 独立页操作
- 筛选：产品 + SDS 文档版本（须同时选定且有 doc_id 才有数据）。
- 列：SRS 编号、需求名称、概述、功能、逻辑图、输入、输出、接口、产品、SDS 版本、操作（编辑）。
- 编辑弹窗字段（均选填）：
  - 概述、功能详情、逻辑文本、输入、输出、接口。
  - **逻辑图上传**：`.png/.jpg/.jpeg` 多图；每张可填说明、可删除。
  - 已有逻辑图：说明可改、可删除（确认删除）。

### 4.3 边界测试
| 场景 | 预期 |
|------|------|
| 未选产品/版本 | 列表无数据 |
| 删除逻辑图 | 确认后移除 |
| 上传非图片 | 不允许选择 |

## 5. 需求追溯

### 5.1 详情页追溯节点
- 未同步：点「获取SRS追溯」拉取（打开「需求追溯表」前若未同步会自动拉取）。
- 已同步：点「需求追溯表」查看只读追溯（SRS编号、SDS编号、需求代码、章节号）。

### 5.2 追溯独立编辑页 `SdsTraces.tsx`
- 筛选：产品 + SDS 版本。
- 列：SRS 编号、SDS 编号、类型名称、需求代码、章节号、SDS 版本、编辑。
- 编辑弹窗：

| 字段 | 可编辑 |
|------|--------|
| SRS 编号 | 否（禁用） |
| SDS 编号 | 是（必填） |
| 需求代码、章节号 | 是 |

### 5.3 同步机制说明
- 「获取SRS追溯」会从绑定的 SRS 拉取需求并写入 SDS 追溯与章节；已有手工内容按规则合并。
- 加载失败提示「加载设计与需求追溯失败」。

### 5.4 边界测试
| 场景 | 预期 |
|------|------|
| 未绑定 SRS 点同步 | 无法同步/提示先绑定 |
| 打开追溯表但未同步 | 自动先执行同步 |
| SDS 编号留空保存 | 校验拦截 |

---

## 6. 导出与对比

- **导出 Word**：列表页「导出」或详情页「导出」（须已保存）。
- **文档对比**：产品追溯总览 → 文档对比，文档类型选「软件详细设计」，左右选不同产品/版本 → 开始对比（结果列含 SDS 版本）。

---

## 7. SDS 关键规则提醒
1. SDS 通过 `srsdoc_id` 绑定具体 SRS 版本；删除 SRS 会使绑定的 SDS 解绑。
2. 文档保存为「删除全部节点再整树重建」，编辑时务必让树加载完整后再保存。
3. 设计条目 `输入` 字段在系统内部字段名为历史拼写，不影响使用。
