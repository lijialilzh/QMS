## 模块总览：测试、图表与追溯

本模块覆盖产品研发后期的验证与核对工作，包含三块内容：**测试管理**（按产品+阶段维护测试集，并通过 Excel 导入测试用例）、**产品图示**（按产品上传物理拓扑图、体系结构图、用户界面关系图、网络安全流程图四类图表，并与 SRS/SDS 文档节点联动）、**全局视图**（核对产品的文档内容比对、整合导出与一键打印）。
它解决的核心问题是：把“产品—需求—设计—风险—测试”的全链路追溯关系核对清楚，确保每条需求都有对应的设计、图表与测试证据，并能在版本升级时快速发现功能增删。

## 1. 测试集管理（新建 / 编辑 / 删除）

- **界面位置**：菜单「开发测试文件管理 → 测试文件 → 测试集管理」。
- **用户常见问法**：怎么新建测试集、怎么建测试集、测试集怎么编辑、怎么改测试阶段、怎么删测试集、测试集在哪。
- **是做什么的**：按「产品 + 测试阶段」组织测试集，阶段分为单元测试、集成测试、系统测试、用户测试；新建/编辑测试集时可上传 Excel 导入用例。
- **解决什么问题**：把一个产品在不同测试阶段的用例分组管理，作为测试用例的归属容器，支撑后续的追溯核对。
- **怎么用**：
  1. 在列表页按「产品（完整版本）+ 阶段」筛选后搜索；列表显示产品名称、完整版本、阶段、创建时间。
  2. 点「新建」，在弹窗里选择产品、选择测试阶段、上传 Excel 用例文件（.xlsx），点「确定」提交。
  3. 编辑：点行内「编辑」，可修改产品、阶段，或重新上传 Excel 文件。
  4. 删除：点行内「删除」并确认，删除测试集时会一并删除该集下所有用例。
- **相关功能**：测试用例管理（用例归属测试集、通过 Excel 导入）、产品管理（测试集挂在产品下）、产品追溯总览。

## 2. 测试用例管理（新建 / 编辑 / 导入测试用例）

- **界面位置**：测试集列表行内「查看测试用例」打开的弹窗（只读用例表）；维护入口在测试集的新建/编辑弹窗（Excel 导入）。
- **用户常见问法**：测试用例怎么导入、怎么新建测试用例、用例怎么录入、怎么批量导入用例、怎么查看测试用例、怎么导出测试用例。
- **是做什么的**：管理归属于测试集的测试用例，记录用例编号、关联的 SRS 需求编号、测试类型、功能、描述、前置条件、测试步骤、预期结果、备注；用例统一通过测试集的 Excel 批量导入维护，不支持逐条手工录入。
- **解决什么问题**：用统一的 Excel 导入方式批量维护用例，并通过用例编号、需求编号建立与需求的追溯关联。
- **怎么用**：
  1. 导入用例：在测试集列表点「新建」（或对已有测试集点「编辑」），打开弹窗。
  2. 选择产品，选择测试阶段（单元测试 / 集成测试 / 系统测试 / 用户测试）。
  3. 在「Excel 文件」处上传用例文件（仅 .xlsx），Excel 首行为表头，需包含用例编号、需求编号、测试类型等列。
  4. 点「确定」提交，系统按 Excel 内容导入用例。
  5. 查看：在该测试集行点「查看测试用例」，在弹窗中查看导入结果（只读用例表，列含用例编号、SRS 编号、测试类型、阶段、功能、描述、前置条件、测试步骤、预期结果、备注）。
  6. 导出：在测试集行点「导出测试用例」，导出 Excel。
- **相关功能**：测试集管理（用例的归属与导入入口）、SRS 需求（用例通过 SRS 编号 / srs_code 关联需求）、产品追溯总览。

## 3. 产品图示（上传图表 / 分类）

- **界面位置**：菜单「产品管理 → 产品图示」下的四个二级菜单——「物理拓扑图」「体系结构图」「用户界面关系图」「网络安全流程图」（同一页面按菜单区分类型）。
- **用户常见问法**：怎么上传图表、拓扑图怎么传、结构图在哪上传、流程图怎么上传、图表怎么替换、怎么下载图表、怎么批量删除图表。
- **是做什么的**：按产品维护四类图表文件——物理拓扑图（img_topo）、体系结构图（img_struct）、用户界面关系图（img_ui）、网络安全流程图（img_flow），并与 SRS/SDS 文档节点双向联动。
- **解决什么问题**：把产品的拓扑、结构、UI关系、网络安全流程等图示集中管理，并自动与需求/设计文档节点的图片联动，保证图文一致。
- **怎么用**：
  1. 从「产品管理 → 产品图示」下对应的菜单进入（物理拓扑图 / 体系结构图 / 用户界面关系图 / 网络安全流程图）。
  2. 选择产品。
  3. 选择文档版本（网络安全流程图选"详细设计文档版本"即 SDS；物理拓扑图与体系结构图选"需求规格说明文档版本"即 SRS；用户界面关系图选 SRS 版本）。
  4. 点「新建」，在弹窗中选择产品并上传图片文件（仅 .png / .jpg / .jpeg，单个文件），点「确定」上传。
  5. 上传成功后列表新增一行，文件名显示为“产品名_图类型.扩展名”，并展示文件大小、创建时间等。
  6. 已上传的图表行可进行：编辑（重新上传替换）、下载（在新窗口打开文件）、删除；勾选多行后可批量删除。
- **相关功能**：SRS / SDS 文档（图表与文档节点双向联动、列表自动回填）、产品管理（图表挂在产品下）。

## 4. 全局视图

- **界面位置**：菜单「全局视图 → 文档内容比对」。
- **用户常见问法**：怎么看产品追溯、追溯总览在哪、怎么导出追溯、怎么核对 SRS 和 SDS 版本、怎么做产品追溯。
- **是做什么的**：按产品展示其 SRS / SDS 版本配对与追溯关系，并支持单行导出该产品的完整追溯 Excel。
- **解决什么问题**：快速核对某个产品的 SRS / SDS 版本配对与追溯覆盖情况（需求、设计、风险、测试的追溯关系）。
- **怎么用**：
  1. 进入「产品追溯总览 → 追溯总览」。
  2. 在搜索框输入产品名称进行模糊搜索，回车或点搜索按钮。
  3. 表格按产品展示：产品名称、型号、完整版本、版本追溯（该产品的 SRS + SDS 版本组合）、追溯文档（SRS / SDS 版本列表）。
  4. 点某产品行的「导出」，导出该产品的完整追溯 Excel（含需求、设计、风险、测试的追溯关系）。
- **相关功能**：文档对比（版本升级时核对功能增删）、SRS / SDS 文档、产品 RCM（风险控制追溯）、测试用例。

## 5. 文档对比

- **界面位置**：菜单「全局视图 → 内容对比」。
- **用户常见问法**：怎么做文档对比、怎么对比两个产品、SRS 怎么对比、SDS 版本怎么比、怎么看功能增删、版本对比在哪。
- **是做什么的**：选择文档类型（SRS 或 SDS）后，对左右各选一份产品的文档版本进行差异对比。
- **解决什么问题**：在版本升级或产品对照时，快速看出两份文档在产品信息、版本、功能等方面的相同与不同（尤其是功能增删）。
- **怎么用**：
  1. 选择文档类型：需求规格说明（SRS）/ 软件详细设计（SDS）。
  2. 左侧选择产品 A 及其文档版本。
  3. 右侧选择产品 B 及其文档版本。
  4. 点「开始对比」。
  5. 在结果表格中查看：对比项名称、产品 A 值、产品 B 值、对比状态（相同 / 不同）；对比项含产品名 / 型号 / 版本 / UDI / 适用范围、SRS（或 SDS）版本、功能增删。
- **相关功能**：产品追溯总览、SRS / SDS 文档。
