# 产品追溯总览与对比

## 1. 功能概述

- **产品追溯总览**：展示产品的 SRS/SDS 版本对与追溯关系，单行导出追溯 Excel。
- **产品对比**：选 SRS 或 SDS 两份文档对比差异。

---

## 2. 产品追溯总览

### 2.1 用户操作流程
模糊搜索产品 → 表格展示 SRS+SDS 版本对、`srs_versions`/`sds_versions` → 单行导出追溯 Excel。

### 2.2 前端 / 后端
- 页面：`overview/ProdTraces.tsx`
- `list_product({ with_trace: 1 })`、`export_product_trace({ id })`
- 菜单权限：`product_view`

### 2.3 业务逻辑
- `__query_traces`：SdsDoc join SrsDoc on srsdoc_id，按产品聚合 TraceObj。
- 导出模板 `temp_product_trace.xlsx`，按 SRS/SDS 版本分行写产品信息与文档类型标签。

---

## 3. 产品对比

### 3.1 用户操作流程
选文档类型（SRS/SDS）→ 左右各选产品版本 → 各选文档版本 →「开始对比」→ 表格显示列名、A/B 值、相同/不同。

### 3.2 前端
- 页面：`overview/ProdComparison.tsx`
- 对比 API（**非 product 模块**）：`compare_srs_doc({ id0, id1 })` / `compare_sds_doc`
- 产品列表：`doSearchProducts`（list_product）

### 3.3 返回结构
行数组：`column_code, column_name, values[0|1], same_flag`（1 相同，否则不同）。

### 3.4 对比项
- 产品名/型号/版本/UDI/scope、SRS 版本、（SDS 额外）SDS 版本。
- **功能增删按 `srs_req.code` 集合差集**（不按名称），名称仅展示用。

---

## 4. 边界与特殊处理

- 对比须 `doc_a_id !== doc_b_id`；版本下拉按 version 去重。
- 菜单权限：`product_view`（非独立 overview 权限码）。
- 产品对比前端入口在 overview；SDS 对比 API 已实现，列表页未必暴露入口。

---

## 5. 修改注意事项 / 不可破坏的核心逻辑

1. **功能增删按 code 集合差集，不按名称**——避免改名误判，不可改回按名称。
2. 追溯总览 `__query_traces` 按 srsdoc_id join 是追溯链基础。
3. 对比 API 归属 SRS/SDS 模块，不在 product 模块。
