# 用户操作说明书（九）全局视图：文档对比、整合导出、一键打印

> 涵盖：文档内容比对、整合导出、导出记录、一键打印、打印记录、AI 客服。
> 适用范围：所有用户（对应 `product_view` 权限）。

---

## 1. 文档内容比对（菜单：全局视图 → 文档内容比对，`overview/DocComparison.tsx`）

### 1.1 适用范围
对比两个文档（SRS 或 SDS）的内容差异，支持按文档类型切换。

### 1.2 操作步骤
1. 进入「全局视图 → 文档内容比对」。
2. 选择**文档类型**：需求规格说明（SRS）/ 软件详细设计（SDS）。切换会清空左右选择与结果。
3. 左侧：选择产品 A + 文档版本（选产品后加载去重版本）。
4. 右侧：选择产品 B + 文档版本。
5. 点「开始对比」。

### 1.3 对比结果
表格列：对比项名称、产品 A 值、产品 B 值、对比状态（相同 / 不同）。
- 对比项含产品名/型号/版本/UDI/适用范围、文档版本、功能增删。
- **功能增删按需求编号集合差集判断**，改名不计为增删。

### 1.4 边界测试
| 场景 | 预期 |
|------|------|
| 未选齐 | 「请选择…（select_both）」 |
| 左右选同一文档 | 「请选择不同的文档（select_different）」 |
| 无差异 | 全部显示「相同」 |
| 无数据 | 结果区显示「-」 |

## 2. 整合导出（菜单：全局视图 → 整合导出 → 整合导出，`overview/DocIntegrateExport.tsx`）

### 2.1 适用范围
按产品+版本聚合所有文档（产品文件/开发文件/测试文件三大分组），勾选后批量导出为 zip 包。

### 2.2 操作步骤
1. 进入「全局视图 → 整合导出 → 整合导出」。
2. 选择产品 + 完整版本。
3. 页面按三大分组展示文档清单（Collapse 折叠面板 + Table）：
   - **产品文件**（16个）：产品立项报告、产品开发计划、需求规格说明、产品验收记录、产品发布说明、版本更新历史、产品技术要求、自研软件研究报告、风险管理计划、初步危害分析清单、自研软件网络安全研究报告、网络安全能力分析、产品标签样稿、网络安全维护计划、风险管理报告、培训记录表
   - **开发文件**（8个）：软件配置管理计划、软件配置状态报告、软件开发计划、软件详细设计、开发环境维护说明、代码审查记录、数据申请单、开发设备清单
   - **测试文件**（10个）：软件测试计划、软件测试报告、测试环境维护说明、安装维护手册、现场测试规程、现场测试记录、用户测试计划、用户测试报告、测试设备清单
4. 勾选需要导出的文档（可全选）。
5. 点「整合导出」，系统逐个生成 Word 文档，通过 SSE 进度条显示进度。
6. 全部完成后自动下载 zip 包。

### 2.3 边界测试
| 场景 | 预期 |
|------|------|
| 未选产品 | 文档清单为空 |
| 未勾选任何文档 | 提示请选择文档 |
| 导出过程中某个文档失败 | 进度条显示失败数，继续导出其余文档 |
| 产品下无任何文档 | 文档清单显示为空 |

## 4. 一键打印（菜单：全局视图 → 一键打印 → 一键打印，`overview/DocOneClickPrint.tsx`）

### 4.1 适用范围
按产品+版本勾选文档，逐个调用 IPP 打印接口发送到默认打印机。

### 4.2 操作步骤
1. 进入「全局视图 → 一键打印 → 一键打印」。
2. 选择产品 + 完整版本。
3. 勾选需要打印的文档。
4. 点「一键打印」，系统逐个生成 Word 文档并发送到默认打印机。
5. 打印结果记录到打印记录表。

### 4.3 前置条件
- 需先在「通用配置 → 打印服务配置」中配置并设置默认打印机。

### 4.4 边界测试
| 场景 | 预期 |
|------|------|
| 未配置默认打印机 | 提示请先配置打印机 |
| 打印机连接失败 | 记录失败，继续打印其余文档 |
| 未勾选任何文档 | 提示请选择文档 |

## 6. AI 客服

### 6.1 适用范围
提供 AI 客服问答功能，基于用户手册和 AI 客服知识库进行检索式问答。

### 6.2 操作步骤
1. 在系统导航中找到 AI 客服入口（通常在页面右下角或导航栏）。
2. 在输入框输入问题。
3. 系统自动检索知识库，返回 TOP 2 最相关章节内容。
4. 未命中时返回"猜你想问"建议。

### 6.3 边界测试
| 场景 | 预期 |
|------|------|
| 输入空问题 | 提示请输入问题 |
| 问题无匹配结果 | 返回"猜你想问"建议 |
| 知识库文件不存在 | 提示知识库不可用 |
