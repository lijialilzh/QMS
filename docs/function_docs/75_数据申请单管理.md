# 数据申请单管理（DAT）

## 1. 功能概述

管理数据申请单（开发文件），设备清单表格以 JSON 存储，支持切换产品重新获取产品信息。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/dat/DatDocs.tsx`（列表）、`DatDocDetail.tsx`（详情/编辑）
- API：`api/ApiDatDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_dat_doc` | `dat_doc_edit` |
| GET | `/duplicate_dat_doc` | `dat_doc_edit` |
| POST | `/update_dat_doc` | `dat_doc_edit` |
| GET | `/rebind_product` | `dat_doc_edit` |
| DELETE | `/delete_dat_doc` | `dat_doc_edit` |
| GET | `/list_dat_doc` | `dat_doc_view` |
| GET | `/get_dat_doc` | `dat_doc_view` |
| GET | `/export_dat_doc` | `dat_doc_view` |

---

## 5. 数据库表

`dat_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 设备清单表格以 JSON 表格形式存储。
2. 支持 rebind_product 切换产品。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
