# 单元测试计划管理（UTP）

## 1. 功能概述

管理单元测试计划（测试文件），PDP 风格章节树结构。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/utp/UtpDocs.tsx`（列表）、`UtpDocDetail.tsx`（详情/编辑）
- API：`api/ApiUtpDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_utp_doc` | `utp_doc_edit` |
| GET | `/duplicate_utp_doc` | `utp_doc_edit` |
| POST | `/update_utp_doc` | `utp_doc_edit` |
| GET | `/rebind_product` | `utp_doc_edit` |
| DELETE | `/delete_utp_doc` | `utp_doc_edit` |
| GET | `/list_utp_doc` | `utp_doc_view` |
| GET | `/get_utp_doc` | `utp_doc_view` |
| GET | `/export_utp_doc` | `utp_doc_view` |

---

## 5. 数据库表

`utp_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. PDP 风格章节树结构。
2. 与 UTR（单元测试报告）不同，UTP 是测试计划阶段文档。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
