# 算法模块管理

## 1. 功能概述

在「产品管理 → 基本信息」下新增「算法模块管理」页面，维护产品（产品 + 完整版本）所包含的算法模块清单。

- **绑定维度**：产品 + 完整版本（`prod_id`）。
- **表格列**：序号、模块。
- **默认值**：首次打开某产品且无模块时，自动写入「肺栓塞分割」「肺叶分割」两条，之后可手动新增/删除/改名。

## 2. 数据表

表名 `prod_algo_module`：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 主键 |
| prod_id | Integer NOT NULL, index | 产品 ID |
| name | String(128) | 模块名称 |
| sort_order | Integer 默认 0 | 排序 |

## 3. 接口

- `POST /prod_algo_module/add_prod_algo_module`（`prod_algo_module_edit`）
- `POST /prod_algo_module/update_prod_algo_module`（`prod_algo_module_edit`）
- `DELETE /prod_algo_module/delete_prod_algo_modules`（`prod_algo_module_edit`）
- `GET /prod_algo_module/list_prod_algo_module`（`prod_algo_module_view`）

## 4. 规则

- 未选产品时内容区居中空态「请先选择产品」；新增/删除按钮禁用。
- 首次打开某产品且模块为空时，自动写入默认 2 条（肺栓塞分割、肺叶分割），写入失败不阻塞。
- 模块名称单元格点击可编辑并即时保存；序号按 `sort_order` 升序展示为 1..N。
- 权限：写 `prod_algo_module_edit`，读 `prod_algo_module_view`；产品经理拥有读写，开发/测试/RA 仅读。

## 5. 验收标准

- [ ] 菜单出现在「产品管理 → 基本信息」下。
- [ ] 选择产品（完整版本）后正确加载该产品算法模块。
- [ ] 新产品的空列表自动写入「肺栓塞分割」「肺叶分割」。
- [ ] 新增/删除/改名可正常操作并保存。
- [ ] 不同产品模块数据互不影响。
