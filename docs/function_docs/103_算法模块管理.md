# 算法模块管理

## 1. 功能概述

在「产品管理 → 基本信息」下提供一个「算法模块管理」菜单（不再分子菜单「导航模块管理」「章节模块管理」），维护产品（产品 + 完整版本）的算法模块清单。

- **绑定维度**：产品 + 完整版本（`prod_id`）。
- **列表来源**：以章节模块 `prod_algo_chapter` 为清单；同一产品下按模块名称对齐导航模块 `prod_algo_module`。只存在于导航模块、名称对不上章节模块的旧数据，仍出现在本列表中。
- **表格列**：序号、模块、是否为导航模块。
- **是否为导航模块**：下拉「是 / 否」。新增行默认「否」。
- **默认值**：某产品两张表都为空时，首次展开只写入章节模块「肺栓塞分诊」「肺叶分割」，是否为导航模块为「否」。已有导航模块时不补写章节模块。

模型文件列表、数据文件列表仍只读 `prod_algo_module`。文档章节（`md_003`、`md_014` 等）仍只读 `prod_algo_chapter`。本页只改这两张表的维护方式，不改上述读取逻辑。

## 2. 数据表

两张表都保留，字段不变。

`prod_algo_chapter`（章节模块，文档章节读取）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 主键 |
| prod_id | Integer NOT NULL, index | 产品 ID |
| name | String(128) | 模块名称 |
| sort_order | Integer 默认 0 | 排序 |

`prod_algo_module`（导航模块，模型/数据文件列表读取）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 主键 |
| prod_id | Integer NOT NULL, index | 产品 ID |
| name | String(128) | 模块名称 |
| sort_order | Integer 默认 0 | 排序 |

名称非空且相同的一行，视为同一模块。是否为导航模块 = 「是」表示该名称在 `prod_algo_module` 中有记录。

## 3. 接口

章节模块：

- `POST /prod_algo_chapter/add_prod_algo_chapter`（`prod_algo_chapter_edit`）
- `POST /prod_algo_chapter/update_prod_algo_chapter`（`prod_algo_chapter_edit`）
- `DELETE /prod_algo_chapter/delete_prod_algo_chapters`（`prod_algo_chapter_edit`）
- `GET /prod_algo_chapter/list_prod_algo_chapter`（`prod_algo_chapter_view`）

导航模块：

- `POST /prod_algo_module/add_prod_algo_module`（`prod_algo_module_edit`）
- `POST /prod_algo_module/update_prod_algo_module`（`prod_algo_module_edit`）
- `DELETE /prod_algo_module/delete_prod_algo_modules`（`prod_algo_module_edit`）
- `GET /prod_algo_module/list_prod_algo_module`（`prod_algo_module_view`）

## 4. 规则

- 菜单一项：「算法模块管理」，入口权限 `prod_algo_chapter_view`。旧地址 `/prod_algo_modules` 打开同一页。
- 未选具体产品时默认「全部」，以产品行列出已有章节模块或导航模块的产品（模块数 = 合并后的行数）。点「编辑」或「新增」在本页展开；展开后按钮变为「收起」。
- 展开后列：序号、模块、是否为导航模块、操作。操作列为上移 / 下移 / ＋ / 删除。「＋」在该行下方插入空行（只加章节模块，是否为导航模块为「否」）。无展开区内顶部「新增」按钮。
- 选「是」：按当前名称写入 `prod_algo_module`（名称为空时不写，提示先填名称）。选「否」：删掉同名导航模块，章节模块保留；若该行本来就只有导航模块，则这一行从列表消失。
- 改名：有章节模块则改章节模块名称；该行是导航模块时同步改导航模块名称。名称为空的导航模块不允许保存。
- 删除一行：章节模块与已对齐的导航模块一起删。列表「删除」清掉该产品全部章节模块和全部导航模块。
- 上移 / 下移：按合并后的列表顺序重写两边的 `sort_order`。
- 模块名称单元格点击可编辑并即时保存。序号按合并后的顺序展示为 1..N。
- 权限：章节模块读写沿用 `prod_algo_chapter_view` / `prod_algo_chapter_edit`；改「是否为导航模块」以及同步改名、删除、排序会调用导航模块接口，沿用 `prod_algo_module_view` / `prod_algo_module_edit`。产品经理拥有两边读写，开发/测试/RA 仅读。

## 5. 验收标准

- [ ] 「产品管理 → 基本信息」下只有一个「算法模块管理」，没有「导航模块管理」「章节模块管理」。
- [ ] 进入页面默认「全部」，列出已有章节模块或导航模块的产品。
- [ ] 展开后有「是否为导航模块」列，可选「是」「否」。
- [ ] 选「是」后，模型/数据文件列表能按该名称筛到该模块；选「否」后筛不到，文档章节仍能取到该章节模块。
- [ ] 两张表都空时，展开写入「肺栓塞分诊」「肺叶分割」，且都不是导航模块。
- [ ] 新增/删除/改名/排序后，章节模块与已标记的导航模块名称、顺序一致。
- [ ] 不同产品模块数据互不影响。
