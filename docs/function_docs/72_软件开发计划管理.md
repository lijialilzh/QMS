# 软件开发计划管理（SD）

## 1. 功能概述

管理软件开发计划（开发文件），模板参考产品开发计划（pdp_doc），包含封面/修订记录/各章节文本/人员-软件资源-里程碑三张表。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/sd/SdDocs.tsx`（列表）、`SdDocDetail.tsx`（详情/编辑）
- API：`api/ApiSdDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_sd_doc` | `sd_doc_edit` |
| GET | `/duplicate_sd_doc` | `sd_doc_edit` |
| POST | `/update_sd_doc` | `sd_doc_edit` |
| GET | `/rebind_product` | `sd_doc_edit` |
| DELETE | `/delete_sd_doc` | `sd_doc_edit` |
| GET | `/list_sd_doc` | `sd_doc_view` |
| GET | `/get_sd_doc` | `sd_doc_view` |
| GET | `/export_sd_doc` | `sd_doc_view` |

---

## 5. 数据库表

`sd_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. PDP 风格章节树，包含人员表、软件资源表、里程碑表三张表格。
2. 支持 rebind_product 切换产品重新获取产品信息。
3. 评审记录页面与需求规格说明一致：只读合并表，点右侧「编辑」弹出表格编辑，确认后写回；点「删除」去掉该表。编辑弹框里，参评人员签字、评审时间、评审结论、批准人员签字这些只在第一格有内容的行合并成一格。查看页不显示编辑和删除。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 三张表格的结构与 PDP 保持一致。
