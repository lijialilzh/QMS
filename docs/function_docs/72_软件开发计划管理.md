# 软件开发计划管理（SD）

## 1. 功能概述

管理软件开发计划（开发文件），模板参考产品开发计划（pdp_doc），包含封面/修订记录/各章节文本/人员-软件资源-里程碑三张表。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/sd/SdDocs.tsx`（列表）、`SdDocDetail.tsx`（详情/编辑）
- API：`api/ApiSdDoc.ts`

## 5. 数据库表

`sd_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. PDP 风格章节树，包含人员表、软件资源表、里程碑表三张表格。
2. 支持 rebind_product 切换产品重新获取产品信息。
3. 评审记录页面与需求规格说明一致：只读合并表，点右侧「编辑」弹出表格编辑，确认后写回；点「删除」去掉该表。编辑弹框里，参评人员签字、评审时间、评审结论、批准人员签字这些只在第一格有内容的行合并成一格。查看页不显示编辑和删除。
4. 文件修订记录「修订人」取产品开发负责人：角色为产品开发负责人或开发负责人；否则取所属部门为产品开发部、角色为 TPM（或负责人、经理，不含研发负责人、产品经理）的人；再没有则取 TPM。不取研发负责人。打开和导出时覆盖。批准人仍取研发负责人。
5. 项目简介自动写入产品名称、产品型号、完整版本。项目开发时间取时间线「产品开发部」中「产品开发」活动的开始日到结束日。
6. 人员资源打开即自动填入，不点获取按钮。只取产品开发负责人，以及角色为开发人员/开发工程师或备注含前端、后端的人，所属部门写产品开发部。该表不能改单元格、不能增删行列，只能删除此表。
7. 软件开发计划及里程碑的计划完成时间按上述开发起止按比例拆分后，若落在周末或法定假日则顺延到下一工作日（调休上班日不顺延）。
