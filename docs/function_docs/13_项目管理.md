# 项目管理

## 1. 功能概述

维护项目（产品归属的上级），项目下挂产品。

---

## 2. 用户操作流程

按名称查询 → 增删改 → 删除前校验无关联产品；列表显示 `product_count`。

---

## 3. 前端实现

- 页面：`pages/syscfg/Projects.tsx`
- API：`/project/*`
- 国家枚举：`FDA, NMPA, PMDA, CE, MDR`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/project/add_project` | project_edit |
| POST | `/project/update_project` | project_edit |
| DELETE | `/project/delete_project` | project_edit |
| GET | `/project/list_project` | project_view |
| GET | `/project/get_project` | project_view |

---

## 5. 数据库表

`project`：id, name(唯一), country, note。

---

## 6. 关键业务逻辑与规则

- `name` 唯一。
- 删除阻断：存在 `product.project_id` 指向该项目则失败（`msg_proj_x_product`）。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. **删除前的产品关联校验**不可移除，否则会产生孤儿产品。
2. 国家枚举为前端固定值，新增需前端同步。
