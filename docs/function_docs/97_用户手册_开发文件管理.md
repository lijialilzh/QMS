# 用户操作说明书（八）开发文件管理

> 涵盖：软件配置管理计划、软件配置状态报告、软件开发计划、软件详细设计、开发环境维护说明、代码审查记录、数据申请单、开发设备清单。

---

## 1. 软件配置管理计划（菜单：开发测试文件管理 → 开发文件 → 软件配置管理计划，`scm/ScmDocs.tsx`）

### 1.1 适用范围
按「产品 + 文档版本」管理软件配置管理计划，PDP 风格章节树结构，支持导出 Word。

### 1.2 筛选
- 产品（完整版本）+ 文档版本（模糊匹配）→ 搜索。

### 1.3 列与操作
- 列：产品名称、完整版本、文件编号、文档版本、创建时间、操作。

| 操作 | 说明 |
|------|------|
| 新建 | 弹窗：选产品、文档版本，打开章节树编辑页 |
| 复制 | 复制当前文档到新版本 |
| 编辑 | 进入编辑页，可修改产品名称、完整版本、文档版本及章节内容 |
| 删除 | 标准确认后删除 |
| 导出 | 导出 Word 文档 |

### 1.4 边界测试
| 场景 | 预期 |
|------|------|
| 同产品同版本再建 | 「数据已存在」 |

## 4. 开发环境维护说明（菜单：开发测试文件管理 → 开发文件 → 开发环境维护说明，`dem/DemDocs.tsx`）

### 4.1 适用范围
按「产品 + 文档版本」管理开发环境维护说明，资产编码从**开发设备清单**自动获取，周检查表按产品时间线自动生成。

### 4.2 筛选
- 产品（完整版本）+ 文档版本（模糊匹配）→ 搜索。

### 4.3 列与操作
- 列：产品名称、完整版本、文件编号、文档版本、创建时间、操作。

| 操作 | 说明 |
|------|------|
| 新建 | 弹窗：选产品、文档版本，打开维护说明编辑页 |
| 复制 | 复制当前文档到新版本 |
| 编辑 | 进入编辑页，可修改产品名称、完整版本、文档版本及维护说明内容 |
| 删除 | 标准确认后删除 |
| 导出 | 导出 Word 文档（横版） |

### 4.4 编辑页字段
| 字段 | 必填 | 说明 |
|------|------|------|
| 产品名称 | 是 | 选产品后自动获取 |
| 完整版本 | 是 | 选产品后自动获取 |
| 文件编号 | 否 | 自动从 DHF「开发环境维护说明」获取 |
| 文档版本 | 是 | 手动输入 |
| 变更说明 | 否 | 版本变更说明 |
| 说明正文 | 否 | 固定模板（八节验证说明），可编辑 |
| 资产表 | 否 | 资产编码从开发设备清单自动获取，设备信息自动匹配 |
| 资产周检查表 | 否 | 按产品时间线「开始开发~测试结束」每周自动生成一行，每格 是/否 复选框 |

### 4.5 自动获取规则
- **资产编码**：从「开发设备清单」按清单顺序自动获取（去重）
- **设备信息**：编码以 ISER 开头 → macOS 配置，否则 → Ubuntu 配置
- **检查人**：从产品参与人员取 TPM 签名章
- **周检查表日期**：从产品时间线取「开始开发~测试结束」区间，按周一~周五生成每周一条记录

### 4.6 边界测试
| 场景 | 预期 |
|------|------|
| 同产品同版本再建 | 「数据已存在」 |
| 产品无开发设备清单 | 资产表为空 |
| 产品无时间线 | 无周检查表日期行 |

## 7. 开发设备清单（菜单：开发测试文件管理 → 开发文件 → 开发设备清单，`deq/DeqDocs.tsx`）

### 7.1 适用范围
按「产品 + 文档版本」管理开发设备清单，设备清单表格以 JSON 存储，支持导出 Word。

### 7.2 筛选
- 产品（完整版本）+ 文档版本（模糊匹配）→ 搜索。

### 7.3 列与操作
- 列：产品名称、完整版本、文件编号、文档版本、创建时间、操作。

| 操作 | 说明 |
|------|------|
| 新建 | 弹窗：选产品、文档版本，打开设备清单编辑页 |
| 复制 | 复制当前文档到新版本（同产品版本递增，跨产品版本按目标产品最大版本递增） |
| 编辑 | 进入编辑页，可修改产品名称、完整版本、文档版本及设备清单表格 |
| 删除 | 标准确认后删除 |
| 导出 | 导出 Word 文档 |

### 7.4 编辑页字段
| 字段 | 必填 | 说明 |
|------|------|------|
| 产品名称 | 是 | 选产品后自动获取 |
| 完整版本 | 是 | 选产品后自动获取 |
| 文件编号 | 否 | 自动从 DHF「开发设备清单」获取 |
| 文档版本 | 是 | 手动输入 |
| 变更说明 | 否 | 版本变更说明 |
| 设备清单表格 | 否 | 可编辑表格（序号/名称/规格型号/品牌/资产编码/类别/用途/地点/使用人），默认 10 行示例数据 |

### 7.5 边界测试
| 场景 | 预期 |
|------|------|
| 同产品同版本再建 | 「数据已存在」 |
| 复制到同产品 | 版本号自动递增 |
| 删除已有设备清单 | 直接删除，无级联 |
