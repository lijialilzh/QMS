# 漏洞文档管理（VUH）

## 1. 功能概述

管理漏洞文档（产品文件），包含封面/修订记录/各章节文本/表格。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/vuh/VuhDocs.tsx`（列表）、`VuhDocDetail.tsx`（详情/编辑）
- API：`api/ApiVuhDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_vuh_doc` | `vuh_doc_edit` |
| GET | `/duplicate_vuh_doc` | `vuh_doc_edit` |
| POST | `/update_vuh_doc` | `vuh_doc_edit` |
| DELETE | `/delete_vuh_doc` | `vuh_doc_edit` |
| GET | `/list_vuh_doc` | `vuh_doc_view` |
| GET | `/get_vuh_doc` | `vuh_doc_view` |
| GET | `/export_vuh_doc` | `vuh_doc_view` |

---

## 5. 数据库表

`vuh_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与版本更新历史（54）不同，VUH 是安全漏洞文档。
2. 章节树结构存储。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
