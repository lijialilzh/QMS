## 1. 功能概述

在「基础数据」下维护全局 ECR 登记台账。一条记录对应一个 ECR 编号，不绑定产品版本。

字段：ECR编号、变更后产品名称、变更后版本号、编号申请日期、申请人、变更申请内容、备注。日期按登记表原文保存（如 `2022/10/17`、`2023/2/6`），空单元格保持空字符串。

表为空时写入登记表中的 34 条初始数据，只写一次。之后删除或改动不再自动补回。

---

## 2. 前置依赖 & 关联模块

- 菜单：「基础数据 → ECR管理」`/ecrs`。root、DQA、QA 可见，权限 `ecr_view`。
- 增删改与参与人员相同，仅 root、DQA（及用户 1）可写，权限 `ecr_edit`。
- 编号必填，且不可与其他行重复。

---

## 3. 页面操作

1. 进入页面调用 `list_ecr`，按 `sort_order, id` 升序。顶部可按编号、产品名称、版本、申请人、变更内容、备注搜索。列表只展示，单元格不可直接改。
2. 顶部「新增」打开弹窗，填写后点保存调用 `add_ecr`，新记录排在末尾。ECR编号必填。
3. 操作列「编辑」打开同一弹窗并带出当前行，保存调用 `update_ecr`。变更内容和备注为多行文本。
4. 操作列「删除」经二次确认后调用 `delete_ecr`。
