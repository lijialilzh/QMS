# 现场测试规程管理（FTR）

## 1. 功能概述

管理现场测试规程（测试文件 VV-006），PDP 风格章节树结构，与软件测试计划（STP）结构一致。用于记录产品在现场环境下的测试规程文档，属于质量管理体系中的测试文件。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节（产品信息/时间线/参与人员）→ 导出 docx。

---

## 3. 前端实现

- 页面：`pages/ftr/FtrDocs.tsx`（列表）、`FtrDocDetail.tsx`（详情/编辑）
- API：`api/ApiFtrDoc.ts`

## 5. 数据库表

`ftr_doc`：product_id, version, file_no, change_log, content(JSON)，唯一约束(product_id, version)

---

## 6. 关键业务逻辑与规则

1. content 为 JSON 格式 `{"sections": [...]}`，每个 section 是树形节点（title/body/tables/children）。
2. 自动填充：产品名称替换、文件修订记录（日期/版本/修订人/批准人）、运行环境（从 ProdRuntimeEnv 读取 4 张表）、封面日期/签署人。
3. 复制逻辑：同产品版本递增（A0→A1），跨产品取目标产品最大版本递增。
4. 切换产品（rebind_product）：删除旧记录，重置 content 为默认模板，强制重新自动填充。
5. 导出使用 python-docx 生成 Word，含封面/修订记录/目录/正文章节。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 的 sections 树结构不可改变。
2. 自动填充逻辑（__autofill）不可破坏。
