# 标签文档管理（Label）

## 1. 功能概述

管理产品标签样稿（产品文件），包含封面/修订记录/标签表格/技术要求。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/label/LabelDocs.tsx`（列表）、`LabelDocDetail.tsx`（详情/编辑）
- API：`api/ApiLabelDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_label_doc` | `label_doc_edit` |
| GET | `/duplicate_label_doc` | `label_doc_edit` |
| POST | `/update_label_doc` | `label_doc_edit` |
| DELETE | `/delete_label_doc` | `label_doc_edit` |
| GET | `/list_label_doc` | `label_doc_view` |
| GET | `/get_label_doc` | `label_doc_view` |
| GET | `/export_label_doc` | `label_doc_view` |

---

## 5. 数据库表

`label_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 标签表格以 JSON 表格形式存储于 content 中。
2. 打开和导出使用同一套自动获取。图1、图3 按当前产品版本覆盖：产品型号、英文名称、完整版本、发布版本、软件名称、UDI 取产品；注册人取该产品版本上的注册人，住所、受托生产企业、生产地址、生产许可证编号、联系电话取注册人对应的公司基本信息。对不上注册人时用 id 最小的公司。成品序列号、生产日期、产品注册证号、使用期限没有产品字段，保持文档里的值。封面表不覆盖。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
