# 用户管理

## 1. 功能概述

系统配置下的用户 CRUD 与密码重置，账号绑定角色。

---

## 2. 用户操作流程

查询（账号/姓名/角色）→ 分页列表 → 新增/编辑（账号、姓名、角色、权限预览）→ 重置密码 → 删除/批量删除（`master` 不可删、不可勾选）。

---

## 3. 前端实现

- 页面：`pages/syscfg/Users.tsx`
- API：`api/ApiUser.ts`；角色下拉 `ApiRole.list_role`
- 常量：`MASTER="master"`

---

## 4. 后端接口

| 方法 | 路径 | 权限 | 入参要点 |
|------|------|------|----------|
| POST | `/user/add_user` | user_edit | UserForm: name, nick_name, role_code |
| POST | `/user/update_user` | user_edit | id, nick_name, role_code, 可选 pwd（不可改 name） |
| DELETE | `/user/delete_user` | user_edit | id（禁止删自己） |
| GET | `/user/reset_pwd` | user_edit | id（禁止重置 ADMIN_NAME） |
| GET | `/user/list_user` | user_view \| product_edit | name, nick_name, role_code, 分页 |
| GET | `/user/get_user` | user_view | id |

---

## 5. 数据库表

`usr`：id, name(唯一), pwd, pwd_sk, nick_name, role_code。

---

## 6. 关键业务逻辑与规则

1. 新增：`name` 唯一，初始密码 `DEF_PWD`。
2. 编辑：**不可改 `name`**；master 角色不可改。
3. `list_user` 左连 `role` 带出 `role_name`。
4. 删除：禁止删除自己；master 不可删。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. **不可修改用户登录名 `name`**（唯一键，且会破坏历史关联）。
2. **删除自己 / 删除或重置 master 的禁止逻辑**不可移除。
3. `list_user` 对 `product_edit` 开放是为产品配置选人，不可收紧。
