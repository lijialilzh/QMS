# 研究文档管理（Research）

## 1. 功能概述

管理自研软件研究报告（产品文件），包含封面/各章节文本/表格/图片，支持自动获取产品数据注入（通过 `ref_type` / `img_category` 标记）。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/research/ResearchDocs.tsx`（列表）、`ResearchDocDetail.tsx`（详情/编辑）
- API：`api/ApiResearchDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_research_doc` | `research_doc_edit` |
| GET | `/duplicate_research_doc` | `research_doc_edit` |
| POST | `/update_research_doc` | `research_doc_edit` |
| DELETE | `/delete_research_doc` | `research_doc_edit` |
| GET | `/list_research_doc` | `research_doc_view` |
| GET | `/get_research_doc` | `research_doc_view` |
| GET | `/research_autofill` | `research_doc_view` |
| GET | `/export_research_doc` | `research_doc_view` |

---

## 5. 数据库表

`research_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. `ref_type` 标记自动获取章节（只读），`img_category` 标记图片插入位置。
2. 导出时自动注入产品信息、公司信息、人员签名等。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. `ref_type` / `img_category` 标记的自动内容不可编辑。
