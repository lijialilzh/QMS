# 研究文档管理（Research）

## 1. 功能概述

管理自研软件研究报告（产品文件），包含封面/各章节文本/表格/图片，支持自动获取产品数据注入（通过 `ref_type` / `img_category` 标记）。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/research/ResearchDocs.tsx`（列表）、`ResearchDocDetail.tsx`（详情/编辑）
- API：`api/ApiResearchDoc.ts`

## 5. 数据库表

`research_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. `ref_type` 标记自动获取章节（只读），`img_category` 标记图片插入位置。
2. 导出时自动注入产品信息、公司信息、人员签名等。
3. 章节 1.5 运行环境（`rt_hw` / `rt_sw` / `rt_net`）打开/刷新/导出时按产品运行环境 `tables_json` 覆盖对应表格。文档内自动获取内容只读；章节标题可改、章节可删。章节树通用表格列宽按内容自适应，编号等短列收窄。
4. 章节 1.1 软件标识（`ref_type=sw_ident`）打开/刷新/切换产品/导出时覆盖：
   - `注册申请人` ← 产品「注册人」；
   - `设计开发地址` ← 产品「设计开发地址」（空则回退该公司信息「住所」）。
5. 本文件属**产品部**文件。打开/刷新/切换产品/导出时：
   - 封面编制人 ← 参与人员角色含「产品经理」者；审核人、批准人 ← 产品总监（夏晨）。不取开发部 TPM / 研发负责人。打开时覆盖已填的开发部人员/签名。
   - 封面编制/审核/批准日期与生效日期 ← 时间逻辑线命中「自研软件研究报告」的评审日（无评审则取该文档最后一天），格式 `yyyy.MM.dd`；仅填空。
   - 文件修订记录首行：`修改日期` ← 同上时间线日期（覆盖模板占位 `2025.10.21`；无时间线则清空占位）；`版本号` ← 文档版本；`修订说明` 空则「首次发布」；`修订人` 空则产品经理；`批准人` 空则角色含「产品…负责人」者。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. `ref_type` / `img_category` 标记的自动内容不可编辑。
