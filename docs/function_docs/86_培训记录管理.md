# 培训记录管理（Train Record）

## 1. 功能概述

管理培训记录表（测试文件），一张大表格以 JSON 存储。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 大表格编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/train_record/TrainRecordDocs.tsx`（列表）、`TrainRecordDocDetail.tsx`（详情/编辑）
- API：`api/ApiTrainRecordDoc.ts`

---

---

## 5. 数据库表

`train_record_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 权限复用 `ftr_record_doc_*` 权限码。修改文档版本后，标题下文件编号末尾的版本段（如 A0）自动改为与文档版本一致，保存、再次打开和导出都用改后的编号。
2. 大表格以 JSON 数组形式存储。
3. 打开与导出时，这 6 格按产品自动覆盖，不再把字段名本身当作内容：
   - 培训时间 ← 该产品时间逻辑线中，输出结果含「用户培训记录」的日期行（多条取时间线上靠后的一条）；没有则为空。
   - 培训地点 ← 公司。
   - 培训人数 ← 该产品项目人员里职能为「用户测试」的人数；没有则为空。
   - 培训方式 ← 现场操作及线上。
   - 授课老师 ← 该产品「产品经理」。
   - 培训学时 ← 2。
   培训人员名单取同一批「用户测试」人员姓名，有几人写几人，用顿号连接；没有则为空。考核人员在为空时取产品经理。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与大表格编辑器兼容。
