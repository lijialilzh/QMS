# 培训记录管理（Train Record）

## 1. 功能概述

管理培训记录表（测试文件），一张大表格以 JSON 存储。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 大表格编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/train_record/TrainRecordDocs.tsx`（列表）、`TrainRecordDocDetail.tsx`（详情/编辑）
- API：`api/ApiTrainRecordDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_train_record_doc` | `ftr_record_doc_edit` |
| GET | `/duplicate_train_record_doc` | `ftr_record_doc_edit` |
| POST | `/update_train_record_doc` | `ftr_record_doc_edit` |
| GET | `/rebind_product` | `ftr_record_doc_edit` |
| DELETE | `/delete_train_record_doc` | `ftr_record_doc_edit` |
| GET | `/list_train_record_doc` | `ftr_record_doc_view` |
| GET | `/get_train_record_doc` | `ftr_record_doc_view` |
| GET | `/export_train_record_doc` | `ftr_record_doc_view` |

---

## 5. 数据库表

`train_record_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 权限复用 `ftr_record_doc_*` 权限码。
2. 大表格以 JSON 数组形式存储。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与大表格编辑器兼容。
