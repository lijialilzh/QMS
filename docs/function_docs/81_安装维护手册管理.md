# 安装维护手册管理（IMM）

## 1. 功能概述

管理安装维护手册（测试文件 VV-005），PDP 风格章节树，额外支持导出 MD5 值附件和 MD5 值评审记录。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx / 导出 MD5 附件 / 导出 MD5 评审记录。

---

## 3. 前端实现

- 页面：`pages/imm/ImmDocs.tsx`（列表）、`ImmDocDetail.tsx`（详情/编辑）
- API：`api/ApiImmDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_imm_doc` | `imm_doc_edit` |
| GET | `/duplicate_imm_doc` | `imm_doc_edit` |
| POST | `/update_imm_doc` | `imm_doc_edit` |
| GET | `/rebind_product` | `imm_doc_edit` |
| DELETE | `/delete_imm_doc` | `imm_doc_edit` |
| GET | `/list_imm_doc` | `imm_doc_view` |
| GET | `/get_imm_doc` | `imm_doc_view` |
| GET | `/export_imm_doc` | `imm_doc_view` |
| GET | `/export_imm_md5_attachment` | `imm_doc_view` |
| GET | `/export_imm_md5_review` | `imm_doc_view` |

---

## 5. 数据库表

`imm_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 特有功能：导出 MD5 值附件和 MD5 值评审记录。
2. PDP 风格章节树结构。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. MD5 导出功能为 IMM 独有，不可移除。
