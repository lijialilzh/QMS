# 安装维护手册管理（IMM）

## 1. 功能概述

管理安装维护手册（测试文件 VV-005），PDP 风格章节树，额外支持导出 MD5 值附件和 MD5 值评审记录。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx / 导出 MD5 附件 / 导出 MD5 评审记录。

---

## 3. 前端实现

- 页面：`pages/imm/ImmDocs.tsx`（列表）、`ImmDocDetail.tsx`（详情/编辑）
- API：`api/ApiImmDoc.ts`

## 6. 关键业务逻辑与规则

1. 特有功能：导出 MD5 值附件和 MD5 值评审记录。
2. PDP 风格章节树结构。同级上下移规则同产品开发计划（52）/软件测试计划（STP）：目录「＋」直接添加子章节（末尾），无「上方/下方同级」下拉；新建与普通空章节显示可编辑正文框；可「添加正文」多段（`{{TXT}}` 分隔），清空某段文字后输入框仍保留；上传图片/添加表格按插入顺序在 body 追加 `{{IMG}}`/`{{TBL}}` 交错展示（不自动多出空正文，须点「添加正文」）；仅 1.2 硬件拓扑无正文框且图只读，运行环境自动表只读。
3. 章节 1.3 运行环境打开/导出时从产品运行环境 `tables_json` 整表覆盖 4 张子表（含增删行列后的结构）：1.3.1←表1 服务器硬件、1.3.2←表2 服务器软件、1.3.3←表3 用户端、1.3.4←表4 网络要求（标题含「用户端」且含「网络/表4」时归网络表，不误配用户端表）。文档内这些表只读；章节标题可改、章节可删；「确认运行环境」警告正文与 1.3.5 其他要求仍可改。章节树通用表格列宽按内容自适应，编号等短列收窄。
4. MD5 值评审记录页面与需求规格说明一致：只读合并表，点右侧「编辑」弹出表格编辑，确认后写回；点「删除」去掉该表。编辑弹框里，参评人员签字、评审时间、评审结论、批准人员签字这些只在第一格有内容的行合并成一格。查看页不显示编辑和删除。
5. **文件修订记录首行**：修改日期 ← 时间线含「安装维护手册 / 安装维护 / MD5」的封面日期（有则覆盖模板错误旧日期）；版本号 / 修订说明仅空则填（说明默认「首次发布」）；修订人 ← 测试人员日期规则（2025.09 前「宋月」、之后「孙家旭」，打开即覆盖，同 STP）；批准人 ← 角色含「研发负责人」者（打开即覆盖）。切换产品 `force` 时上述字段整行覆盖。
6. **正文插图占位**：单独一行的「见下图 / 如下图 / 下图」打开时归一为静默 `{{IMG}}`（编辑页不展示这三字、图仍交错显示）；正文句子里的「见下图/如下图」保留为可编辑文字并在该行后插图。
   - **步骤交错**：章节有 `images` 且正文尚无 `{{IMG}}`/见下图/如下图 时，打开归一化按「1、/1./1）」步骤行后依次插入 `{{IMG}}`（张数不超过图片数），编辑页与导出呈「正文→图→正文→图」；步骤不足则余图追加文末。
   - **正文序号**：交错编辑区「正文 N」只按正文段连续编号（1、2、3…），不因中间插图/表跳号（PDP 风格交错页统一）。
7. **安装包名称（全文自动获取）**：打开/换产品时从同产品《软件配置管理计划》「产品开发部软件构建配置项版本控制」表「验证Build」行存储路径解析末尾 `.zip` 文件名（优先与本手册文档版本相同的计划，没有则该产品最新一份；无计划或无包名则不改），覆盖：
   - `content.package_name`；
   - 正文/表格中所有 `InferCare_….zip` / `InferCare ….zip` 及重复前缀等已写坏包名（含 2.2 MD5校验、2.4.1 检查安装包等，不跳过）；
   - MD5 附件主表与「确认安装包信息」表的安装包名称列；
   - MD5 评审结论文案中的包名。
   型号文案替换（RECIST→当前型号）不改含 `.zip` 的串，且型号已含 InferCare 时先剥再拼，避免叠前缀。MD5 值从附件根表或子节「确认安装包信息」表读取（仅空则回填；再兜底 `content.md5_value`），写入 MD5 评审结论文案。MD5 评审「评审时间」有时间线日期则覆盖模板错误旧值（`force_date`）；参评「测试负责人」按测试人员日期规则覆盖姓名与签字。不改「产品型号：InferCare xxx」等非 `.zip` 包名文案。MD5 附件下「概述」固定为「确保安装包不受篡改…」模板，不被主手册「概述」覆盖；「确认产品信息」仍按当前产品字段覆盖。
8. **1.2 硬件拓扑**：打开/换产品时图片 ← 该产品「产品图示 → 物理拓扑图」`img_topo` 最新一条（`pick_doc_image_file_row`，不取体系结构图）；正文置空（不写「物理拓扑图」/`{{IMG}}`，编辑页不展示正文框）；`images` 有则覆盖、无则清空。该章图片为自动获取，编辑页只读展示（无更换/删除/上传）。其余章节（含交错正文中的插图）图片可更换/删除/上传；运行环境自动获取的表格仍只读。
9. **自动获取且只读章节**：打开/换产品时覆盖正文；编辑页正文不可改，不显示添加正文/图/表。
   - **1.4 软件总体描述** ← 产品 `overall_desc`；
   - **1.5 适用范围** ← 产品 `scope`；
   - **1.7 联系信息** ←「公司基本信息」：公司名称←`registrant`、地址←`address`、电话←`contact_phone`（优先按产品注册人匹配，对不上则取 id 最小一条，同标签文档）；
   - **确认产品信息**（含 MD5 附件下同名节）← 产品名称/型号/发布版本/完整版本。
10. **1.3.x 运行环境子章**：自动表只读；章内警告/说明正文排在**表后**（body 以 `{{TBL}}` 或「表N…」起头，再跟警告文案）。
11. **导出与编辑交错一致**：导出 Word 按与编辑页相同规则渲染章节正文/表/图（`{{TBL}}`/`{{IMG}}`/见下表/表N/见下图/图N/步骤插图；缺占位则按编辑页规则补齐）；不写出 `{{TBL}}`/`{{IMG}}`/`{{TXT}}`/`{{EMPTY}}`；余表/余图追加文末；图片支持 `data:image` 与 `/data.trace/` 路径。
12. **表内截图列**：仅表头为「截图」的数据列可「上传图片」或聚焦后 Ctrl/Cmd+V 粘贴，存为 `data:image`；有图时预览并可更换/清除；其它列仍为文字。导出：签字类小图仍用矮高度；截图按约 150DPI 定显示尺寸（避免低分辨率被撑虚），列加宽，文档关闭自动压缩图片。
