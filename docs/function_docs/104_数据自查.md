# 1. 功能概述

- **用途**：按已设定亚组核对灵敏度/特异度是否达到目标值；核对多中心回传总数与原始库、整理记录剔除后与基础库是否一致。不满足时指出哪一条。
- **使用场景**：左侧菜单「数据质控 → 数据自查」`/data_check`。
- **最终目标**：只读该产品已有数据统计缓存 / `dd_015_*`、多中心回传 `dd_002`、数据整理 `dd_003`，不改这些文档、不新建表。
- **关联**：亚组口径对齐 [101_数据统计.md](./101_数据统计.md) 统计结果（因素下的类别即亚组）。回传/整理表结构见 [100_数据文件管理.md](./100_数据文件管理.md)。

# 3. 完整执行流程（分步细化）

## 3.0 触发入口

菜单「数据质控 → 数据自查」进入 `/data_check`，与「数据统计」同组。无 `data_doc_view` 不显示。

## 3.1 选择产品与参数

1. 选择产品（名称+完整版本）。未选不能自查。
2. 目标值默认 `0.8`，可改。灵敏度和特异度都按该值比较。
3. 剔除例数可手填；不填则从最新 `dd_003` 各行「评估结论」解析「N例」后求和。

## 3.2 点「自查」

### 3.2.1 亚组

1. 病例明细优先本机缓存（标注→基础→原始），没有则从该产品最新 `dd_015_03` / `_02` / `_01` 的 `case_rows` 读。
2. 按 101 统计结果同一套因素生成亚组（原「类别」在本页叫「亚组」）。
3. 灵敏度、特异度为 `/` 或空则跳过该项。
4. 数值 `< 目标值` 记为不满足，列出因素、亚组、指标、实际值。
5. 能比较的项全部 ≥ 目标则该项通过。无明细则提示先做数据统计。

### 3.2.2 多中心回传总数

1. 原始库总数 ← 最新 `dd_015_01` 的 `case_rows` 行数；没有则读表中「数据总量（序列）」。
2. 回传合计 ← 最新 `dd_002` 各医院行「回传数据量」（空则「实际接收量」）求和；跳过记录人/复核人行。
3. 两数不等则提示回传合计与原始库总数。缺文件则提示缺哪份。

### 3.2.3 整理记录与基础库

1. 数据量口径：原始库总数（同上）。
2. 基础库期望值 = 原始库总数 − 剔除例数。
3. 基础库实际值 ← 最新 `dd_015_02` 行数或「数据总量（序列）」。
4. 不等则提示期望值与实际值。`dd_003` 没有且未手填剔除时，剔除按 0。

## 3.3 展示

本页列出通过/不通过条目，不写回任何数据文件。

# 4. 核心规则 & 判定条件

| 编号 | 规则 / 判定条件 | 含义 | 不满足 / 命中时的后果 |
|------|----------------|------|----------------------|
| R1 | 权限 `data_doc_view` | 与数据统计同权 | 菜单不可见 |
| R2 | 只读、不落库 | 不改 `dd_002` / `dd_003` / `dd_015_*` | 自查结果仅本页展示 |
| R3 | 亚组 = 统计结果的类别 | 因素下每一类为一亚组 | 口径与 101 一致 |
| R4 | 目标值默认 0.8 | 灵敏度、特异度均与该值比 | 低于目标列出该亚组该指标 |
| R5 | `/` 不算不满足 | 无法计算则跳过 | 不列入失败 |
| R6 | 回传合计 vs 原始库总数 | 多中心各行数量求和 | 不等则提示两条数字 |
| R7 | 基础库 = 原始库 − 剔除 | 评估结论「N例」或手填 | 与 `dd_015_02` 不等则提示 |

# 6. 异常场景 & 兜底逻辑

- 未选产品：提示「请先选择产品」。
- 无病例明细：亚组项提示「请先在数据统计生成或写入病例明细」。
- 无 `dd_002`：回传项提示「没有多中心数据回传记录」。
- 无 `dd_015_01` / `_02`：对应总数项提示缺原始/基础统计表。
- 评估结论解析不到「N例」且未手填：剔除按 0。

# 7. 功能约束 & 修改红线

## 7.1 允许修改范围

- 本文；前端 `pages/data_check/`；`Home.tsx` 本菜单；`index.tsx` 本路由；i18n `menu.data_check`。只读调用已有 `data_doc` 接口与 `dataStatsLocal`。

## 7.2 绝对禁止改动（红线）

- 禁止改 `src/store/`、`src/common/`、`src/utils/base/`。
- 禁止自查时更新 `dd_002` / `dd_003` / `dd_015_*`。
- 禁止经浏览器上传 DICOM。

## 7.3 禁止新增逻辑

- 不得在无 gt/pred 时编造灵敏度、特异度。
- 不得把全库统计当成某个训练集子集去改构建记录。

## 7.4 禁止重构结构

- 不得把本页合并进数据统计页或数据文件编辑页。
