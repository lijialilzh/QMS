# 软件测试报告管理（STR）

## 1. 功能概述

管理软件测试报告（测试文件），PDP 风格章节树结构。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/str/StrDocs.tsx`（列表）、`StrDocDetail.tsx`（详情/编辑）
- API：`api/ApiStrDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_str_doc` | `str_doc_edit` |
| GET | `/duplicate_str_doc` | `str_doc_edit` |
| POST | `/update_str_doc` | `str_doc_edit` |
| GET | `/rebind_product` | `str_doc_edit` |
| DELETE | `/delete_str_doc` | `str_doc_edit` |
| GET | `/list_str_doc` | `str_doc_view` |
| GET | `/get_str_doc` | `str_doc_view` |
| GET | `/export_str_doc` | `str_doc_view` |

---

## 5. 数据库表

`str_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. PDP 风格章节树结构。
2. 与 STP（软件测试计划）不同，STR 是测试报告阶段文档。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
