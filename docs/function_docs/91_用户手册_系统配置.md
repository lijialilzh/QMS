# 用户操作说明书（二）系统配置：用户 / 角色 / 项目 / 产品

> 适用范围：系统管理员、具备相应 `*_edit` 权限的人员。前置：已登录。

---

## 1. 项目管理（菜单：系统配置 → 项目）

### 1.1 适用范围
管理产品所属的项目分组（如按法规市场 FDA/NMPA/PMDA/CE/MDR 划分）。

### 1.2 新建项目
1. 点「新建」。
2. 填写字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 项目名称 | 是 | 全局唯一 |
| 国家 | 否 | 适用市场/法规 |
| 备注 | 否 | ≤256 字 |

3. 点「确定」保存。

### 1.3 编辑 / 删除
- 编辑：点行内「编辑」修改后保存。
- 删除：点「删除」确认；**若项目下存在产品则禁止删除**（提示存在关联产品）。

### 1.4 边界测试
| 场景 | 预期 |
|------|------|
| 项目名称重复 | 提示「数据已存在」 |
| 删除含产品的项目 | 阻止并提示 |
| 名称留空 | 校验拦截 |

---

## 2. 产品管理（菜单：系统配置 → 产品）

### 2.1 适用范围
维护产品及其版本，是 SRS/SDS/风险/测试/图表等所有业务数据的归属主体。

### 2.2 新建产品
1. 点「新建」。
2. 填写字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 所属项目 | 否* | 关联项目 |
| 产品名称 | 是 | 与完整版本联合唯一 |
| 类别 | 否 | |
| 型号(type_code) | 否 | |
| 完整版本(full_version) | 是 | 与名称联合唯一 |
| 发布版本(release_version) | 是 | 非空 |
| UDI | 否 | |
| 产品代码 | 否 | |
| 适用范围(scope) | 否 | 长文本 |
| 产品组成(component) | 否 | 长文本 |
| 备注 | 否 | 长文本 |
| 关联用户(user_ids) | 否 | 产品成员（决定非管理员可见性） |

3. 保存。

### 2.3 关键规则
- **产品经理**新建产品时，系统强制将该产品成员设为本人；产品经理只能编辑本人创建的产品（改他人产品提示「您没有权限执行此操作」）。
- 未指定关联用户时，默认把当前操作人加入产品成员。

### 2.4 编辑 / 删除
- 编辑：可改上述字段；`关联用户`若提交则**整体重建**成员关系。
- 删除：以下任一存在时**禁止删除**——SRS 文档、测试集、产品 DHF、图表文件。

### 2.5 导出
- 「导出」按当前筛选导出产品列表 Excel（含名称、国家、类别、型号、版本、UDI、产品代码、范围、组成、备注、创建时间）。

### 2.6 边界测试
| 场景 | 预期 |
|------|------|
| 名称+完整版本重复 | 「数据已存在」 |
| 完整版本/发布版本留空 | 校验拦截 |
| 删除已建 SRS/测试集/DHF/图表的产品 | 阻止并提示对应关联 |
| 产品经理编辑他人产品 | 「无权限」 |
| 非管理员查看产品列表 | 仅显示本人创建或被分配的产品 |

## 3. 用户管理（菜单：系统配置 → 用户）

### 3.1 适用范围
具备 `user_edit` 的管理员维护登录账号。

### 3.2 列表与筛选
- 筛选：账号(name)、姓名(nick_name)、角色。
- 列：账号、姓名、角色名称、创建时间、操作。

### 3.3 新建用户
1. 点「新建」。
2. 填写：

| 字段 | 必填 | 说明 |
|------|------|------|
| 账号(name) | 是 | 全局唯一登录名 |
| 姓名(nick_name) | 否 | |
| 角色(role_code) | 否 | 决定权限 |

3. 保存。**初始密码为系统默认值**（环境配置），首次登录后请改密码。

### 3.4 编辑 / 重置密码 / 删除
- 编辑：可改姓名、角色等；**不修改账号名**。
- 重置密码：点「重置密码」→ 恢复为默认密码；**不能重置管理员账号**（提示）。
- 删除：**不能删除自己**（提示「不能删除自己」）。

### 3.5 边界测试
| 场景 | 预期 |
|------|------|
| 账号重复 | 「用户名重复」 |
| 删除当前登录用户 | 阻止并提示 |
| 重置管理员密码 | 阻止并提示 |
| 修改密码两次不一致 | 阻止 |

---

## 4. 角色与权限（菜单：系统配置 → 角色）

### 4.1 适用范围
具备 `role_edit` 者维护自定义角色及其权限。

### 4.2 新建角色
1. 点「新建」。
2. 填写角色名称（唯一），在**权限树**中勾选权限项。
3. 保存（角色编码由系统自动生成）。

### 4.3 编辑 / 删除
- 编辑：调整勾选的权限；保存后该角色用户立即生效（下次鉴权）。
- 固定角色：**不可改名**，权限 = 基线权限 ∪ 勾选项。
- 删除：固定角色不可删除；**被用户引用的角色不可删除**（提示「角色被引用」）。

### 4.4 列表信息
- 列表显示每个角色的关联用户数(user_count)、创建时间。
- 角色详情含权限树、系统全部权限、固定基线权限。

### 4.5 边界测试
| 场景 | 预期 |
|------|------|
| 角色名重复 | 「角色名重复」 |
| 删除固定角色 | 阻止 |
| 删除有用户使用的角色 | 阻止并提示 |
| 改固定角色名称 | 不允许 |
