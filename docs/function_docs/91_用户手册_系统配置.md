# 用户操作说明书（二）系统配置：用户 / 角色 / 项目 / 产品

> 适用范围：系统管理员、具备相应 `*_edit` 权限的人员。前置：已登录。

---

## 1. 项目管理（菜单：系统配置 → 项目）

### 1.1 适用范围
管理产品所属的项目分组（如按法规市场 FDA/NMPA/PMDA/CE/MDR 划分）。

### 1.2 新建产品线（项目）
1. 在「系统配置 → 项目」列表页，点击右上角「新增」按钮，弹出“新增”对话框。
2. 填写字段（必填项留空点「确定」时，会在该字段下方出现红色提示“请输入{字段名}”，无法提交）：
   - 产品线名称（必填）：产品线/项目名称。
   - 注册国家（必填）：下拉选择，可选 FDA、NMPA、PMDA、CE、MDR。
   - 备注（选填）：备注信息。
3. 点对话框底部「确定」提交：
   - 保存成功：系统提示“请求处理成功!”，对话框自动关闭，列表刷新并显示新建的产品线。
   - 若“产品线名称 + 注册国家”与已有记录重复：提示“数据已存在！”，请修改后重试。

### 1.3 编辑 / 删除
- 编辑：在表格“操作”列点行内「编辑」，在弹出的“编辑”对话框修改后点「确定」保存（成功提示“请求处理成功!”）。
- 删除：点行内「删除」，弹出确认框（标题“操作”，正文“确认要删除吗？”），点「确定」执行。
   - 若该产品线下已存在产品：提示“项目下有产品，不能删除！”，无法删除。
- 批量删除：勾选多行后点右上角「批量删除」（未勾选时按钮不可用，误点提示“请先选择要删除的项”）；确认框正文为“确认要删除选中的 N 项吗？”，确认后执行，全部成功提示“批量删除成功”。

### 1.4 边界测试
| 场景 | 预期 |
|------|------|
| 名称+注册国家重复 | 提示“数据已存在！” |
| 删除已含产品的产品线 | 阻止并提示“项目下有产品，不能删除！” |
| 必填项留空 | 红色校验提示，无法提交 |

## 2. 产品管理（菜单：系统配置 → 产品）

### 2.1 适用范围
维护产品及其版本，是 SRS/SDS/风险/测试/图表等所有业务数据的归属主体。

### 2.2 新建产品
1. 在「系统配置 → 产品」列表页，点击右上角蓝色「新增」按钮，弹出“新增”对话框。
2. 在对话框中填写以下字段（标注“必填”的项若留空，点「确定」时会在该字段下方出现红色提示“请输入{字段名}”，无法提交）：
   - 产品名称（必填）：产品名称，与“完整版本”组合后必须唯一。
   - 所属项目（必填）：下拉选择已建好的项目（选项显示为“项目名（国家）”）。
   - 类别（必填）：产品类别，手工输入。
   - 型号（选填）：产品型号。
   - 完整版本（必填）：完整版本号，与“产品名称”组合后必须唯一。
   - 发布版本（必填）：对外发布的版本号，不能为空。
   - UDI（必填）：唯一器械标识。
   - 产品代码（选填）：产品代码。
   - 适用范围（必填）：多行文本，描述产品的适用范围。
   - 产品组成（必填）：多行文本，描述产品的组成。
   - 备注（选填）：多行文本备注。
3. 填写完成后，点击对话框底部「确定」提交：
   - 保存成功：系统提示“请求处理成功!”，对话框自动关闭，产品列表刷新并显示刚新建的产品。
   - 若“产品名称”+“完整版本”与已有产品重复：提示“数据已存在！”，请修改后重试。
   - 若当前为产品经理账号：系统会自动把本人设为该产品的成员（之后只能编辑本人创建的产品）。

### 2.3 关键规则
- **产品经理**新建产品时，系统强制将该产品成员设为本人；产品经理只能编辑本人创建的产品（改他人产品提示「您没有权限执行此操作」）。
- 未指定关联用户时，默认把当前操作人加入产品成员。

### 2.4 编辑 / 删除
- 编辑：可改上述字段；`关联用户`若提交则**整体重建**成员关系。
- 删除：以下任一存在时**禁止删除**——SRS 文档、测试集、产品 DHF、图表文件。

### 2.5 导出
- 「导出」按当前筛选导出产品列表 Excel（含名称、国家、类别、型号、版本、UDI、产品代码、范围、组成、备注、创建时间）。

### 2.6 边界测试
| 场景 | 预期 |
|------|------|
| 名称+完整版本重复 | 「数据已存在」 |
| 完整版本/发布版本留空 | 校验拦截 |
| 删除已建 SRS/测试集/DHF/图表的产品 | 阻止并提示对应关联 |
| 产品经理编辑他人产品 | 「无权限」 |
| 非管理员查看产品列表 | 仅显示本人创建或被分配的产品 |

## 3. 用户管理（菜单：系统配置 → 用户）

### 3.1 适用范围
具备 `user_edit` 的管理员维护登录账号。

### 3.2 列表与筛选
- 筛选：账号(name)、姓名(nick_name)、角色。
- 列：账号、姓名、角色名称、创建时间、操作。

### 3.3 新建用户
1. 在「系统配置 → 用户」列表页，点击右上角「新增」按钮，弹出“新增”对话框。
2. 填写字段（必填项留空点「确定」会红色提示“请输入/请选择{字段名}”）：
   - 账号（必填）：登录账号，全局唯一。
   - 姓名（必填）：用户姓名。
   - 角色（必填）：下拉选择角色，决定该用户的权限。
   - 权限预览（只读）：选择角色后自动展示该角色可见的功能模块，无权限时显示“-”。
3. 点对话框底部「确定」提交：
   - 保存成功：系统提示“请求处理成功!”，对话框关闭，列表刷新。新用户初始密码为系统默认值（由环境配置，界面不展示），首次登录后请尽快修改密码。
   - 账号重复：提示“用户已存在！”，请更换账号。

### 3.4 编辑 / 重置密码 / 删除
- 编辑：点行内「编辑」，对话框中“账号”不可修改（输入框禁用），可改姓名、角色；内置管理员账号 master 的“角色”不可修改（下拉禁用）。保存成功提示“请求处理成功!”。
- 重置密码：点行内「重置密码」，确认框正文“确认要重置密码吗？”，确认后该用户密码恢复为系统默认值（提示“请求处理成功!”）。内置管理员 master 的“重置密码”按钮禁用；对管理员账号重置会提示“不能重置管理员密码！”。
- 删除：点行内「删除」，确认框正文“确认要删除吗？”，确认后删除。不能删除当前登录的自己（提示“不能删除自己！”）；内置管理员 master 行的“删除”按钮禁用。
- 批量删除：勾选多行后点右上角「批量删除」（master 无法被勾选）；确认框正文“确认要删除选中的 N 项吗？”，全部成功提示“批量删除成功”。

### 3.5 边界测试
| 场景 | 预期 |
|------|------|
| 账号重复 | “用户已存在！” |
| 删除当前登录用户 | 阻止并提示“不能删除自己！” |
| 重置管理员密码 | 阻止并提示“不能重置管理员密码！” |
| 修改密码两次不一致 | 阻止并提示“两次新密码不一致” |

## 4. 角色与权限（菜单：系统配置 → 角色）

### 4.1 适用范围
具备 `role_edit` 者维护自定义角色及其权限。

### 4.2 查看与配置角色权限
> 说明：角色页当前**没有“新增”入口**，使用的是系统预置的 7 个固定角色（root 超级管理员、dqa、qa、ra、产品经理、开发、测试）。日常主要是查看与调整各角色的权限范围。

1. 在「系统配置 → 角色」列表页，可查看各角色的名称、创建时间、关联用户数；右上角有「刷新」按钮可刷新列表。
2. 点行内「权限范围」，弹出“编辑”对话框：
   - 角色名称：固定角色名称不可修改（输入框禁用）。
   - 角色权限：通过“全选”复选框或各功能模块卡片勾选该角色可见的导航模块（仅控制导航模块范围，不细分“查看/编辑”等子权限）；超级管理员 root 的权限固定为全部、不可更改（复选框禁用）。
3. 点对话框底部「确定」保存：
   - 未勾选任何权限：提示“请选择角色权限！”，不会提交。
   - 保存成功：提示“请求处理成功!”，对话框关闭，列表刷新；该角色下的用户在下次鉴权时生效。

### 4.3 删除角色
- 勾选要删除的自定义角色后，点右上角「删除」（超级管理员 root 不可勾选、会被自动排除；未选到可删项时提示“请先选择要删除的项”）。
- 确认框正文“确认要删除选中的 N 项吗？”，确认后执行，全部成功提示“批量删除成功”。
- 限制：系统固定角色不允许删除（提示“固定角色不允许删除”）；仍有关联用户的角色不能删除（提示“角色正在被使用，不能删除！”）。

### 4.4 列表信息
- 列表显示每个角色的名称、创建时间、关联用户数。
- 通过「权限范围」可查看/编辑该角色已勾选的导航模块权限范围。

### 4.5 边界测试
| 场景 | 预期 |
|------|------|
| 删除固定角色 | 阻止并提示“固定角色不允许删除” |
| 删除有用户使用的角色 | 阻止并提示“角色正在被使用，不能删除！” |
| 改固定角色名称 | 不允许（名称输入框禁用） |

## 5. 公司信息管理（菜单：通用配置 → 公司基本信息）

### 5.1 适用范围
管理公司基本信息，供各文档导出时自动填充封面/页眉信息。

### 5.2 列表与操作
- 列：注册人、住所、受托生产企业、生产地址、生产许可证编号、联系电话、代表人/职位、创建时间、操作（编辑/删除）。
- 支持模糊搜索。

### 5.3 新建 / 编辑
| 字段 | 必填 | 说明 |
|------|------|------|
| 注册人 | 是 | 公司注册人名称 |
| 住所 | 是 | 公司注册地址 |
| 受托生产企业 | 否 | 受托生产企业名称 |
| 生产地址 | 否 | 生产地址 |
| 生产许可证编号 | 否 | 生产许可证编号 |
| 联系电话 | 否 | 联系电话 |
| 代表人 | 否 | 法定代表人 |
| 职位 | 否 | 代表人职位 |

### 5.4 边界测试
| 场景 | 预期 |
|------|------|
| 注册人/住所留空 | 红色校验提示，无法提交 |
| 删除被引用的公司信息 | 直接删除（无级联校验） |

## 6. 人员签名管理（菜单：通用配置 → 人员签名管理）

### 6.1 适用范围
管理人员签名与预留印鉴，供各文档导出时自动注入签名/印章图片。

### 6.2 列表与操作
- 列：姓名、职务、印鉴（图片预览）、签字（图片预览）、状态、排序、操作（编辑/删除）。
- 支持模糊搜索。

### 6.3 新建 / 编辑
| 字段 | 必填 | 说明 |
|------|------|------|
| 姓名 | 是 | 人员姓名 |
| 职务 | 是 | 人员职务 |
| 印鉴 | 否 | 上传印鉴图片（仅 .png/.jpg/.jpeg） |
| 签字 | 否 | 上传签字图片（仅 .png/.jpg/.jpeg） |
| 状态 | 否 | 启用/禁用 |
| 排序 | 否 | 数字，越小越靠前 |

### 6.4 操作说明
- 图片上传后以 base64 格式存储，表格内直接预览缩略图。
- 导出文档时按排序顺序取用签名/印章。

### 6.5 边界测试
| 场景 | 预期 |
|------|------|
| 姓名/职务留空 | 红色校验提示，无法提交 |
| 上传非图片文件 | 不允许选择 |
| 删除已使用的签名 | 直接删除（导出时不再包含） |

## 7. 版本命名规则（菜单：通用配置 → 版本命名规则）

### 7.1 适用范围
全局单条配置，定义产品的版本命名规则。所有产品共享同一套规则。

### 7.2 操作步骤
1. 进入「通用配置 → 版本命名规则」。
2. 页面居中卡片展示当前版本命名规则文字内容。
3. 点击文字内容直接进入编辑态，修改后失焦自动保存。
4. 下方示意图固定展示，不可编辑。

### 7.3 字段说明
| 字段 | 说明 |
|------|------|
| 版本命名规则 | 多行文本，描述版本号的命名规范（如 X.Y.Z 格式说明） |

### 7.4 边界测试
| 场景 | 预期 |
|------|------|
| 内容为空保存 | 保存空内容 |
| 多人同时编辑 | 后保存者覆盖前者 |

## 8. 打印服务配置（菜单：通用配置 → 打印服务配置）

### 8.1 适用范围
管理打印机配置，支持多台打印机，配置 IPP/TCP9100 协议，支持测试连接和一键打印。

### 8.2 列表与操作
- 列：打印机名称、主机、端口、协议、是否默认、备注、操作（编辑/删除）。
- 支持设置默认打印机。

### 8.3 新建 / 编辑
| 字段 | 必填 | 说明 |
|------|------|------|
| 打印机名称 | 是 | 打印机名称 |
| 主机 | 是 | 打印机 IP 地址或主机名 |
| 端口 | 是 | 端口号（如 9100、631） |
| 协议 | 是 | 下拉选择：IPP / TCP9100 |
| 打印机 URI | 否 | IPP 协议时填写完整 URI |
| 备注 | 否 | 备注信息 |

### 8.4 操作说明
- **测试连接**：点行内「测试连接」，系统生成 PostScript 测试页发送到打印机，成功提示连接正常。
- **设置默认**：点行内「设为默认」，该打印机成为一键打印的目标打印机（全局唯一默认）。
- 一键打印功能在「全局视图 → 一键打印」中调用。

### 8.5 边界测试
| 场景 | 预期 |
|------|------|
| 主机/端口/名称留空 | 红色校验提示，无法提交 |
| 测试连接失败 | 提示连接失败信息 |
| 设置多个默认 | 新默认覆盖旧默认 |
