# 验收文档管理（ACC）

## 1. 功能概述

管理产品验收记录文档（产品文件），记录验收基本信息、验收内容、验收结论。支持按产品自动获取验收信息（只读），导出为 docx 格式。

---

## 2. 用户操作流程

列表页按产品+版本搜索 → 新增/编辑 → 章节树编辑器编辑内容 → `acc_info` 章节自动获取（只读）→ 导出 docx。

---

## 3. 前端实现

- 页面：`pages/acc/AccDocs.tsx`（列表）、`AccDocDetail.tsx`（详情/编辑）
- API：`api/ApiAccDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_acc_doc` | `acc_doc_edit` |
| GET | `/duplicate_acc_doc` | `acc_doc_edit` |
| POST | `/update_acc_doc` | `acc_doc_edit` |
| DELETE | `/delete_acc_doc` | `acc_doc_edit` |
| GET | `/list_acc_doc` | `acc_doc_view` |
| GET | `/get_acc_doc` | `acc_doc_view` |
| GET | `/acc_autofill` | `acc_doc_view` |
| GET | `/export_acc_doc` | `acc_doc_view` |

---

## 5. 数据库表

`acc_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 章节树结构存储于 content(JSON)，`ref_type` 标记自动获取章节（只读不可编辑）。
2. 导出时通过 `acc_autofill` 注入产品数据。
3. 支持复制（duplicate）生成新文档。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. `ref_type` 标记的自动获取章节不可编辑。
2. content(JSON) 结构需与章节树编辑器兼容。
