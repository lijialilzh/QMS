# 产品管理

## 1. 功能概述

产品是系统核心实体，SRS/SDS/测试集/图表/DHF/风险均挂在产品下。提供产品 CRUD、导出、数据可见范围控制与追溯查询。

---

## 2. 用户操作流程

模糊搜索 → 列表 → 新增/编辑（项目、类别、型号、版本、UDI、范围、组成等）→ 删除/批量删除 → 导出列表 Excel。

---

## 3. 前端实现

- 页面：`pages/product/Products.tsx`
- API：`api/ApiProduct.ts`；编辑时 `ApiProject.list_project`

---

## 4. 后端接口

| 方法 | 路径 | 权限 | 入参 |
|------|------|------|------|

---

## 5. 数据库表

- `product`：project_id, name, category, type_code, full_version, release_version(必填), udi, product_code, scope, component, note, create_user_id；**唯一 (name, full_version)**
- `prod_user`：user_id, product_id（多对多，唯一对）

---

## 6. 关键业务逻辑与规则

### 6.1 数据可见范围（重要）
- `user.id == 1`：全部产品。
- `product_manager`：仅 `create_user_id == 自己`。
- 其他用户：`prod_user` 关联 或 `create_user_id`（兼容历史数据）。

### 6.2 新增
- `user_ids` 默认 `[op_user.id]`；产品经理强制仅自己。

### 6.3 删除阻断
- 存在 SrsDoc / TestSet / ProdDhf / DocFile 时禁止删除。

### 6.4 追溯
- `with_trace=1`：join SdsDoc ↔ SrsDoc 得 `traces`、`srs_versions`、`sds_versions`。

### 6.5 产品-文档关系（核心）
- 产品 1:N **SRS 文档**（`srs_doc.product_id`）。
- SDS 经 `srsdoc_id` 挂 SRS：追溯链 **产品 → SRS 版本 ↔ SDS 版本**。
- 测试集、图表文件、DHF 均挂 `product_id`。
- 版本管理 DHF 联动复制 SRS 时，排除 `version` 为 `__deleted_srs__` 前缀的软删记录；编号对不上时回退到该模块未删除文档中的最新一条。

---

## 7. 边界与特殊处理

- `list_product` 允许 srs/sds view 访问，供需求/设计模块的产品下拉框使用。
- `(name, full_version)` 唯一，重复新增会失败。

---

## 8. 修改注意事项 / 不可破坏的核心逻辑

1. **数据可见范围三分支（id==1 / product_manager / prod_user）** 是安全边界，不可简化或绕过。
2. **删除阻断校验**（存在下游文档/测试集/DHF/图表）不可移除。
3. `(name, full_version)` 唯一约束是版本管理基础。
4. 产品-文档逻辑关系（product_id / srsdoc_id）贯穿全系统追溯，不可改动字段语义。
