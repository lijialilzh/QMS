# 产品管理

## 1. 功能概述

产品是系统核心实体，SRS/SDS/测试集/图表/DHF/风险均挂在产品下。提供产品 CRUD、导出、数据可见范围控制与追溯查询。合规医院列表为全局基础数据（所有产品共用），见 [102_合规医院列表.md](./102_合规医院列表.md)。

---

## 2. 用户操作流程

模糊搜索 → 列表 → 新增/编辑（项目、类别、型号、版本、UDI、范围、组成、注册人、设计开发地址等）→ 删除/批量删除 → 导出列表 Excel。列表操作列同时显示「编辑 / 复制 / 删除」，不被列宽裁切。

---

## 3. 前端实现

- 页面：`pages/product/Products.tsx`；产品可见范围：`pages/syscfg/SrsViewers.tsx`

## 5. 数据库表

- `product`：project_id, name, category, type_code, full_version, release_version(必填), udi, product_code, registrant, design_address, scope, component, note, create_user_id；**唯一 (name, full_version)**
- `prod_user`：user_id, product_id（多对多，唯一对）

---

## 6. 关键业务逻辑与规则

### 6.1 数据可见范围（重要）
- 超级管理员（`user.id == 1` 或 `root`）与 DQA：全部产品。
- 除超级管理员与 DQA 外：产品列表、产品图示，以及各模块文件列表，都只显示产品可见范围勾选的产品。产品经理另外始终可见自己添加的产品。只能看到某个产品时，只能看到该产品下的文件。

### 6.2 新增
- `user_ids` 默认 `[op_user.id]`；产品经理强制仅自己。
- 新增/编辑可维护「注册人」（选自公司信息）和「设计开发地址」。复制产品时一并带出。

### 6.3 删除阻断
- 存在 SrsDoc / TestSet / ProdDhf / DocFile 时禁止删除。

### 6.4 追溯
- `with_trace=1`：join SdsDoc ↔ SrsDoc 得 `traces`、`srs_versions`、`sds_versions`。

### 6.5 产品-文档关系（核心）
- 产品 1:N **SRS 文档**（`srs_doc.product_id`）。
- SDS 经 `srsdoc_id` 挂 SRS：追溯链 **产品 → SRS 版本 ↔ SDS 版本**。
- 测试集、图表文件、DHF 均挂 `product_id`。
- 版本管理 DHF 联动复制 SRS 时，排除 `version` 为 `__deleted_srs__` 前缀的软删记录；编号对不上时回退到该模块未删除文档中的最新一条。

### 6.6 新增、修改、删除的角色
- 时间逻辑线、DHF、运行环境、设备资源、参与人员：仅超级管理员（`root` 或用户 id 为 1）与 DQA。
- 算法模块管理（导航模块与章节模块）：超级管理员、DQA、模型人员、数据人员。
- 版本管理（产品新增、修改、删除、复制）：超级管理员、DQA、产品经理。
- 产品风险管理中的 RCM、HAZ：超级管理员、DQA、产品经理。
- 产品风险管理中的 THREAT：超级管理员、DQA。
- 以上限制只针对新增、修改、删除、复制、导入。查看和导出不按这组角色收紧。QA 即使持有编辑权限码也不能写这些数据。

### 6.7 产品可见范围
- 配置挂在产品上、按人勾选，复用 `prod_user`，不新增权限码、不按每份 SRS 勾人。
- 超级管理员与 DQA 可配置，且自己看 SRS 默认全部可见（与 master 同权限）。QA/RA/开发/测试等按勾选范围。
- 产品管理、产品图示和各文件列表与产品可见范围同一口径：除超级管理员与 DQA 外，只看勾选的产品。产品经理再加自己添加的产品；配置页点开产品经理账号时，这些产品默认勾选且不能取消。其他账号不受此限制，可以取消自己添加的产品。

---

## 7. 边界与特殊处理

- `list_product` 允许 srs/sds view 访问，供需求/设计模块的产品下拉框使用。
- `(name, full_version)` 唯一，重复新增会失败。

---

## 8. 修改注意事项 / 不可破坏的核心逻辑

1. **数据可见范围**按产品可见范围控制。除超级管理员与 DQA 外，产品列表、产品图示和各文件列表只含勾选产品（`prod_user`）。产品经理额外包含本人创建，且保存时不能去掉这些产品。超级管理员与 DQA 看全部。
2. **删除阻断校验**（存在下游文档/测试集/DHF/图表）不可移除。
3. `(name, full_version)` 唯一约束是版本管理基础。
4. 产品-文档逻辑关系（product_id / srsdoc_id）贯穿全系统追溯，不可改动字段语义。
