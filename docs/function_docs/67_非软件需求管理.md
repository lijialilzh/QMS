# 非软件需求管理（NSR）

## 1. 功能概述

管理自研软件网络安全研究报告（产品文件），包含封面/各章节文本/表格/图片，支持自动获取产品数据注入。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/nsr/NsrDocs.tsx`（列表）、`NsrDocDetail.tsx`（详情/编辑）
- API：`api/ApiNsrDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_nsr_doc` | `nsr_doc_edit` |
| GET | `/duplicate_nsr_doc` | `nsr_doc_edit` |
| POST | `/update_nsr_doc` | `nsr_doc_edit` |
| DELETE | `/delete_nsr_doc` | `nsr_doc_edit` |
| GET | `/list_nsr_doc` | `nsr_doc_view` |
| GET | `/get_nsr_doc` | `nsr_doc_view` |
| GET | `/nsr_autofill` | `nsr_doc_view` |
| GET | `/export_nsr_doc` | `nsr_doc_view` |

---

## 5. 数据库表

`nsr_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与网络安全管理（47）不同，NSR 是网络安全研究报告文档。
2. 自动获取产品信息注入封面/修订记录。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 自动获取章节不可编辑。
