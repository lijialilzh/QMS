# 非软件需求管理（NSR）

## 1. 功能概述

管理自研软件网络安全研究报告（产品文件），包含封面/各章节文本/表格/图片，支持自动获取产品数据注入。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/nsr/NsrDocs.tsx`（列表）、`NsrDocDetail.tsx`（详情/编辑）
- API：`api/ApiNsrDoc.ts`

## 5. 数据库表

`nsr_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与网络安全管理（47）不同，NSR 是网络安全研究报告文档。
2. 自动获取产品信息注入封面/修订记录。
3. 附录 A、附录 C、风险矩阵取 HAZ：产品 HAZ 分类含「网络安全」或英文「Cybersecurity」（不区分大小写）的记录都纳入。附录 C 再按其关联 RCM 筛选可追溯性分析行。
4. 1.1 软件信息：产品名称、产品型号、软件发布版本、软件完整版本按产品自动获取且只读。软件安全性级别、网络安全性级别不自动获取，可在章节内手改并保存，再次打开时保留手改值。切换产品会按新产品重新取全文，这两项回到模板默认值。
5. 1.3 网络安全能力表：空白的「进一步风险分析编号」按同一行「判断依据」匹配当前产品全部 HAZ。判断依据按换行和逗号、句号拆句，某一句出现在该 HAZ 的事件或情况中即命中，多个编号换行写入。该行为「否」且对不上时，空格子写「无」。已有编号不覆盖，格子仍可手改。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 自动获取章节不可编辑。例外：1.1 软件信息中的软件安全性级别、网络安全性级别可手改。
