# 软件测试计划管理（STP）

## 1. 功能概述

管理软件测试计划（测试文件），PDP 风格章节树结构。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/stp/StpDocs.tsx`（列表）、`StpDocDetail.tsx`（详情/编辑）
- API：`api/ApiStpDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_stp_doc` | `stp_doc_edit` |
| GET | `/duplicate_stp_doc` | `stp_doc_edit` |
| POST | `/update_stp_doc` | `stp_doc_edit` |
| GET | `/rebind_product` | `stp_doc_edit` |
| DELETE | `/delete_stp_doc` | `stp_doc_edit` |
| GET | `/list_stp_doc` | `stp_doc_view` |
| GET | `/get_stp_doc` | `stp_doc_view` |
| GET | `/export_stp_doc` | `stp_doc_view` |

---

## 5. 数据库表

`stp_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. PDP 风格章节树结构。
2. 与 STR（软件测试报告）不同，STP 是测试计划阶段文档。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
