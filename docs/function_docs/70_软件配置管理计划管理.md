# 软件配置管理计划管理（SCM）

## 1. 功能概述

管理软件配置管理计划（开发文件），PDP 风格章节树结构。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/scm/ScmDocs.tsx`（列表）、`ScmDocDetail.tsx`（详情/编辑）
- API：`api/ApiScmDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_scm_doc` | `scm_doc_edit` |
| GET | `/duplicate_scm_doc` | `scm_doc_edit` |
| POST | `/update_scm_doc` | `scm_doc_edit` |
| DELETE | `/delete_scm_doc` | `scm_doc_edit` |
| GET | `/list_scm_doc` | `scm_doc_view` |
| GET | `/get_scm_doc` | `scm_doc_view` |
| GET | `/export_scm_doc` | `scm_doc_view` |

---

## 5. 数据库表

`scm_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. PDP 风格章节树结构，参考产品开发计划（52）。
2. 支持复制（duplicate）生成新文档。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
