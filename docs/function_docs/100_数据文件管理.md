# 1. 功能概述

- **用途**：按「产品 + 文档类型 + 文档版本」维护数据侧 Word/Excel，交互与模型文件相同。
- **使用场景**：菜单「数据文件 → {类型名}」建档、改章节树、导出。
- **最终目标**：`(product_id, doc_type, version)` 唯一；封面空的编制部门为「数据部」；产品信息仅填空、不回写产品主数据。
- **导出格式**：`docx` 走封面→修订→目录→正文；`xlsx` 每章节一张工作表。
- **关联**：引擎与规则对齐 [99_模型文件管理.md](./99_模型文件管理.md)；权限 `data_doc_view` / `data_doc_edit`。

Word：`dd_001` 数据采集需求、`dd_006` 数据标注质量评估方法、`dd_007` 人员考核评价方法、`dd_016` 开发环境维护记录说明、`dd_017` 标注环境维护记录说明。

Excel：`dd_002` 多中心数据回传记录、`dd_003` 数据整理记录、`dd_004` 数据采集需求反馈、`dd_005_01`/`dd_005_02` 人员培训记录、`dd_008_01`/`dd_008_02` 试标注记录、`dd_009_01`/`dd_009_02`/`dd_009_03` 标注记录、`dd_010` 数据库上传记录、`dd_011` 数据标注需求反馈、`dd_012` 训练集测试集查重记录、`dd_013_01`～`dd_013_07` 人员考核评价记录、`dd_014` 数据库维护记录、`dd_015_01`～`dd_015_03` 数据库统计表、`dd_016_qr` 开发环境维护记录、`dd_017_qr` 标注环境维护记录、`dd_eq` 数据设备清单。

大表（标注明细等）只预填表头与少量空行。数据库统计表数字由独立模块「数据统计」生成，见 [101_数据统计.md](./101_数据统计.md)；下载的 Excel 可在 `dd_015_*` 编辑页导入展示。封面/修订/产品信息仍按第 4 节填空，不从统计模块取。离线脚本 `trace-api/scripts/data_stats/` 仅作备用。

| 组件 / 文件 | 作用 |
|------------|------|
| `pages/model_doc/DataDocs.tsx` | 列表（克隆模型文件列表） |
| `pages/model_doc/DataDocDetail.tsx` | 详情（克隆模型文件编辑页） |

## 2.3 涉及接口

前缀 `/trace-api/data_doc`，方法与模型文件同名替换 `model`→`data`。权限 `data_doc_edit` / `data_doc_view`。另：`POST /import_stats_excel` 上传统计脚本 xlsx，解析为章节树返回，不落库（需 `data_doc_edit`）。

## 2.4 状态仓库 / 公共方法

同 99：`serv_review_util`、`docx_util`、`ProductVersionSelect`。封面部门规则 `DOC_DEPT[dd_*]=data`。

统计操作入口见 [101_数据统计.md](./101_数据统计.md)（菜单「数据统计」，浏览器本地计算）。备用离线脚本（全产品，不写死路径）：

| 脚本 | 作用 |
|------|------|
| `scripts/data_stats/data_statistics_multi.py` | `--input` 病例 DICOM 目录 → 病例分布 xlsx |
| `scripts/data_stats/summarize_db_stats.py` | 分布 xlsx → 因素/类别/序列数/占比 |
| `scripts/data_stats/triage_subgroup.py` | 分布 xlsx（可含 gt/pred/dice）→ 亚组统计 xlsx |

编辑页「导入统计 Excel」只替换非封面/修订/产品信息章节，点保存才落库。

# 3. 完整执行流程（分步细化）

## 3.0 触发入口

菜单「数据文件 → {类型名}」进入 `/data_docs/{doc_type}`。

## 3.1～3.6

与 99 相同：列表 / 新增 / 编辑查看 / 导出 / 复制 / 删除。接口与表名为 `data_doc`。导出按类型 format 输出 docx 或 xlsx。`dd_015_*` 可导入统计脚本 Excel 替换记录章节。

成功终态：`data_doc` 落库一行；导出不落库。

# 4. 核心规则 & 判定条件

| 编号 | 规则 / 判定条件 | 含义 | 不满足 / 命中时的后果 |
|------|----------------|------|----------------------|
| R1 | `(product_id, doc_type, version)` 唯一 | 同产品同类型不重复版本 | `msg_obj_exist` |
| R2 | 写 `data_doc_edit`，读 `data_doc_view` | 权限 | 无权限拦截，菜单不可见 |
| R3 | `product_manager` 非超管 | 只看自己创建的产品 | 其它产品不出现 |
| R4 | 自动获取仅填空 | 保护手改 | 已填保留 |
| R5 | 不回写产品主数据 | 只读来源 | 不影响 `product` |
| R6 | 封面编制部门空则「数据部」 | 与模型文件「模型部」区分 | 用户已填则保留 |
| R7 | 更新忽略 `doc_type` | 类型由菜单锁定 | 不能改类型 |
| R9 | 导入统计 Excel 只替换记录章节 | 保护封面/修订/产品信息 | 封面三块保留，其余按工作表重建 |

产品信息、修订首行、文件编号规则同 99（关键字取该类型名称）。

# 6. 异常场景 & 兜底逻辑

与 99 相同（版本重复、详情不存在、类型非法、自动获取源空、保存导出失败、无权限）。大表模板截断不影响已保存的用户数据。

# 7. 功能约束 & 修改红线

## 7.1 允许修改范围

- 本文与 `01` 的 `data_doc` 表；`data_doc` 模型/对象/服务/接口/模板；`scripts/data_stats/`；`serv_review_util` 的 `dd_*` 登记；前端 `DataDocs*`、`ApiDataDoc.ts`、`Home.tsx` 数据菜单、`index.tsx` 路由。数据统计独立页见 101。

## 7.2 绝对禁止改动（红线）

- 禁止改产品文件封面与模型文件已上线 Word 的导出结构。
- 禁止回写产品主数据；禁止改 `src/store/`、`src/common/`、`src/utils/base/`。
- 必须单表 `data_doc` + `doc_type`。
- 禁止自动获取覆盖已填。

## 7.3 禁止新增逻辑

- 不得新增本文未列出的 `doc_type`。
- 文档集成导出收录不在本文范围。

## 7.4 禁止重构结构

- 不得整文件重写立项报告、不得为赶工改模型 Word 已测接口签名（仅允许给导出增加 xlsx 分支）。
