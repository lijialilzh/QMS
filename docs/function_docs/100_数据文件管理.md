# 1. 功能概述

- **用途**：按「产品 + 文档类型 + 文档版本」维护数据侧 Word/Excel，交互与模型文件相同。
- **使用场景**：菜单「数据文件」按样例文件夹 `数据/` 的 DD 编号排列；005 / 008 / 009 / 013 为二级分组，其余类型直接挂在「数据文件」下。进入后建档、改章节树、导出。名称与 `doc_type` 不改。
- **最终目标**：`(product_id, doc_type, version)` 唯一；封面空的编制部门为「数据部」；无独立「产品信息」章，不回写产品主数据。
- **导出格式**：`docx` 走封面→修订→目录→正文；`xlsx` 每章节一张工作表。
- **关联**：引擎与规则对齐 [99_模型文件管理.md](./99_模型文件管理.md)；权限 `data_doc_view` / `data_doc_edit`。

# 3. 完整执行流程（分步细化）

## 3.0 触发入口

菜单「数据文件 → {类型名}」或「数据文件 → {二级分组} → {类型名}」进入 `/data_docs/{doc_type}`。分组名与样例文件夹 `005-人员培训记录`、`008-数据试标注记录`、`009-数据标注记录`、`013-人员考核评价记录` 对应（不含编号前缀）。

## 3.1～3.6

与 99 相同：列表 / 新增 / 编辑查看 / 导出 / 复制 / 删除。接口与表名为 `data_doc`。导出按类型 format 输出 docx 或 xlsx。Word 评审表与 99 相同：相邻相同非空格先横向合并，纵向合并首列（该列已横向合并时仍合并）。`dd_015_*` 可导入统计脚本 Excel 替换记录章节。

成功终态：`data_doc` 落库一行；导出不落库。

# 4. 核心规则 & 判定条件

| 编号 | 规则 / 判定条件 | 含义 | 不满足 / 命中时的后果 |
|------|----------------|------|----------------------|
| R1 | `(product_id, doc_type, version)` 唯一 | 同产品同类型不重复版本 | `msg_obj_exist` |
| R2 | 写 `data_doc_edit`，读 `data_doc_view` | 权限 | 无权限拦截，菜单不可见 |
| R3 | `product_manager` 非超管 | 只看自己创建的产品 | 其它产品不出现 |
| R4 | 自动获取仅填空 | 保护手改 | 已填保留；打开或换产品时精确全文替换产品名称 / 型号 / 产品代码（规则同 99） |
| R5 | 不回写产品主数据 | 只读来源 | 不影响 `product` |
| R6 | 封面编制部门空则「数据部」 | 与模型文件「模型部」区分 | 用户已填则保留 |
| R7 | 更新忽略 `doc_type` | 类型由菜单锁定 | 不能改类型 |
| R9 | 导入统计 Excel 只替换记录章节 | 保护封面/修订 | 封面、修订保留，其余按工作表重建；不生成「产品信息」章 |
| R10 | 左侧菜单按 DD 编号归档；标注规则/标记规则/标注需求挂数据文件 | 与用户指定归档一致；005/008/009/013 二级分组 | 不改类型名；`md_002_*`/`md_003` 不出现在模型文件菜单 |

修订首行、文件编号规则同 99（关键字取该类型名称）。无独立「产品信息」章（打开/新增/导出去掉）。原 Word 有「附件 1 评审记录」表的类型（`dd_001`、`md_003`），附件为空则按原表补上；误挂在其它章节的评审表挪回附件。打开或换产品时，章节标题 / 正文 / 表格对产品名称、型号、产品代码做精确全文替换（模板基准名「肺栓塞CT图像辅助评估软件」、型号「IR-CT-PE」换成当前产品；换产品时再把原产品字段整段换成新产品）。签名图不替换。不按疾病词或模块名做模糊匹配。

# 7. 功能约束 & 修改红线

## 7.1 允许修改范围

- 本文与 `01` 的 `data_doc` 表；`data_doc` 模型/对象/服务/接口/模板；`scripts/data_stats/`；`serv_review_util` 的 `dd_*` 登记；前端 `DataDocs*`、`ApiDataDoc.ts`、`Home.tsx` 数据菜单、`index.tsx` 路由。数据统计独立页见 101。

## 7.2 绝对禁止改动（红线）

- 禁止改产品文件封面与模型文件已上线 Word 的导出结构。
- 禁止回写产品主数据；禁止改 `src/store/`、`src/common/`、`src/utils/base/`。
- 必须单表 `data_doc` + `doc_type`。
- 禁止自动获取覆盖已填。

## 7.3 禁止新增逻辑

- 不得新增本文未列出的 `doc_type`。
- 文档集成导出收录不在本文范围。

## 7.4 禁止重构结构

- 不得整文件重写立项报告、不得为赶工改模型 Word 已测接口签名（仅允许给导出增加 xlsx 分支）。

# 8. 验收标准

- [ ] 数据文件按编号归档；005/008/009/013 为二级菜单；数据标注规则 / 标记规则 / 数据标注需求在数据文件下，不在模型文件下。

- [ ] 封面空的编制部门为「数据部」；模型文件仍为「模型部」。
- [ ] 仅填空自动获取；不回写产品。
- [ ] 编辑页切换产品后，正文/标题/表格中原产品名称与型号整段换成新产品。
- [ ] Word 导出 docx，Excel 导出 xlsx。
- [ ] 复制递增版本；删除生效。
- [ ] 无 `data_doc_view` 看不到菜单。
- [ ] `dd_015_*` 可导入统计 Excel 展示；封面/修订不被导入覆盖；保存后落库。独立生成入口见 101。
