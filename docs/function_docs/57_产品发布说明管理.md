# 产品发布说明管理（Release Note）

## 1. 功能概述

管理产品发布说明（产品文件），章节树结构，记录每个版本的产品发布信息，包括新功能、修复的问题等。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/release_note/ReleaseNotes.tsx`（列表）、`ReleaseNoteDetail.tsx`（详情/编辑）
- API：`api/ApiReleaseNote.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_release_note` | `release_note_edit` |
| GET | `/duplicate_release_note` | `release_note_edit` |
| POST | `/update_release_note` | `release_note_edit` |
| DELETE | `/delete_release_note` | `release_note_edit` |
| GET | `/list_release_note` | `release_note_view` |
| GET | `/get_release_note` | `release_note_view` |
| GET | `/export_release_note` | `release_note_view` |

---

## 5. 数据库表

`release_note`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 章节树结构存储于 content(JSON)。
2. 与版本更新历史（54）不同，发布说明侧重发布内容而非版本历史记录。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
