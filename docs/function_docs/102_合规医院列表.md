## 1. 功能概述

维护**全局**合规医院清单：医院名称、区域划分、医院编号、省份、城市信息。所有产品共用同一份列表，按医院编号匹配 TXID。列与 `hospital_info.xls` 一致。

- 数据维度：全局（不按产品隔离）。表字段 `prod_id` 保留，新写入固定为 `0`。
- 菜单：「基础数据 → 合规医院列表」`/prod_hospitals`。
- 支持 Excel 导入（`.xls` / `.xlsx`，表头对齐 `hospital_info.xls`）；导入覆盖整份全局清单。不回写产品主数据。任意产品的 `dd_002` 打开/换产品/数据统计写入时只读本全局列表：按病例明细 TXID 查医院编号，命中的医院信息及数据量写入回传表（见 [100_数据文件管理.md](./100_数据文件管理.md) R20）。

## 2. 前置依赖 & 关联模块

- 不依赖产品下拉。
- 权限：读 `prod_hospital_view`，写 `prod_hospital_edit`。产品经理读写；开发/测试/RA 只看；root/DQA/QA 全权限。
- 【只读 / 禁止修改】：`/product/*` 产品模块、参与人员、时间逻辑线、运行环境、设备资源。数据文件仅 `dd_002` 只读本列表，不回写。

## 3. 完整执行流程（分步细化）

1. 进入页面 → `list_prod_hospital`（可不传 `prod_id`），按 `sort_order, id` 升序展示全部医院。
2. 全局尚无记录时，自动写入默认 8 家医院（`prod_id=0`），之后可手动增删改或导入覆盖；已有记录不重复写入。
3. 检索分栏：医院名称 / 医院编号为输入框（输入或回车筛选，只筛本列）；省份 / 城市为下拉，选项来自当前全局清单去重，选省份后城市仅列该省。多栏同时填为 AND。无圆形查询按钮。表单关闭浏览器自动填充。任一栏有值时不触发默认写入。
4. 点击「新增」→ `add_prod_hospital(prod_id=0, 空字段, sort_order=当前最大+1)`，再加载。
5. 点击「导入」→ 选择 `.xls` / `.xlsx` → 确认覆盖 → `import_prod_hospitals(prod_id=0, replace=true, file)`（覆盖整份全局清单）。
   - 表头行定位含「医院名称」「医院编号」的行（`hospital_info.xls` 第 2 行；第 1 行标题「客户信息」跳过）。
   - 列映射：医院名称→`org_name`，区域划分→`region`，医院编号→`hospital_no`，省份→`province`，城市信息→`city`；若有合同编号则写入 `contract_no`。
   - 医院名称与医院编号都空的行跳过；同一文件内医院编号重复只保留首次。
6. **点击单元格即可编辑、失焦实时保存**：
   - 医院名称 / 医院编号 / 省份 / 城市信息：`Input`，失焦或回车保存；
   - 区域划分：`AutoComplete`（东区 / 南区 / 西区 / 北区，可自定义），失焦保存；
   - 保存调用 `update_prod_hospital`，不改 `id` / `prod_id`。
7. 删除：行尾「删除」→ 确认 → `delete_prod_hospitals(id)` → 重新加载。

## 4. 核心规则 & 判定条件

| 编号 | 规则 / 判定条件 | 含义 | 不满足 / 命中时的后果 |
|------|----------------|------|----------------------|
| R1 | `add_prod_hospital`：`prod_id` 可空，空则写 `0` | 全局清单 | 不按产品隔离 |
| R2 | `update_prod_hospital` 不更新 `id` / `prod_id` | 不改归属 | 只改名称/编号/区域/省份/城市/合同编号/排序 |
| R3 | `delete_prod_hospitals` 逗号分隔 id | 物理删除 | 过滤非数字后批量删 |
| R4 | 列表按 `sort_order, id` 升序；不按 `prod_id` 过滤 | 全局查询 | 所有产品读同一份 |
| R5 | 空表才写默认 8 家 | 保护手改 / 导入结果 | 已有记录不重复写 |
| R6 | 写 `prod_hospital_edit`，读 `prod_hospital_view` | 权限 | 无权限拦截，菜单不可见 |
| R7 | `import_prod_hospitals`：`replace=true` 先清空全部再写入（`prod_id=0`） | 导入覆盖全局 | 无表头或文件无法解析返回参数错误 |

## 5. 数据结构说明

表 `prod_hospital`：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 主键 |
| prod_id | Integer NOT NULL, index | 保留字段；全局清单新写入为 `0` |
| contract_no | String(64) | 合同编号（导入有则写，列表不展示） |
| org_name | String(256) | 医院名称 |
| hospital_no | String(64) | 医院编号 |
| region | String(32) | 区域划分 |
| province | String(64) | 省份 |
| city | String(128) | 城市信息 |
| sort_order | Integer 默认 0 | 排序 |

接口：

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/prod_hospital/add_prod_hospital` | prod_hospital_edit |
| POST | `/prod_hospital/update_prod_hospital` | prod_hospital_edit |
| DELETE | `/prod_hospital/delete_prod_hospitals` | prod_hospital_edit |
| GET | `/prod_hospital/list_prod_hospital` | prod_hospital_view |
| POST | `/prod_hospital/import_prod_hospitals` | prod_hospital_edit |

## 6. 异常场景 & 兜底逻辑

- 导入文件无「医院名称 + 医院编号」表头：参数错误。
- 保存/删除/导入失败：`message.error` 提示后端 msg。
- 数据库异常：后端 `rollback` 并返回 `msg_err_db`。

---

## 7. 功能约束 & 修改红线

1. `update` 不可修改 `prod_id`。
2. 删除为物理删除，按 id 批量；不做软删除。
3. `dd_002` 打开/换产品只读本全局列表，按病例明细 TXID 匹配后写入回传表，不回写本列表。`dd_003` / `dd_004` / `dd_010` 跟随最新 `dd_002` 回传结果（见 [100_数据文件管理.md](./100_数据文件管理.md) R21 / R22 / R29），也不回写本列表。
4. 默认 8 家仅在全局记录为空时写入一次。
5. 导入覆盖整份全局清单。

## 8. 验收标准

- [ ] 菜单「基础数据 → 合规医院列表」可见（有 `prod_hospital_view`）。

- [ ] 导入 `hospital_info.xls`（或同列表头 xlsx）覆盖全局清单，条数与 Excel 有效行一致。
- [ ] 无 `prod_hospital_view` 看不到菜单。
- [ ] 任意产品打开/换产品 `dd_002` 或数据统计写入时，只出现病例明细 TXID 命中的全局合规医院及其数据量（无清单或无明细则回传表不改）。
