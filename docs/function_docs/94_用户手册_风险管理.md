# 用户操作说明书（五）风险管理

> 涵盖：风险基础库（RCM/HAZ/CST）、产品风险（产品 RCM/HAZ/CST/DHF）、风险管理报告。
> 适用范围：风险/质量/法规人员（对应 `rcm/haz/cst/prod_*/risk_mgmt_doc` 的 view/edit 权限）。

---

## 第一部分：风险基础库（菜单：风险与追溯管理 → 风险基础库）

三个库（RCM/HAZ/CST）结构类似：模糊搜索 + 导入 / 导出 / 新建 / 批量删除。

### 1. RCM 风险控制措施库（`basedata/Rcms.tsx`）

#### 1.1 列与操作
- 列：编号、描述、证明、备注、创建时间、操作（编辑/删除）。
- 导入：选 `.xlsx` 即上传；导出：按筛选导出（最多 2000 条）。
- 批量删除：先勾选，未选提示「请选择要操作的数据」。

#### 1.2 新建 / 编辑
| 字段 | 必填 |
|------|------|
| 编号 code | 是 |
| 描述 description | 是 |
| 证明 proof | 否 |
| 备注 note | 否 |

#### 1.3 边界测试
| 场景 | 预期 |
|------|------|
| 编号重复 | 「数据已存在」 |
| 删除被产品/需求引用的 RCM | 删除主数据会同时删其产品关联（prod_rcm）；请谨慎 |

---

### 2. HAZ 危害分析库（`basedata/Hazs.tsx`）

#### 2.1 列（节选）
编号、来源、事件、处境、损害、初始风险（概率/程度/危险水平）、控制措施、RCM、证据、当前风险、受益/残余标志、类别、操作。

#### 2.2 取值下拉
- 概率：1–5；程度：A–E；危险水平：不可接受 / 进一步降低的研究 / 可忽略。

#### 2.3 新建 / 编辑
- **必填**：编号、来源、事件、处境、损害。
- 选填：初始/当前风险三项、控制措施、RCM（多选，选项为 RCM 描述，标签显示 code）、证据、受益开关、类别。
- 选 RCM 后会自动拼接到「控制措施」。

#### 2.4 导入
模板从第 3 行起读取数据。

---

### 3. CST 网络安全威胁库（`basedata/Csts.tsx`）

#### 3.1 列
编号、类别、模块、连接、描述、损害、创建时间、操作。

#### 3.2 类别下拉
认证、授权、保密性、密码学、代码/数据和执行完整性、事件检测与日记记录、恢复力与恢复、其他。

#### 3.3 新建 / 编辑
- **必填**：编号、描述。
- 选填：类别、模块、连接、损害。
- 导入：模板从第 2 行起读取。

## 第二部分：产品风险（菜单：风险与追溯管理 → 产品风险）

将基础库关联到具体产品并补充评估。

### 4. 产品 RCM（`prod_risk/prod_rcm`）

#### 4.1 操作流程
1. 选择产品（**必须先选**，否则「请选择产品!」）。
2. 点「添加」打开主库 RCM 勾选弹窗：模糊搜索 → 多选（编号/描述/证明/备注）→ 确定。
   - 未勾选确定提示「请选择HAZ!」（文案沿用，实为 RCM）。
3. 列表展示：编号、描述、是否关联 SRS（是/否）、SRS 编号、测试编号、证明、备注、操作（仅删除）。
4. 删除 / 批量删除 / 导出。

#### 4.2 说明
- **无行内编辑**（产品 RCM 只能删后重加）。
- 「是否关联 SRS」「SRS 编号」「测试编号」由系统按追溯规则自动计算。

---

### 5. 产品 HAZ（`prod_risk/prod_haz`）

#### 5.1 操作流程
1. 选产品 →「添加」打开主库 HAZ 勾选弹窗（未选「请选择HAZ!」）。
2. 点行「编辑」进入行内编辑态（显示取消/保存）。

#### 5.2 可编辑列
- 处境、损害（多行）。
- 初始风险 / 当前风险（概率、程度、危险水平 三个下拉）。
- 控制措施（多行）；**选 RCM 多选会自动重写控制措施文本**。
- 证据（多行）。
- RCM 列：多选（选项 label=描述，value=code）。

#### 5.3 只读列
编号、来源、事件、受益标志、类别、产品。

#### 5.4 自动推导
- 选 RCM 后，处置(deal)/证据(evidence) 可由**同产品**的 RCM 描述与测试编号自动聚合。

---

### 6. 产品 CST（`prod_risk/prod_cst`）

#### 6.1 行内编辑列
| 列 | 控件 |
|----|------|
| 控制前/后 评分、严重度、等级 | 数字输入 |
| 控制前/后 可接受性 | 下拉：可接受 / 不可接受 / 可忽略 |
| RCM 编号 | 多选（主库 RCM） |

- 只读：编号、类别、描述（来自主数据）。
- 添加：主库 CST 勾选弹窗（未选「请选择HAZ!」）。
- **CST 评分为独立 Float 体系，与 HAZ 评分不是同一套字段。**

---

### 7. 产品 DHF 设计历史文件（`prod_risk/ProdDhfs.tsx`）

#### 7.1 操作
- 筛选：产品。
- 按钮：导入、导出、新建、批量删除。
- 列：编号、名称、产品名称、产品版本、编辑/删除。

#### 7.2 新建 / 编辑
- 必填：产品、编号、名称。
- 同产品下编号唯一。

#### 7.3 导入「导入DHF」
| 字段 | 必填 |
|------|------|
| 产品 | 是 |
| Excel | 是（`.xlsx`），未选「请选择文件」 |
- 导入按编号更新，否则按名称回写编号。

#### 7.4 边界测试
| 场景 | 预期 |
|------|------|
| 同产品同编号 | 「数据已存在」 |
| 删除引用 DHF 的产品 | 产品删除被阻止 |

## 第三部分：风险管理报告（菜单：风险与追溯管理 → 风险管理报告）

#### 8.3 复制版本
点「复制」→ 确认 → 生成新版本号（同时复制风险分析/控制行）。

---

### 9. 报告详情（`risk_mgmt/RiskMgmtDocDetail.tsx`）

#### 9.1 顶栏
| 按钮 | 可见条件 |
|------|----------|
| 返回 | 始终 |
| 初始化模版 | 非查看 |
| 保存 | 非查看 |
| 导出 Word | 非新建 |

#### 9.2 基础信息
- 新建：选产品（必填）→ 联动该产品风险数据。
- 已有：产品名/型号/版本只读。
- 版本（必填）、变更说明。

#### 9.3 目录结构
- 编辑态：「新增一级目录」；树节点可编辑标题、加同级/下级、删除。
- 无目录提示「暂无目录结构，请点击初始化模版」。

#### 9.4 章节内容（选中章节后编辑）
| 章节类型 | 交互 |
|----------|------|
| 4.2 参与人员 | 从参与人员库勾选 / 表格行编辑 / 删除行 |
| 5.2.3 接受标准 | 固定风险矩阵色块表（红/橙/绿图例），编辑态可维护矩阵格 |
| 附录 B 风险分析矩阵 | 单元格可编辑（数据主要来自产品 HAZ 实时矩阵） |
| 6.5 风险控制 | 可增 RCM 行；展示产品 RCM 描述列表 |
| 普通章节 | 段落文本 + 表格单元格可编辑 |
| 含图章节 | 上传/更换/清除图片；非图片提示「请选择图片文件」 |

> **重要**：详情页的风险矩阵主要取自**产品 HAZ 实时数据**（`list_prod_haz`），并与 `risk_analysis/risk_control` 结构化表、`content` JSON 并存（三套数据源）。维护时以产品 HAZ 为准。

#### 9.5 查看态
表单禁用，表格只读。

---

### 10. 参与人员库（`risk_mgmt/RiskMgmtParticipants.tsx`）

- 搜索：关键词（项目角色/姓名）。
- 表格：项目角色、姓名、编辑/删除。
- 新建/编辑必填：项目角色、姓名。
- 删除确认「确认删除该参与人员吗？」。
- 唯一约束：(角色, 姓名)。
- 说明：参与人员同时存在于「人员库」与各报告 `content` 中，二者相对独立。

---

### 11. 风险管理整体边界测试
| 场景 | 预期 |
|------|------|
| 同产品同版本报告 | 「数据已存在」 |
| 复制版本号冲突 | 「数据已存在」 |
| 删除报告 | 级联删除其风险分析/控制行 |
| 风险分析同 (报告, HAZ编号) 重复 | 「数据已存在」 |
| 风险控制同 (报告, RCM编号) 重复 | 「数据已存在」 |
| 接受标准矩阵 | 为合规内置内容（5×5），不应随意更改 |
| 删除主数据 RCM/HAZ/CST | 会联动删除对应产品关联 |
