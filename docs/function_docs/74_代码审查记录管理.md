# 代码审查记录管理（CRR）

## 1. 功能概述

管理代码审查记录（开发文件），包含代码地址/检查日期/被审核人/审核人/审核依据/检查表/结论/审核签字。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/crr/CrrDocs.tsx`（列表）、`CrrDocDetail.tsx`（详情/编辑）
- API：`api/ApiCrrDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_crr_doc` | `crr_doc_edit` |
| GET | `/duplicate_crr_doc` | `crr_doc_edit` |
| POST | `/update_crr_doc` | `crr_doc_edit` |
| GET | `/rebind_product` | `crr_doc_edit` |
| DELETE | `/delete_crr_doc` | `crr_doc_edit` |
| GET | `/list_crr_doc` | `crr_doc_view` |
| GET | `/get_crr_doc` | `crr_doc_view` |
| GET | `/export_crr_doc` | `crr_doc_view` |

---

## 5. 数据库表

`crr_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与变更需求表（25）不同，CRR 是代码审查记录（开发文件），CRR 是变更需求记录。
2. 包含检查表、审核签字等字段。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
