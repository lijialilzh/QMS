# 网络安全能力分析管理（Cyber Cap / MDS2）

## 1. 功能概述

管理网络安全能力分析（MDS2，产品文件），可编辑的问答/备注以 `content: {"cells": {坐标: 值}}` 存储，产品相关字段导出时自动填充至 xlsx 模板。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 网格编辑器填写问答/备注 → 导出 xlsx。

---

## 3. 前端实现

- 页面：`pages/cyber_cap/CyberCapDocs.tsx`（列表）、`CyberCapDocDetail.tsx`（详情/编辑）
- API：`api/ApiCyberCapDoc.ts`

---

---

## 5. 数据库表

`cyber_cap_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. content 结构为 `{"cells": {"A1": "值", "B2": "备注"}}`，坐标对应 xlsx 模板单元格。
2. `cyber_cap_schema` 返回模板定义（行/列标题、只读标记）。
3. `cyber_cap_autofill` 自动填充产品相关字段。
4. 导出为 xlsx 格式（非 docx）。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content 的 cells 坐标结构不可改变。
2. schema 定义的只读单元格不可编辑。
