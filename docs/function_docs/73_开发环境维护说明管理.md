# 开发环境维护说明管理（DEM）

## 1. 功能概述

管理开发环境维护说明（开发文件），包含说明正文、资产表、各资产周检查表，以 JSON 章节树存储。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/dem/DemDocs.tsx`（列表）、`DemDocDetail.tsx`（详情/编辑）
- API：`api/ApiDemDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_dem_doc` | `dem_doc_edit` |
| GET | `/duplicate_dem_doc` | `dem_doc_edit` |
| POST | `/update_dem_doc` | `dem_doc_edit` |
| GET | `/rebind_product` | `dem_doc_edit` |
| DELETE | `/delete_dem_doc` | `dem_doc_edit` |
| GET | `/list_dem_doc` | `dem_doc_view` |
| GET | `/get_dem_doc` | `dem_doc_view` |
| GET | `/export_dem_doc` | `dem_doc_view` |

---

## 5. 数据库表

`dem_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 章节树包含说明正文、资产表、周检查表。
2. 支持 rebind_product 切换产品。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
