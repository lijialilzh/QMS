# 初步危害分析清单管理（PHA）

## 1. 功能概述

管理初步危害分析清单（风险文件），按产品+版本管理。整份文档以 content(JSON) 存储（单表），含封面/修订记录/A.1~A.4 各表。自动替换全文产品名称，A.2~A.4（CFMEA/DFMEA/PFMEA）表按危害编号从产品 HAZ 回填，封面日期从时间逻辑线自动更新。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/pha/PhaDocs.tsx`（列表）、`PhaDocDetail.tsx`（详情/编辑）
- API：`api/ApiPhaDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_pha_doc` | `pha_doc_edit` |
| GET | `/duplicate_pha_doc` | `pha_doc_edit` |
| POST | `/update_pha_doc` | `pha_doc_edit` |
| DELETE | `/delete_pha_doc` | `pha_doc_edit` |
| GET | `/list_pha_doc` | `pha_doc_view` |
| GET | `/get_pha_doc` | `pha_doc_view` |
| GET | `/export_pha_doc` | `pha_doc_view` |

---

## 5. 数据库表

`pha_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 模板 `pha_template.json` 定义章节树结构。
2. 自动替换全文产品名称。
3. A.2~A.4（CFMEA/DFMEA/PFMEA）表按危害编号从产品 HAZ 回填。
4. 封面日期从时间逻辑线自动更新。
5. 导出复用 `docx_util` 工具。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 自动获取章节不可编辑。
2. HAZ 回填逻辑不可破坏。
