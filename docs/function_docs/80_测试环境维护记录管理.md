# 测试环境维护记录管理（TEM）

## 1. 功能概述

管理测试环境维护记录（测试文件），包含说明正文、资产表、各资产周检查表，支持刷新内容。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 刷新内容 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/tem/TemDocs.tsx`（列表）、`TemDocDetail.tsx`（详情/编辑）
- API：`api/ApiTemDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_tem_doc` | `tem_doc_edit` |
| GET | `/duplicate_tem_doc` | `tem_doc_edit` |
| POST | `/update_tem_doc` | `tem_doc_edit` |
| DELETE | `/delete_tem_doc` | `tem_doc_edit` |
| GET | `/list_tem_doc` | `tem_doc_view` |
| GET | `/get_tem_doc` | `tem_doc_view` |
| GET | `/refresh_content` | `tem_doc_view` |
| GET | `/export_tem_doc` | `tem_doc_view` |

---

## 5. 数据库表

`tem_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与 DEM（开发环境维护说明）结构类似，但 TEM 是测试环境。
2. `refresh_content` 接口用于刷新内容（如重置为模板默认值）。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
