# 测试环境维护记录管理（TEM）

## 1. 功能概述

管理测试环境维护记录（测试文件），包含说明正文、资产表、各资产周检查表，支持刷新内容。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 刷新内容 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/tem/TemDocs.tsx`（列表）、`TemDocDetail.tsx`（详情/编辑）
- API：`api/ApiTemDoc.ts`

---

## 5. 数据库表

`tem_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与 DEM（开发环境维护说明）结构类似，但 TEM 是测试环境。
2. `refresh_content` 接口用于刷新内容（如重置为模板默认值）。
3. 打开/刷新时资产编码仍从测试设备清单获取。同一资产编码已经保存的设备信息、产品名称、完整版本保留，不改回模板；清单里新出现的编码才写入默认设备信息（ISER 为 macOS，其余为 Ubuntu）。周检查表已填的勾选、问题、检查人按日期保留。保存写入用户提交的资产表。切换产品仍按新产品重取。
4. 编辑页标题「测试环境维护记录」居中，文件编号显示在标题同一行的右侧。
5. 周检查表表头按《测试环境维护记录说明》原模板。用途含「公用」或「共用」的资产用服务器检查表，其余用测试机检查表。标题为「服务器检查表（编码）」或「测试机检查表（编码）」。表头三行：日期、出现的问题及处理方式、检查人各纵向跨三行；中间整行是「检查内容」。检查内容下面，服务器为硬件环境（CPU、GPU、内存、网卡）、软件环境（操作系统运行是否正常、数据库运行是否正常、应用服务运行是否正常）、测试环境是否更新升级、服务器是否杀毒、网络环境是否正常、测试工具（是否正常运行、是否更新升级）、服务器是否备份、服务器日志是否错误。测试机为硬件环境（CPU、GPU、内存、网卡）、软件环境（操作系统运行是否正常、浏览器运行是否正常）、测试环境是否更新升级、测试机是否杀毒、网络环境是否正常、测试工具（是否正常运行、是否更新升级）。检查内容下的分组和叶列底色为灰色。已保存勾选的列数和当前表一致时按日期保留；列数对不上时按该表默认勾选重排。
