# 用户操作说明书（一）总览、登录与通用约定

> 本系列（90–95）以**用户实际操作**为基准编写，逐步说明每个功能的操作流程、字段填写、适用范围与边界测试，供使用者与测试人员对照执行。

## 0. 阅读约定
- 「菜单 → 子菜单」表示从左侧导航逐级进入。
- 「点击 X」指页面上的按钮 / 链接 / 图标。
- **必填**字段未填写时无法提交，系统给出红色提示。
- 「边界测试」列出该功能需重点验证的异常 / 极限场景。

---

## 1. 系统简介与适用范围

QMS 是面向**医疗器械软件**的质量管理追溯系统，覆盖：
- 需求规格说明（SRS）→ 软件详细设计（SDS）→ 测试 的全链路追溯；
- 风险管理（危害 HAZ / 控制措施 RCM / 网络安全 CST / 风险管理报告）；
- 系统配置（用户、角色、项目、产品）。

**适用人群**：质量（DQA/QA）、法规（RA）、产品经理、研发、测试等角色。
**适用浏览器**：现代浏览器（Chrome / Edge 等）。

## 2. 登录与退出

### 2.1 登录步骤
1. 打开系统地址，进入登录页。
2. 输入**账号**与**密码**。
3. 点击「登录」。
4. 成功后进入主界面（默认落地页按权限展示）。

### 2.2 字段说明
| 字段 | 必填 | 说明 |
|------|------|------|
| 账号 | 是 | 管理员分配的登录名 |
| 密码 | 是 | 新用户初始密码由管理员设置（默认环境值，建议首次登录后修改） |

### 2.3 退出
点击右上角用户区 →「退出」，清除会话返回登录页。

### 2.4 修改密码
进入「修改密码」：输入旧密码 + 新密码 + 确认新密码 → 提交。
- 两次新密码必须一致，否则提示「两次新密码不一致」。
- 新密码不能为空，否则提示「新密码未设置」。

### 2.5 边界测试
| 场景 | 预期 |
|------|------|
| 账号不存在 | 提示「用户不存在」 |
| 密码错误 | 提示「密码错误」 |
| 会话过期（超过 24 小时未活动）后操作 | 返回未登录，需重新登录 |
| 直接访问未登录可访问的页面 | 被拦截，提示未登录 |
| 修改密码时旧密码错误 | 提示密码错误，不允许修改 |

## 3. 主界面与导航

左侧为功能菜单（按当前角色权限显示），主要分组：
- **创建管理**：SRS 文档、SDS 文档。
- **风险与追溯管理**：风险基础库（RCM/HAZ/CST）、产品风险、风险管理报告、SRS/SDS 追溯。
- **测试管理**：测试集。
- **文件管理**：物理拓扑图、体系结构图、网络安全流程图。
- **产品追溯总览**：追溯总览、文档对比。
- **系统配置**：用户、角色、项目、产品。

> 菜单项是否可见取决于角色权限；无权限的菜单不显示，无权限的操作会提示「您没有权限执行此操作」。

## 4. 通用操作约定（所有列表页通用）

### 4.1 查询 / 筛选
- 多数列表页顶部提供筛选条件（如产品、版本、关键词）。
- 选择 / 输入条件后点「搜索」（圆形放大镜）从第 1 页重新查询。
- 「选择产品」控件为产品名称 + 完整版本联动；部分页面需先选产品才能加载版本下拉。

### 4.2 新建 / 编辑
- 点「新建 / 添加」打开弹窗或跳转新建页；填写必填字段后提交。
- 点行内「编辑」修改。

### 4.3 删除
- 单条删除：点行内「删除」→ 弹出确认框「确认删除？」→ 确认执行。
- 批量删除：先勾选行 → 点「批量删除」；未勾选时提示「请选择要操作的数据」。
- 删除被引用的数据会被拒绝（见各模块边界）。

### 4.4 导入 / 导出
- **导入**：选择符合模板的 Excel（`.xlsx`）/ Word（`.docx`）文件后上传；格式不符会提示对应错误。
- **导出**：按当前筛选条件导出 Excel / Word 文件（浏览器下载）。

### 4.5 分页
- 列表底部分页，可切换每页条数（常见 20/50/100；部分页为 100/500/1000）。
- 注意：产品 RCM/HAZ/CST、测试用例等列表为**前端分页**（后端一次返回全部匹配）。

### 4.6 通用边界测试
| 场景 | 预期 |
|------|------|
| 必填项留空提交 | 红色提示「请输入 / 请选择 {字段}」 |
| 唯一性冲突（名称/编号重复） | 提示「数据已存在」 |
| 删除被引用对象 | 提示对应「存在关联…」并阻止删除 |
| 无权限点击操作 | 提示「您没有权限执行此操作」 |
| 网络/服务异常 | 提示「数据库处理异常，请稍后再试」或对应错误 |

## 5. 角色与权限速查

固定角色：`root / dqa / qa / ra / product_manager(产品经理) / developer / tester`，不可删除、不可改名。

权限按「查看(view) / 编辑(edit)」分模块控制（见 [02_接口设计总览.md](./02_接口设计总览.md) §3.4）。
- **产品经理**只能看 / 改自己创建或被分配（产品成员）的产品及其下数据。
- 其它非管理员用户的产品相关列表，按「产品成员关联」或「本人创建」过滤。
- `root`（id=1）可见全部数据。

---

## 6. 推荐操作主线（端到端）

1. **系统配置**：建项目 → 建产品 → 配角色与用户（手册二）。
2. **需求**：建 / 导入 SRS 文档 → 维护需求条目、变更需求表、功能描述（手册三）。
3. **设计**：基于 SRS 建 / 导入 SDS 文档 → 同步追溯 → 维护设计条目（手册四）。
4. **风险**：维护风险基础库 → 关联到产品 → 编写风险管理报告（手册五）。
5. **测试**：导入测试集与用例（手册六）。
6. **追溯核对**：追溯总览、文档对比、追溯导出（手册六）。
