# 非软件主文档管理（NSMP）

## 1. 功能概述

管理网络安全维护计划（产品文件），章节树结构，支持自动获取产品数据。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/nsmp/NsmpDocs.tsx`（列表）、`NsmpDocDetail.tsx`（详情/编辑）
- API：`api/ApiNsmpDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_nsmp_doc` | `nsmp_doc_edit` |
| GET | `/duplicate_nsmp_doc` | `nsmp_doc_edit` |
| POST | `/update_nsmp_doc` | `nsmp_doc_edit` |
| DELETE | `/delete_nsmp_doc` | `nsmp_doc_edit` |
| GET | `/list_nsmp_doc` | `nsmp_doc_view` |
| GET | `/get_nsmp_doc` | `nsmp_doc_view` |
| GET | `/nsmp_autofill` | `nsmp_doc_view` |
| GET | `/export_nsmp_doc` | `nsmp_doc_view` |

---

## 5. 数据库表

`nsmp_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 网络安全维护计划，与网络安全能力分析（65）不同，NSMP 是维护计划文档。
2. 自动获取产品信息注入。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 自动获取章节不可编辑。
