# 56 产品技术要求

## 1. 功能概述

「产品技术要求」是「产品管理」模块下的独立文档（参考《产品开发计划》《版本更新历史》实现），用于按产品维护医疗器械产品技术要求文档，支持新增、目录树编辑、导出 Word、复制、删除，并对版本信息、版本命名规则、运行环境等内容自动获取最新数据，附录按「图表文件管理」嵌入体系结构图与物理拓扑图。

模板来源：`TX-TF-RUS-PD-008-A0 产品技术要求.docx`。

## 2. 入口与权限

- 菜单：产品管理 → 产品技术要求（`/ptr_docs`）。
- 权限码：
  - `ptr_doc`：产品管理/产品技术要求（父级）
  - `ptr_doc_view`：查看（列表/详情/导出）
  - `ptr_doc_edit`：编辑（新增/更新/复制/删除）
- 已加入「全部权限」与「产品经理」默认权限集；前端角色配置「产品管理」分组识别 `ptr_doc` 前缀。
- 产品经理仅能看到自己创建产品下的文档（与其它文档模块一致）。

## 3. 数据结构

### 3.1 表 `ptr_doc`

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | Integer | 主键 |
| product_id | Integer | 产品 ID（非空） |
| version | String(64) | 文档版本（非空，与 product_id 唯一） |
| file_no | String(128) | 文件编号 |
| change_log | String(512) | 版本变更说明 |
| content | JSON | 整份文档目录树 |
| create_time / update_time | DateTime | 基类字段 |

唯一约束：`(product_id, version)`。

### 3.2 content 结构

```json
{ "sections": [ { "title": "...", "ref_type": "...", "img_category": "...", "body": "...", "tables": [[["..."]]], "children": [ ... ] } ] }
```

- `ref_type` 取值：`cover`（封面）、`prod_version`（产品版本）、`naming_rule`（版本命名规则）、`runtime`（运行环境）、`rt_srv_hw`/`rt_srv_sw`/`rt_client`/`rt_net`（运行环境四张表）、`appendix`（附录）。
- `img_category`：附录嵌图类型，`img_struct`（体系结构图）/`img_topo`（物理拓扑图），对应「图表文件管理」。
- 默认模板内容来自资源文件 `trace-api/src-res/ptr_default_content.json`（新增时整存为初始内容）。

## 4. 自动获取规则

进入编辑页 / 刷新 / 导出时，按产品取最新数据并**覆盖**对应章节（源值为空时保留模板默认值）：

| 章节 | 数据来源 | 规则 |
| --- | --- | --- |
| 封面产品名称 | 产品管理 `product.name` | 覆盖 |
| 1.x 产品版本（软件完整/发布版本） | `product.full_version` / `product.release_version` | 覆盖 |
| 1.x 版本命名规则正文 | 基础数据·版本命名规则（全局单条 `version_rule`） | 覆盖，并在「软件完整版本及说明：」后插入示意图 |
| 2.6 运行环境（架构说明 + 四张表） | 运行环境模块 `prod_runtime_env` | 覆盖（架构、服务器硬件/软件、用户端、网络条件各单元格） |

> 自动获取仅在前端加载与后端导出时计算；`get_ptr_doc` 返回的是库内存储原文，不含自动获取结果。

## 5. 导出 Word

- 封面：标题「医疗器械产品技术要求」+ 产品名称（居中）。
- 目录：插入可更新的 TOC 域。
- 正文：顶级章节自动编号（1/2/3…），子级层级编号（1.1、2.1.1…）；**封面与附录不编号**。
- 版本命名规则：正文「软件完整版本及说明：」后插入命名规则示意图（`src-res/assets/version_naming_rule.png`）。
- 附录：按 `img_category` 调用 `pick_doc_image_file_row(product_id, category, doc_version, product_version)` 取图，经 `docx_util.save_img2docx` 嵌入；体系结构图=`img_struct`、物理拓扑图=`img_topo`；「用户界面关系图/主页面图示」暂无图源，仅保留图题文字。
- 表格：`Table Grid` 样式，居中。

## 6. 后端接口（前缀 `/trace-api/ptr_doc`）

| 方法 | 路径 | 权限 | 说明 |
| --- | --- | --- | --- |
| POST | `/add_ptr_doc` | ptr_doc_edit | 新增（以默认模板初始化 content） |
| GET | `/duplicate_ptr_doc` | ptr_doc_edit | 复制（同产品版本号递增 / 跨产品按目标产品最大版本递增） |
| POST | `/update_ptr_doc` | ptr_doc_edit | 更新（content / file_no / change_log 等） |
| DELETE | `/delete_ptr_doc` | ptr_doc_edit | 删除 |
| GET | `/list_ptr_doc` | ptr_doc_view | 列表（按产品、文档版本筛选；产品经理仅见本人产品） |
| GET | `/get_ptr_doc` | ptr_doc_view | 详情 |
| GET | `/export_ptr_doc` | ptr_doc_view | 导出 Word |
