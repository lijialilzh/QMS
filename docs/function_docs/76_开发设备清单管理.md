# 开发设备清单管理（DEQ）

## 1. 功能概述

管理开发设备清单（开发文件），设备清单表格以 JSON 存储。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/deq/DeqDocs.tsx`（列表）、`DeqDocDetail.tsx`（详情/编辑）
- API：`api/ApiDeqDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_deq_doc` | `deq_doc_edit` |
| GET | `/duplicate_deq_doc` | `deq_doc_edit` |
| POST | `/update_deq_doc` | `deq_doc_edit` |
| DELETE | `/delete_deq_doc` | `deq_doc_edit` |
| GET | `/list_deq_doc` | `deq_doc_view` |
| GET | `/get_deq_doc` | `deq_doc_view` |
| GET | `/export_deq_doc` | `deq_doc_view` |

---

## 6. 关键业务逻辑与规则

1. 与 TEQ（测试设备清单）不同，DEQ 是开发设备清单。
2. 设备清单表格以 JSON 表格形式存储。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
