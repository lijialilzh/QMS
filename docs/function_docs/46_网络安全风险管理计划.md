# 网络安全风险管理计划（Cybersec Plan）

## 1. 功能概述

按产品维护「网络安全风险管理计划」文档（章节树 JSON），属于测试文件。与「网络安全风险管理报告」（47）配套——本模块是计划阶段文档，47 是执行结果文档。支持导出 docx。

> 与「风险管理计划」（64）独立并行——本模块面向 IEC 62304/IEC 81001-5-1 / FDA 网络安全要求，不复用 rmp_doc 模型与表，零耦合。

---

## 2. 用户操作流程

### 2.1 列表

按产品/版本筛选 → 新建空白 / 复制版本（弹窗选目标产品，支持跨产品复制） / 编辑文件编号 / 导出 docx / 删除。

列表列：产品名称、产品版本、文档版本、文件编号（单击编辑）、变更说明、创建时间、操作（查看/编辑/复制/导出/删除）。

### 2.2 详情（`/cybersec_plan_docs/add | edit/:id | view/:id`）

章节树编辑、`content` JSON、产品信息自动获取（名称/版本/项目时间/人员/日期）、导出 Word。

**新增模式选产品后自动联动**：
- 选定产品后自动拉取产品信息，填充封面/修订记录/正文章节。
- **产品定义**（标题归一化为「产品定义」）：← 产品名称/型号/完整版本，打开/换产品即覆盖，编辑页**只读**（不可改正文、不可添加正文/图/表）；章节标题可改、章节可删。没有产品型号时不写「产品型号」这一行。
- 其它文本章节仍按需手填或模板默认。
- 「初始化模版」按钮加载标准目录结构。

## 3. 章节结构（`content.sections[]` 多级树）

> 封面（cover）/ 文件修订记录（revision）为前置章节，不参与正文编号。

```text
网络安全风险管理计划                    ← ref_type=cover（封面信息表）
文件修订记录                            ← ref_type=revision
1 概述
   1.1 目的
   1.2 产品定义                            ← 自动获取产品名称/完整版本，只读
   1.3 适用范围
   1.4 系统架构和安全实现
      1.4.1 系统总体架构                  ← ref_type=flow_diagram（自动获取网络安全流程图）
2 阶段活动                              ← ref_type=stage_activity（阶段/开始/结束/结果 表）
3 关联文件
4 网络安全风险管理小组                     ← ref_type=team（按项目角色自动匹配人员）
5 网络安全风险管理计划
   5.1 网络安全风险管理流程
   5.2 网络安全风险管理活动
      5.2.1 网络安全威胁识别
      5.2.2 网络安全风险评估
      5.2.3 网络安全风险控制
      5.2.4 网络安全风险评审
   5.3 网络安全风险管理可接受水平
6 网络安全风险管理资源、培训和沟通
   6.1 资源
   6.2 培训
   6.3 沟通
7 网络安全风险管理评审
8 网络安全风险管理文件与记录
```

## 6. 数据库表

`cybersec_plan_doc`（单表，content JSON）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 自增主键 |
| product_id | Integer NOT NULL | 产品ID |
| version | String(64) NOT NULL | 文档版本 |
| file_no | String(128) | 文件编号 |
| change_log | String(512) | 版本变更说明 |
| content | JSON | 文档内容（章节树） |

唯一约束：`(product_id, version)`

content 结构：`sections[]`（title, ref_type, text, tables, children, images）、productName。

ref_type 取值：cover、revision、stage_activity、flow_diagram、team。

## 7. 关键业务逻辑与规则

1. **计划文档**：与网络安全风险管理报告（47）配套，本模块是计划阶段，47 是执行结果文档。两者独立模型、独立表，零耦合。
2. **自动获取**：
   - 封面日期、生效日期、修订「修改日期」等从产品时间逻辑线获取（关键字**仅**「网络安全风险管理计划」，避免串到通用《风险管理计划》；打开即覆盖）。
   - **时间计划**「计划完成时间」按阶段从时间线取最晚一月（格式 **`yyyy-MM`**，如 `2025-05`）：准备阶段、威胁识别与分析、风险评估这三行是同一个时间，都←网络安全风险管理计划；制定控制措施←网络安全风险管理报告；SBOM信息←SBOM；SBOM安全性←SBOM安全性；网络安全扫描←网络安全扫描；动态维护保持「持续进行」。有命中则覆盖，无命中则清空模板旧日期。任务/交付物列不改。
   - **时间计划「交付物」列纵向合并**：编辑页与 Word 导出一致——某行交付物有文、其后连续空行则合并为一格（如准备/威胁识别/风险评估三行共用《网络安全风险管理计划》《评审记录》）；不改数据存储（空单元格仍存空串）。
   - 封面**编制人**、修订记录**修订人** ← 参与人员角色含「DQA」者（默认李佳励），打开即覆盖；审核人/批准人规则不变。
   - 4. 网络安全风险管理小组：按项目角色关键字（如"网络安全负责人"、"产品经理"等）从产品参与人员自动匹配填充。
   - **产品定义**：打开/换产品覆盖产品名称、型号与完整版本文案，只读（见 2.2）。
   - **全文产品身份**：打开、换产品、导出时，正文（含表格、内容块）里已出现的产品名称、产品型号、完整版本换成当前产品。模板占位「InferCare RECIST」同样替换。封面和修订记录里的文件版本不改。其余手填句子保留。
   - 1.4.1 系统总体架构（`ref_type=flow_diagram`）：自动获取产品网络安全流程图（同 47 规则）。
   - 物理拓扑图 / 体系结构图（`ref_type=img_topo` / `img_struct` 或标题含对应关键字）：图片打开时、以及从「产品图示」回到本页时，按**产品名称和完整版本**从「产品图示」取图，不按文档版本（如 A0）挑文件，只读。产品图示列表返回该图的更新时间，页面把它写进图片地址；产品图示更换后重新打开本页，页面与导出看到的是同一张新图。**图题居中显示在图下方**，图题行（如「图2 体系结构图」）不进入可编辑正文框。图题以下的说明从同产品最新《需求规格说明》对应章节（物理拓扑图 / 系统结构图）图题以下正文获取，打开即覆盖；该说明可修改，下次打开仍按需求规格说明重新获取。需求里没有这段说明时不改计划里已有的图下文字。
   - 7 运行环境：打开/导出时从产品运行环境 `tables_json` 整表覆盖 4 张表（含增删行列后的结构与表标题）。正文规范为「N）标题 + `{{TBL}}`」交错；编辑页按占位交错渲染表，**不展示** `{{TBL}}` 字面量。表名（如「表1 服务器硬件配置要求」）写在表格上方，不作为表内首行；导出同样把表名放在表格外面。文档内自动获取正文与表只读；章节标题可改、章节可删。章节树通用表格列宽按内容自适应，编号等短列收窄。
3. **自由正文/图/表**（PDP 风格，与 52 / IMM 一致，`pages/pdp/freeChapterBlocks.ts`）：普通章节可「添加正文」多段、上传图片、添加表格，按插入顺序交错；`{{IMG}}`/`{{TBL}}` 等为内部静默占位，编辑框不展示。自动获取章节里，产品定义、运行环境表、拓扑图/架构图的图片、流程图仍只读。拓扑图和架构图图题以下的说明可改。已有 `blocks` 的章节仍按块顺序渲染（与自由交错并存、互不覆盖）。
4. **复制（支持跨产品）**：列表「复制」弹窗选目标产品（默认当前产品），版本号自动生成、不允许手动填。
   - 同产品：`new_version(原版本)` 递增；跨产品：按目标产品现有最大版本 `new_version()` 递增。
5. **删除文档**：直接删除，无级联子表。
6. **导出 Word**：封面「网络安全风险管理计划」→ 封面信息表 → 文件修订记录 → 目录(TOC) → 正文章节。导出与编辑页一致：按 `{{TBL}}`/`{{IMG}}`/见下表/表N/见下图/图N 交错输出表与图；静默占位不写入 Word；**图题在图下**；余表/余图追加文末。

## 8. 修改注意事项 / 不可破坏的核心逻辑

1. 与网络安全风险管理报告（47）独立并行，不可复用其模型与表。
2. **数据可见范围**：列表接口 `list_cybersec_plan_doc` 必须按产品可见范围（`prod_user`）过滤，与产品列表、47 报告口径一致。超级管理员与 DQA 看全部，产品经理额外包含本人创建的产品，其他角色（开发、测试、QA、RA 等）只看到被勾选的产品文档。
3. 自动获取的图片、产品定义、运行环境表不可编辑。拓扑图和架构图图题以下的说明可改。
4. 封面/修订记录为前置章节，不参与正文编号。
