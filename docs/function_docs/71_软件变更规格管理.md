# 软件变更规格管理（SCS）

## 1. 功能概述

管理软件配置状态报告（开发文件），PDP 风格章节树结构。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/scs/ScsDocs.tsx`（列表）、`ScsDocDetail.tsx`（详情/编辑）
- API：`api/ApiScsDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_scs_doc` | `scs_doc_edit` |
| GET | `/duplicate_scs_doc` | `scs_doc_edit` |
| POST | `/update_scs_doc` | `scs_doc_edit` |
| DELETE | `/delete_scs_doc` | `scs_doc_edit` |
| GET | `/list_scs_doc` | `scs_doc_view` |
| GET | `/get_scs_doc` | `scs_doc_view` |
| GET | `/export_scs_doc` | `scs_doc_view` |

---

## 5. 数据库表

`scs_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. PDP 风格章节树结构。
2. 与 SCM（70）不同，SCS 是状态报告而非计划。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与章节树编辑器兼容。
