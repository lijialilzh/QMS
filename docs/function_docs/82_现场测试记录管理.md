# 现场测试记录管理（FTR Record）

## 1. 功能概述

管理现场测试记录（测试文件 VV-006），一张大表格以 JSON 存储。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 大表格编辑器 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/ftr/FtrRecordDocs.tsx`（列表）、`FtrRecordDocDetail.tsx`（详情/编辑）
- API：`api/ApiFtrRecordDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_ftr_record_doc` | `ftr_record_doc_edit` |
| GET | `/duplicate_ftr_record_doc` | `ftr_record_doc_edit` |
| POST | `/update_ftr_record_doc` | `ftr_record_doc_edit` |
| GET | `/rebind_product` | `ftr_record_doc_edit` |
| DELETE | `/delete_ftr_record_doc` | `ftr_record_doc_edit` |
| GET | `/list_ftr_record_doc` | `ftr_record_doc_view` |
| GET | `/get_ftr_record_doc` | `ftr_record_doc_view` |
| GET | `/export_ftr_record_doc` | `ftr_record_doc_view` |

---

## 5. 数据库表

`ftr_record_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与功能描述（26）不同，FTR Record 是现场测试记录。
2. 大表格以 JSON 数组形式存储。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. content(JSON) 结构需与大表格编辑器兼容。
