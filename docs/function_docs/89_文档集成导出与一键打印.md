# 文档集成导出与一键打印

## 1. 功能概述

文档整合导出与一键打印模块。按产品+版本聚合所有文档（产品文件/开发文件/测试文件三大分组），支持：
1. **整合导出**：勾选文档后逐个调用各模块 serv 的 `export_xxx_doc()` 收集 docx，打包 zip 下载（支持 SSE 进度流推送）
2. **一键打印**：勾选文档后逐个调用 IPP 打印接口
3. **导出/打印记录**：记录每次操作的产品、文档数量、成功/失败数、操作人、时间

---

## 2. 用户操作流程

选择产品+版本 → 按分组展示文档清单（Collapse+Table）→ 勾选文档 → 点击"整合导出"（SSE 进度条）或"一键打印" → 查看导出/打印记录。

---

## 3. 前端实现

- 页面：`pages/overview/DocIntegrateExport.tsx`（整合导出）、`DocOneClickPrint.tsx`（一键打印）、`DocExportRecords.tsx`（导出记录）、`DocPrintRecords.tsx`（打印记录）

## 6. 关键业务逻辑与规则

### 整合的文档模块（34 个模块，分三大分组）

| 分组 | 文档模块 |
|------|----------|
| **产品文件**（16个） | pir_doc, pdp_doc, srs_doc, acc_doc, release_note, vuh_doc, ptr_doc, research_doc, rmp_doc, pha_doc, nsr_doc, cyber_cap_doc, label_doc, nsmp_doc, risk_mgmt_doc, train_record_doc |
| **开发文件**（8个） | scm_doc, scs_doc, sd_doc, sds_doc, dem_doc, crr_doc, dat_doc, deq_doc |
| **测试文件**（10个） | stp_doc, str_doc, tem_doc, imm_doc, ftr_doc, ftr_record_doc, utp_doc, utr_doc, teq_doc |

### 整合导出流程
1. 前端发起 `/integrate_export` 请求，传入产品 ID、版本、勾选的文档列表。
2. 后端逐个调用各模块 serv 的 `export_xxx_doc()` 生成 docx 临时文件。
3. 通过 SSE 流 `/integrate_export_progress` 推送进度（当前文档名/总数/成功数/失败数）。
4. 全部完成后打包为 zip，通过 `/integrate_download` 下载。

### 一键打印流程
1. 前端发起 `/one_click_print_list` 获取可打印文档列表。
2. 逐个调用各模块 serv 的 `export_xxx_doc()` 生成 docx，再通过 IPP 客户端发送到默认打印机。
3. 记录打印结果到 `doc_record` 表。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 新增文档模块时需同步更新 `list_integrate_docs` 中的分组列表。
2. SSE 进度流协议不可破坏。
3. 打印依赖打印服务配置（88）中的默认打印机。
