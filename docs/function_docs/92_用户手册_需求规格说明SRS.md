# 用户操作说明书（三）需求规格说明（SRS）

> 适用范围：需要编写 / 维护需求规格说明的人员（需 `srs_doc_view` 查看、`srs_doc_edit` 编辑）。前置：已建好产品。
> 主操作路径为「SRS 文档列表 → 文档详情页」；需求条目、变更需求表、功能描述均在**文档详情页内**完成。

---

## 1. SRS 文档列表（菜单：创建管理 → SRS 文档，路径 `/srs_docs`）

### 1.1 筛选
- **选择产品**：产品名称 + 完整版本联动，可清空。
- **文档版本**：须先选产品才加载该产品下已有 SRS 版本。
- 点搜索（圆形放大镜）查询。

### 1.2 新建 SRS 文档与顶部按钮
- **导入**：打开「导入 Word 需求」弹窗（见第 2 节）。
- **新建 SRS 文档**：点「新建」进入新建页，操作主线如下：
  1. 在 SRS 文档列表页点「新建」，进入新建页。
  2. 选择产品，填写本次需求文档版本号。
  3. 点「初始化模版」加载标准目录结构。
  4. 在目录树中编辑各章节的标题、正文，维护需求条目、变更需求表、功能描述等内容。
  5. 点顶栏「保存」保存整个文档；新建保存成功后会进入该文档的编辑页。

### 1.3 表格列
产品名称、产品完整版本、需求文档版本、文件编号、文件夹名称、变更说明、创建时间、操作。

### 1.4 行内操作
| 操作 | 行为 |
|------|------|
| 查看 | 进入只读详情 `/srs_docs/view/{id}` |
| 编辑 | 进入编辑 `/srs_docs/edit/{id}` |
| 复制 | 确认「确定要复制'{产品}-{版本}'的'{文档版本}'版本吗？」→ 复制成功 |
| 导出 | 导出 Word（行内 loading） |
| 删除 | 确认弹窗（含红色提醒：删除后需求列表清空、绑定的 SDS 解除绑定） |

### 1.5 文件编号行内编辑
单击「文件编号」单元格进入输入框，失焦或回车保存；空值显示 `-`，保存成功提示「文件编号已保存」。

### 1.6 边界测试
| 场景 | 预期 |
|------|------|
| 未选产品就选版本 | 版本下拉禁用/为空 |
| 复制后版本号冲突 | 「数据已存在」 |
| 删除已绑定 SDS 的 SRS | 允许删除但 SDS 解绑（软删 SRS 版本） |

## 2. 导入 Word 需求

### 2.1 导入 Word 需求操作步骤
1. 列表页点「导入」。
2. 弹窗填写：

| 字段 | 必填 | 说明 |
|------|------|------|
| 产品 | 是 | 产品+版本联动选择 |
| 需求文档版本 | 是 | 文本输入 |
| 变更说明 | 否 | 多行文本 |
| Word 文件 | 是 | 仅 `.docx`，单文件 |

3. 点「确定」上传解析。

### 2.2 导入结果
- 成功：自动创建文档并解析出章节树、需求条目、变更需求表、功能描述、关联 RCM、图表文件。
- 失败：弹「导入失败」，提示「Word导入校验未通过，请检查文档标题编号与内容格式」或请求异常。

### 2.3 边界测试
| 场景 | 预期 |
|------|------|
| 未选文件点确定 | 「请选择文件」 |
| 非 .docx 文件 | 不允许选择 |
| 同产品同版本已存在 | 「该产品下已经有{版本}版本文档存在」 |
| 服务端缺 python-docx | 提示「当前环境缺少 python-docx 依赖，暂不可用 Word 导入」 |
| 标题编号不规范的 Word | 「导入失败」 |

---

## 3. 文档详情页布局（`/srs_docs/add` | `/edit/:id` | `/view/:id`）

页面自上而下为单栏：
1. **顶栏**：返回 |（编辑模式）导出、初始化模版、保存。
2. **基本信息**：当前产品、当前版本（新建时为可填的产品、版本）。
3. **版本变更说明**：只读展示 +「编辑变更说明」。
4. **封面区**：需求规格说明表、文件修订记录表（来自树，无则「暂无」）。
5. **目录结构区**：层级缩进的树形编辑区，顶部「添加一级菜单」。

> 查看模式（`/view/`）：顶栏仅「返回」，全部只读。
> 该页**不支持节点拖拽排序**，顺序由模板结构与自动排序逻辑决定。

### 3.1 顶栏按钮
| 按钮 | 条件 / 行为 |
|------|-------------|
| 导出 | 须已保存过；否则提示「请先保存文档」。导出当前编辑快照 Word |
| 初始化模版 | 新建且已选产品：加载标准目录；已保存文档：恢复到进入编辑页时的内容 |
| 保存 | 校验通过后保存整棵树；新建成功后跳转 `/srs_docs/edit/{新id}` |

---

## 4. 编辑章节树

### 4.1 新增节点
| 操作 | 入口 | 说明 |
|------|------|------|
| 添加一级菜单 | 目录结构区顶栏 | 根级追加空节点 |
| 添加 N 级菜单 | 节点行「添加{N+1}级菜单」 | 仅 level ≤ 2 的节点显示（最多到四级） |
| 前面添加同级 | 节点左侧 `+`（提示「在前面添加同级节点」） | |
| 后面添加同级 | 节点右侧 `+`（提示「在后面添加同级节点」） | |

**不可新增/删除节点的场景**：只读模式、自动生成的需求层级节点（功能描述相关）、功能描述 KV 表所在层级。

### 4.2 编辑节点内容
| 区域 | 操作 |
|------|------|
| 章节标题 | 输入框（placeholder「请输入标题」） |
| 需求编号 | 部分节点显示；功能描述节点编号只读 |
| RCM | 多选下拉「选择RCM」；选中后 RCM 描述写入正文；无 RCM 选项时禁用 |
| 正文 | 多行输入；部分「其他需求」章节正文只读 |

> 「其他需求」关联章节的标题/编号只读，提示「请在其他需求列表中修改章节名称和需求编号」。

### 4.3 删除节点
点节点「删除」→ Popconfirm「确认删除？」。变更需求表节点删除会**联动删除整张表**（见第 6 节）。

### 4.4 边界测试
| 场景 | 预期 |
|------|------|
| 在 level=4 节点再加下级 | 「添加下级菜单」不显示 |
| 删除自动功能描述节点 | 无删除入口 |
| 只读模式尝试编辑 | 输入框禁用 |

## 5. 章节内表格与图片

### 5.1 插入表格
1. 点节点「表格」。
2. 弹窗填：表名、行数(1–50)、列数(1–20)、表头（逗号分隔，可留空）。
3. 点「生成表格预览」→ 在预览区编辑单元格。
4. 行操作：`+` 在下方插行；删行（**至少保留一行**，否则「至少保留一行」）。
5. 点「保存表格」。

### 5.2 表格编辑 / 删除
- 表格下方有「编辑」「删除」。删除确认「确认删除表格？」。
- **功能描述 KV 表**：可编辑，**不可删除**（提示「功能描述表格不允许删除」）。
- **变更需求表**：编辑打开专用弹窗；删除则删整张表。

### 5.3 导入表格（Excel）
点「导入表格」上传 Excel（首行表头，至少一行数据）。
- 成功「导入成功」；失败「导入失败，请检查Excel内容（首行表头，至少一行数据）」。

### 5.4 上传图片
- 普通图片节点：点「选择文件 / 重新上传」。
- 产品绑定的拓扑/结构/流程图：上传至图表文件库；**未选产品**时提示「请先选择产品」。
- 只读模式下图片可预览放大。

## 6. 需求条目管理

需求以树内嵌表格 / 预览表格展示，编辑通过表格弹窗完成，保存调用批量保存。

### 6.1 标准需求（产品需求列表）
- 列：需求编号、模块、功能、子功能。
- 编辑步骤：找到标准需求表 → 点「编辑」→ 在弹窗改单元格 →「保存表格」。
- 行增删：弹窗内每行 `+` 插行、垃圾桶删行（锁定行不可删）。
- 改需求编号：直接改「需求编号」列；与旧行冲突时系统自动先写临时编号再更新（用户无感）。
- 删除行后保存：库中对应旧行被删除。

### 6.2 其他需求
- 列：需求编号、需求模块、对应章节号。
- 编辑流程同上，保存为「其他需求」类型；其章节标题/编号须在此表维护（树上只读）。

### 6.3 保存校验（重点边界）
| 提示 | 触发 |
|------|------|
| 产品需求列表至少需要一条标准需求 | 无有效标准行 |
| 产品需求列表第 N 行需填写需求编号 | 有内容但缺编号 |
| SRS 编号重复 | 编号重复 |
| 至少需要填写一个字段（编号/模块/功能/子功能） | 整行为空 |
| 模块/功能/子功能层级重复 | 层级重复 |

---

## 7. 变更需求表

### 7.1 新增变更需求表
1. 点「新增变更表格」。
2. 打开弹窗「新增变更表格」：填**表名**（必填，默认「变更需求N」），并直接编辑四列（需求编号、模块、功能、子功能）。
3. 点「保存表格」后创建并保存；点「取消」不建表。
   - 未填表名：「请输入表名」；无文档 id：「缺少文档信息」。

### 7.2 表内增删行
在变更需求弹窗中编辑单元格、行尾 `+` 增行、删行（至少一行）→「保存表格」→「变更需求已保存」。

### 7.3 删除整张变更需求表
| 入口 | 确认 | 联动 |
|------|------|------|
| 树内变更表标题旁「删除」 | 「确认删除表格？」 | 删 srs_type + 需求行 + 第 7 章对应功能描述 |
| 删除变更需求表树节点 | 同上 | 先清业务数据再删节点 |

- 失败示例：「未找到可删除的变更需求表，请刷新后重试」「删除变更表格失败」。

### 7.4 边界测试（重点，历史易出问题）
| 场景 | 预期 |
|------|------|
| 删除手动新增的变更表 | 表及其第 7 章功能描述一并删除，刷新后不再出现 |
| 删除导入的 Word 变更表 | 仅删目标表，**其它导入变更表保留** |
| 删除后刷新页面 | 已删表不应「复活」 |
| 删除后是否残留空表 | 不应残留空壳表 |
| 变更表名为空 | 「表格标题不能为空」/「请输入表名」 |

---

## 8. 功能描述（第 7 章）

### 8.1 自动生成
保存**标准需求 / 变更需求**行后，系统自动在第 7 章生成对应功能描述子章节及 KV 明细表。**无独立「新增功能描述」按钮**——新增需求行并保存即可触发。

### 8.2 填写字段
1. 定位第 7 章下对应 SRS 编号的功能描述节点。
2. 点 KV 表「编辑」。
3. 在弹窗右列填写：需求概述、主参加者、前置条件、触发器、工作流/事件流、后置条件、异常情况、约束。
   - 需求编号、需求名称行锁定（名称来自需求表）。
   - 异常/约束/工作流等行可出现 RCM 多选，选后自动拼接到内容；无 RCM 时提示「暂无RCM数据，请先在RCM列表中维护」。
4. 点「保存表格」→「功能描述已保存」。

### 8.3 批量查看
树上 `srs_reqds` 节点点「需求详细列表」打开只读宽表（含 RCM 编号列）。

### 8.4 边界测试
| 场景 | 预期 |
|------|------|
| 删除某需求行后 | 对应功能描述章节同步移除 |
| 功能描述章节缺失 | 保存时给出**警告**（不阻断保存） |
| 编辑变更表数据未加载完 | 「变更需求表未加载完成，请刷新后重试」 |

## 9. 全局保存校验汇总
| 提示 | 触发 |
|------|------|
| 请选择产品 | 未选产品 |
| 请输入版本号 | 版本为空 |
| 请先维护目录结构或正文内容 / 文档结构为空 | 树为空 |
| 该产品下已经有{X}版本文档存在 | 版本重复 |
| 请先保存文档 | 未保存就导出 |
| 请先选择产品和版本 | 初始化模版未选产品 |

## 10. 导出与追溯

### 10.1 导出 Word
- 列表页「导出」直接下载；详情页「导出」须先保存，基于当前树+需求快照导出。

### 10.2 SRS 文档追溯（菜单：风险与追溯管理 → SRS 文档追溯，`/srs_doc_trace`）
1. 选择产品 → 搜索。
2. 表格列：产品名、版本、文档版本、文件编号、操作。
3. 每行：
   - **查看**：弹出追溯表（需求编号、RCM 标志、软件详细设计、接口编号、各类测试记录、RCM、备注）；有变更追溯时下方显示「{产品版本}变更追溯」子表。
   - **导出 Excel** / **导出 Word**。

### 10.3 文档对比（菜单：产品追溯总览 → 文档对比，`/prod_comparison`）
1. 文档类型选「需求规格说明」。
2. 左侧选产品 A + SRS 版本；右侧选产品 B + 版本（须不同）。
3. 点「开始对比」。
4. 结果表：对比项、产品 A 值、产品 B 值、状态（相同/不同）。
   - 功能增删按需求**编号集合**比较（改名不算增删）。

### 10.4 边界测试
| 场景 | 预期 |
|------|------|
| 对比左右选同一文档 | 「请选择不同的文档」 |
| 未选齐对比项 | 「请选择…」 |
| 未保存文档点导出 | 「请先保存文档」 |
