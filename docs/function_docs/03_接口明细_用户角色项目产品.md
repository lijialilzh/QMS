# 接口明细：用户 / 角色 / 项目 / 产品

> 公共规范（响应壳 `Resp`、分页 `Page`、鉴权、权限码、错误码）见 [02_接口设计总览.md](./02_接口设计总览.md)。
> 完整路径 = `/trace-api` + 下列路径。所有业务对象字段几乎均为 `Optional`，无模型层校验，必填来自 `Form(...)` 与 service 逻辑。

---

## 一、用户模块 `api_user.py`（prefix `/user`）

### 公共模型

**LoginForm / PwdForm / UserForm（`tobj_user.py`）**

| 模型 | 字段 | 类型 | 含义/约束 |
|------|------|------|-----------|
| LoginForm | name | str | 账号 |
| LoginForm | pwd | str | 密码（空按 `""` 校验） |
| UserForm | id | int | 用户ID（更新/删除用） |
| UserForm | name | str | 账号（DB unique，64） |
| UserForm | pwd | str | 密码（更新时非空才改） |
| UserForm | nick_name | str | 用户姓名（64） |
| UserForm | role_code | str | 角色编码（64） |
| PwdForm | pwd | str | 旧密码 |
| PwdForm | pwd_new1 | str | 新密码1（业务要求非空） |
| PwdForm | pwd_new2 | str | 新密码2（须与 pwd_new1 一致） |

**UserObj（`vobj_user.py`，继承 UserForm）出参**

| 字段 | 类型 | 含义 |
|------|------|------|
| 继承 UserForm 全部 | | |
| create_time | datetime | 创建时间（`%Y-%m-%d %H:%M:%S`） |
| role_name | str | 角色名称 |
| role_perms | List[str] | 权限编码列表（get_user 含；list 一般不含） |

### POST `/user/login` — 登录
- 权限：白名单（无需登录）
- 入参：Body `LoginForm`
- 出参：`Resp`，成功 `code=1`（**不含 data**），写 session
- 错误：`msg_user_null`（用户不存在）；`msg_err_pwd`（密码错误）

### GET `/user/logout` — 退出
- 权限：白名单 / 入参：无 / 出参：`code=1`，清 session

### GET `/user/current_user` — 当前用户
- 权限：登录 / 入参：无（取 `CtxUser`）/ 出参：`Resp[UserObj]`
- 错误：`msg_user_null`；未登录由中间件 `code=-2`

### POST `/user/update_pwd` — 修改密码
- 权限：登录 / 入参：Body `PwdForm`
- 错误：`msg_user_null`、`msg_err_pwd`、`msg_newpwd_unset`、`msg_newpwd_diff`、`msg_err_db`

### POST `/user/add_user` — 添加用户
- 权限：`user_edit` / 入参：Body `UserForm`（name, nick_name, role_code）
- 初始密码 = 环境变量 `DEF_PWD`（默认 `test`，md5+盐）
- 错误：`msg_user_exist`（name 重复）、`msg_err_db`

### DELETE `/user/delete_user` — 删除用户
- 权限：`user_edit` / 入参：Query `id: int`（必填）
- 错误：`msg_err_del_self`（删自己）

### POST `/user/update_user` — 更新用户
- 权限：`user_edit` / 入参：Body `UserForm`（需 id；**不更新 name**）
- 错误：`msg_user_null`、`msg_err_db`

### GET `/user/reset_pwd` — 重置密码
- 权限：`user_edit` / 入参：Query `id: int`
- 错误：`msg_user_null`、`msg_err_reset_admin`（重置 `ADMIN_NAME` 被拒）、`msg_err_db`

### GET `/user/list_user` — 用户列表
- 权限：`user_view` ∨ `product_edit`
- 入参 Query：`name`(模糊)、`nick_name`(模糊)、`role_code`(精确)、`page_index`、`page_size`
- 出参：`Resp[Page[UserObj]]`（含 role_name）

### GET `/user/get_user` — 用户详情
- 权限：`user_view` / 入参：Query `id`（作主键）
- 出参：`Resp[UserObj]`（含 role_perms）/ 错误：`msg_user_null`

## 二、角色模块 `api_role.py`（prefix `/role`）

### 公共模型

**RoleForm / PermForm（`tobj_role.py`）**

| 模型 | 字段 | 类型 | 含义 |
|------|------|------|------|
| RoleForm | id | int | 角色ID |
| RoleForm | code | str | 角色编码（unique 64；新增由服务端 `get_uuid()` 生成） |
| RoleForm | name | str | 角色名称（unique 128） |
| RoleForm | role_perms | list[str] | 权限编码列表 |
| PermForm | id/p_code/code/name | int/str | 权限项 |

**RoleObj（`vobj_role.py`）出参**

| 字段 | 类型 | 含义 |
|------|------|------|
| 继承 RoleForm | | |
| perm_tree | list[PermObj] | 权限树（仅 get_role） |
| all_perms | list[str] | 系统全部权限 code |
| fixed_base_perms | list[str] | 固定角色基线权限 |
| user_count | int | 关联用户数（list_role） |
| create_time | datetime | 创建时间 |

### POST `/role/add_role`
- 权限：`role_edit` / 入参：Body `RoleForm`（name, role_perms；code 服务端生成）
- 错误：`msg_role_exist`、`msg_err_db`

### DELETE `/role/delete_role`
- 权限：`role_edit` / 入参：Query `code: str`
- 错误：固定角色禁止删除；`msg_role_in_use`（被用户引用）

### POST `/role/update_role`
- 权限：`role_edit` / 入参：Body `RoleForm`（需 code）
- 逻辑：固定角色不可改 name；最终权限 = `fixed_base_perms` ∪ 提交项
- 错误：`msg_role_null`、`msg_err_db`

### GET `/role/list_role`
- 权限：`role_view` ∨ `user_view` / 入参：`name`(模糊)、分页
- 出参：`Resp[Page[RoleObj]]`（含 user_count、create_time；无 perm_tree）

### GET `/role/get_role`
- 权限：`role_view` / 入参：Query `code`
- 出参：`Resp[RoleObj]`（含 perm_tree、all_perms、fixed_base_perms、role_perms）
- 错误：`msg_role_null`

### 公共模型

**ProjectForm / ProjectObj**

| 字段 | 类型 | 约束 |
|------|------|------|
| id | int | |
| name | str | unique 64 |
| country | str | 64 |
| note | str | 256 |
| product_count（Obj） | int | 关联产品数 |
| create_time（Obj） | datetime | |

### POST `/project/add_project`
- 权限：`project_edit` / 入参：Body `ProjectForm`
- 错误：`msg_obj_exist`（name 重复）、`msg_err_db`

### DELETE `/project/delete_project`
- 权限：`project_edit` / 入参：Query `id: int`
- 错误：`msg_proj_x_product`（存在关联产品）

### POST `/project/update_project`
- 权限：`project_edit` / 入参：Body `ProjectForm`（需 id）
- 错误：`msg_obj_null`、`msg_err_db`

### GET `/project/list_project`
- 权限：`project_view` / 入参：`name`(模糊)、分页 / 出参：`Resp[Page[ProjectObj]]`（含 product_count）

### GET `/project/get_project`
- 权限：`project_view` / 入参：Query `id` / 出参：`Resp[ProjectObj]` / 错误：`msg_obj_null`

## 四、产品模块 `api_product.py`（prefix `/product`）

### 公共模型

**ProductForm（`tobj_product.py`）**

| 字段 | 类型 | DB 约束/说明 |
|------|------|--------------|
| id | int | |
| name | str | 256；与 full_version 联合 unique |
| project_id | int | 所属项目 |
| category | str | 256 |
| type_code | str | 256（产品型号） |
| full_version | str | 256；联合 unique |
| release_version | str | 256，非空 |
| udi | str | 256 |
| product_code | str | 256 |
| scope | str | TEXT |
| component | str | TEXT |
| note | str | TEXT |
| user_ids | List[int] | 关联用户（`prod_user`） |

**ProductObj / TraceObj 出参额外字段**

| 字段 | 类型 | 含义 |
|------|------|------|
| create_time | datetime | |
| country | str | 来自关联 Project |
| traces | List[TraceObj] | `with_trace=1` 时 |
| srs_versions | List[str] | 去重 SRS 版本 |
| sds_versions | List[str] | 去重 SDS 版本 |
| TraceObj.srsdoc_version | str | SRS 文档版本 |
| TraceObj.sdsdoc_version | str | SDS 文档版本 |

### POST `/product/add_product`
- 权限：`product_edit` / 入参：Body `ProductForm`
- 逻辑：`product_manager` 角色强制 `user_ids=[当前用户]`；未传则默认关联当前操作人；写 `create_user_id`
- 错误：`msg_obj_exist`（name+full_version 重复）、`msg_err_db`

### DELETE `/product/delete_product`
- 权限：`product_edit` / 入参：Query `id: int`
- 错误：`msg_prod_x_srsdoc` / `msg_prod_x_testset` / `msg_prod_x_proddhf` / `msg_prod_x_docfile`（被引用）

### POST `/product/update_product`
- 权限：`product_edit` / 入参：Body `ProductForm`（需 id）
- 逻辑：`user_ids` 非 None 时重建 `prod_user` 关联
- 错误：`msg_obj_exist`、`msg_obj_null`、`msg_no_perm`（产品经理改非本人创建）、`msg_err_db`

### GET `/product/list_product`
- 权限：`product_view` ∨ `srs_doc_view` ∨ `sds_doc_view`
- 入参 Query：`fuzzy`(多字段 OR 模糊)、`with_trace`(int，1 填充追溯)、分页
- 出参：`Resp[Page[ProductObj]]`（含 user_ids、country；with_trace=1 含 traces/srs_versions/sds_versions）
- 范围：id≠1 且 `product_manager` 仅看 `create_user_id=自己`；其它非管理员看 `prod_user` 关联或本人创建

### GET `/product/get_product`
- 权限：`product_view` / 入参：Query `id` / 出参：`Resp[ProductObj]`（默认无 traces）/ 错误：`msg_obj_null`

### GET `/product/export_product_trace` — 导出产品追溯
- 权限：`product_view` / 入参：Query `id`
- 出参：`StreamingResponse` xlsx，文件名 `{file_product_trace}-{时间}.xlsx`（内部 with_trace=1）

### GET `/product/export_products` — 导出产品列表
- 权限：`product_view` / 入参：同 list（fuzzy、分页）
- 出参：xlsx 流；列：name, country, category, type_code, full_version, release_version, udi, product_code, scope, component, note, create_time
