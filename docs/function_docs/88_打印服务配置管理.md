# 打印服务配置管理

## 1. 功能概述

管理打印机配置（系统配置），支持多台打印机配置（列表 CRUD），配置 IPP/TCP9100 打印机，支持测试连接和一键打印。

---

## 2. 用户操作流程

列表页展示所有打印机配置 → 新增/编辑弹窗配置打印机（主机/端口/名称/协议）→ 测试连接 → 设置默认打印机 → 删除。

---

## 3. 前端实现

- 页面：`pages/syscfg/PrintServiceCfg.tsx`
- API：`api/ApiPrintCfg.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| GET | `/list_print_cfg` | `print_cfg_view` |
| GET | `/get_default_print_cfg` | `print_cfg_view` |
| POST | `/add_print_cfg` | `print_cfg_edit` |
| POST | `/update_print_cfg` | `print_cfg_edit` |
| DELETE | `/delete_print_cfg` | `print_cfg_edit` |
| POST | `/set_default_print_cfg` | `print_cfg_edit` |
| GET | `/test_print_conn` | `print_cfg_view` |

---

## 5. 数据库表

`print_service_cfg`：printer_host, printer_port, printer_name, printer_uri, protocol, is_default, remark

---

## 6. 关键业务逻辑与规则

1. 支持 IPP 和 TCP9100 两种协议。
2. 测试连接时生成 PostScript 测试页发送到打印机。
3. 一键打印功能在文档集成导出模块中调用。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 协议类型（IPP/TCP9100）不可随意新增。
2. 默认打印机全局唯一。
