# 用户操作说明书（七）产品文件管理

> 涵盖：产品立项报告、产品开发计划、需求规格说明、产品验收记录、产品发布说明、版本更新历史、产品技术要求、自研软件研究报告、漏洞文档。
> 适用范围：产品/研发/质量人员（对应各模块 `*_view` / `*_edit` 权限）。

---

## 1. 产品立项报告（菜单：产品文件管理 → 产品文件 → 产品立项报告，`pir/PirDocs.tsx`）

### 1.1 适用范围
按「产品 + 文档版本」管理产品立项报告，章节树编辑，基本信息表与修订记录按产品/时间线/参与人员自动获取，支持导出 Word。

### 1.2 筛选
- 产品（完整版本）+ 文档版本（模糊匹配）→ 搜索。

### 1.3 列与操作
- 列：产品名称、完整版本、文件编号、文档版本、创建时间、操作。

| 操作 | 说明 |
|------|------|
| 新建 | 弹窗：选产品、文档版本，打开章节树编辑页 |
| 复制 | 复制当前文档到新版本 |
| 编辑 | 进入编辑页，可修改产品名称、完整版本、文档版本及章节内容 |
| 删除 | 标准确认后删除 |
| 导出 | 导出 Word 文档 |

### 1.4 编辑页字段
| 字段 | 必填 | 说明 |
|------|------|------|
| 产品名称 | 是 | 选产品后自动获取 |
| 完整版本 | 是 | 选产品后自动获取 |
| 文件编号 | 否 | 自动从 DHF 获取 |
| 文档版本 | 是 | 手动输入 |
| 变更说明 | 否 | 版本变更说明 |
| 章节内容 | 否 | 章节树编辑器，基本信息表与修订记录自动获取（只读） |

### 1.5 边界测试
| 场景 | 预期 |
|------|------|
| 同产品同版本再建 | 「数据已存在」 |
| 自动获取章节 | 只读不可编辑 |

## 9. 产品 DHF 管理（菜单：产品文件管理 → 其他 → 产品DHF管理，`prod_risk/ProdDhfs.tsx`）

### 9.1 适用范围
按产品管理设计历史文件（DHF）清单，支持导入/导出 Excel。

### 9.2 筛选
- 产品（完整版本）→ 搜索。

### 9.3 列与操作
- 列：编号、名称、产品名称、产品版本、创建时间、操作（编辑/删除）。

| 操作 | 说明 |
|------|------|
| 新建 | 弹窗：选产品、填写编号和名称 |
| 导入 | 弹窗：选产品、上传 xlsx 文件 |
| 导出 | 导出当前筛选的 DHF 列表 Excel |
| 批量删除 | 勾选后批量删除 |

### 9.4 新建 / 编辑字段
| 字段 | 必填 | 说明 |
|------|------|------|
| 产品 | 是 | |
| 编号 | 是 | 同产品下唯一 |
| 名称 | 是 | |

### 9.5 导入规则
- 导入按编号更新，否则按名称回写编号。

### 9.6 边界测试
| 场景 | 预期 |
|------|------|
| 同产品同编号 | 「数据已存在」 |
| 删除引用 DHF 的产品 | 产品删除被阻止 |
