# 人员签名管理

## 1. 功能概述

管理人员签名（基础数据），记录人员姓名、职务、预留印鉴（图片）、人员签字（图片）、状态、排序。供各文档导出时自动注入签名/印章图片。

---

## 2. 用户操作流程

列表页展示所有人员签名 → 新增/编辑弹窗填写字段并上传印鉴/签字图片（base64）→ 保存 → 支持删除和排序。

---

## 3. 前端实现

- 页面：`pages/basedata/PersonSigns.tsx`
- API：`api/ApiPersonSign.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_person_sign` | `person_sign_edit` |
| POST | `/update_person_sign` | `person_sign_edit` |
| DELETE | `/delete_person_sign` | `person_sign_edit` |
| GET | `/list_person_sign` | `person_sign_view` |
| GET | `/get_person_sign` | `person_sign_view` |

---

## 5. 数据库表

`person_sign`：name, position, seal_img(TEXT base64), sign_img(TEXT base64), status, sort_order

---

## 6. 关键业务逻辑与规则

1. 图片以 base64 dataURL 格式存储和传输。
2. 表格内直接预览印鉴/签字图片缩略图。
3. 按 sort_order 排序展示。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 图片字段为 TEXT 类型存储 base64，注意长度限制。
2. 签名数据被多个文档导出功能引用。
