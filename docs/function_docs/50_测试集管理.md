# 测试集管理

## 1. 功能概述

按产品 + 测试阶段维护测试集，支持 Excel 导入用例。阶段：单元测试、集成测试、系统测试、用户测试。

---

## 2. 用户操作流程

按产品、阶段筛选 → 新增/编辑（产品+阶段+可选 xlsx）→ 删除（级联用例）→「查看测试用例」弹窗 → 导出用例 Excel。

---

## 3. 前端实现

- 页面：`pages/test_set/TestSets.tsx`（内嵌 `TestCases`）
- API：`api/ApiTestSet.ts`（multipart）

---

## 4. 后端接口

| 方法 | 路径 | 权限 | 入参 |
|------|------|------|------|
| POST | `/test_set/add_test_set` | test_set_edit | Form: product_id, stage, file? |
| POST | `/test_set/update_test_set` | test_set_edit | id, product_id?, stage?, file? |
| DELETE | `/test_set/delete_test_set` | test_set_edit | id |
| GET | `/test_set/list_test_set` | test_set_view \| srs_doc_view | product_id?, stage?, 分页 |
| GET | `/test_set/get_test_set` | test_set_view | id |

---

## 5. 数据库表

`test_set`：product_id, stage；唯一 `(product_id, stage)`。

---

## 6. 关键业务逻辑与规则

1. **Excel 导入**（`__read_excel`）：读 **全部 sheet**；扫描前 30 行识别表头（用例编号、需求编号、测试类型等）；`code` 须匹配 `^[A-Za-z0-9][A-Za-z0-9._-]{1,63}$` 且含 `-`；varchar 字段截断 64；sheet 名写入用例 `sheet_name`（用户测试阶段下 sheet 名=型号）。
2. 更新且上传文件：**先删该集全部用例再导入**。
3. 列表过滤：未指定 product_id 时，超级管理员与非产品经理看全部；产品经理仅自己创建的产品（与软件测试计划等测试文件列表一致）。
4. **QA 默认权限**：可 `test_set_view`（查看列表/详情/导出），**无** `test_set_edit`（不可新增/更新导入/删除测试集）。超级管理员、DQA、测试人员等仍按各自默认角色包。
5. stage=`用户测试` 且导入 Excel 成功后，触发用户测试记录的自动新建或刷新（见 `91_用户测试记录管理.md`）。
6. stage∈{单元测试,集成测试,系统测试} 且导入成功后，触发开发测试记录自动新建（见 `101_开发测试记录_单元集成系统.md`）。
7. **查看用例**：弹窗按 `sheet_name` 分 Tab 区分型号（不另加「型号」列）；无 sheet 名时仅「全部」一页。
8. **导出数据集**：单元/集成/系统 → 导出测试记录 xlsx（模版+用例，按 `sheet_name` 分 sheet）；其它阶段仍导出用例表。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. `(product_id, stage)` 唯一不可放开。
2. **更新上传文件 = 先清空再导入**，不可改为增量合并（会重复）。
3. 用例编号正则校验（含 `-`、长度 ≤64）不可放松，影响追溯编号匹配。
4. 删除测试集级联删用例不可遗漏。
