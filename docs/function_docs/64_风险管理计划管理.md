# 风险管理计划管理（RMP）

## 1. 功能概述

管理风险管理计划（产品文件），章节树结构，产品信息自动获取，其余模板化。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/rmp/RmpDocs.tsx`（列表）、`RmpDocDetail.tsx`（详情/编辑）
- API：`api/ApiRmpDoc.ts`

---

## 4. 后端接口

| 方法 | 路径 | 权限 |
|------|------|------|
| POST | `/add_rmp_doc` | `rmp_doc_edit` |
| GET | `/duplicate_rmp_doc` | `rmp_doc_edit` |
| POST | `/update_rmp_doc` | `rmp_doc_edit` |
| DELETE | `/delete_rmp_doc` | `rmp_doc_edit` |
| GET | `/list_rmp_doc` | `rmp_doc_view` |
| GET | `/get_rmp_doc` | `rmp_doc_view` |
| GET | `/rmp_autofill` | `rmp_doc_view` |
| GET | `/export_rmp_doc` | `rmp_doc_view` |

---

## 5. 数据库表

`rmp_doc`：product_id, version, file_no, change_log, content(JSON)

---

## 6. 关键业务逻辑与规则

1. 与风险管理报告（45）不同，RMP 是计划阶段文档。
2. 自动获取产品基本信息注入封面/修订记录。

---

## 7. 修改注意事项 / 不可破坏的核心逻辑

1. 自动获取章节不可编辑。
