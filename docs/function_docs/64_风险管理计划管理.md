# 风险管理计划管理（RMP）

## 1. 功能概述

管理风险管理计划（产品文件），章节树结构，产品信息自动获取，其余模板化。支持导出 docx。

---

## 2. 用户操作流程

列表页按产品搜索 → 新增/编辑 → 章节树编辑器 → 自动获取章节只读 → 导出 docx。

---

## 3. 前端实现

- 页面：`pages/rmp/RmpDocs.tsx`（列表）、`RmpDocDetail.tsx`（详情/编辑）
- API：`api/ApiRmpDoc.ts`

## 6. 关键业务逻辑与规则

1. 与风险管理报告（45）不同，RMP 是计划阶段文档。
2. 自动获取产品基本信息注入封面/修订记录。
3. 「范围」正文自动覆盖：产品名称 ← 产品名称，产品型号 ← `type_code`，完整版本 ← `full_version`。打开/刷新/导出都按当前产品重写这一段，不保留手改。
4. 「责任和职责分配」里表头为「项目角色 / 姓名 / 职责」的风险管理小组表：姓名按「项目角色」精确匹配该产品风险参与人员（`risk_participant`，同一角色多人用「、」连接）。打开/刷新/导出覆盖姓名；角色对不上则姓名为空。不读取项目人员，不改职责列。该表只读，不能改单元格，也不能增删行列或删除此表。
5. 正文和表格里的「10-3」「10-4」这类一位指数，页面上显示为右上角次方（10⁻³）。打开文档即转换；导出 Word 时同样写成 10 的上标。签名图单元格不转换。
6. 表格里上下或左右相邻、去空白后内容相同的单元格合并成一格。空单元格和签名图不合并。风险管理小组表不合并。评审记录页面与需求规格说明一致，用只读合并表展示，点「编辑」才改、点「删除」去掉该表。编辑弹框里，参评人员签字、评审时间、评审结论、批准人员签字这些只在第一格有内容的行合并成一格。导出仍按原规则合并整行标题和「其他参会人员 / 其他参评人员」。其余表格页面和导出的重复项合并一致。改合并格里的文字时，这一格覆盖的每个原单元格一起改。
