## 1. 功能概述

按**产品（版本）**维护《2.4 运行环境》标准模板：默认 4 张表，作为几乎所有交付文档都会引用的「运行环境」章节来源。每个产品一条记录，预填模板默认值，架构说明与表格均可编辑。

- 数据维度：产品版本级（`prod_id`，与产品参与人员/时间线一致），一个产品唯一一条记录（`prod_id` 唯一）。
- 模板结构：架构说明（默认可改的「软件为B/S架构」）+ 表1 服务器硬件 + 表2 服务器软件 + 表3 用户端 + 表4 网络要求。
- 每张表可改标题、表头、单元格，可增删行/列（至少保留 1 行 1 列）；不增删整张表。

- 【只读 / 禁止修改】：`/product/*` 产品模块。

## 3. 完整执行流程（分步细化）

1. 进入页面 → 拉取产品下拉（`list_product`），用产品名称 + 完整版本级联选择。
2. 选择产品（版本）→ `get_prod_runtime_env(prod_id)`：
   - 已有记录：返回该产品已保存的运行环境；
   - 未建记录：返回**模板默认值**（带 `prod_id`，不落库），供前端预填。
3. 编辑（点击字段直接编辑、失焦实时保存）：
   - 架构说明、表标题、表头、单元格均为多行文本（`Input.TextArea`，自动撑高），架构说明可改（不锁死 B/S）；
   - 行尾操作列：表头为「操作」，数据行「＋」在下方插入行、「删除」删行；列宽固定较宽，两个按钮不挤在一起；不在表上方放＋列/－列；增删后立即保存；其余列宽按内容自适应，编号/配置等短列收窄；
   - 失焦时若较上次保存快照有变化 → 调 `save_prod_runtime_env`（按 `prod_id` upsert，首次保存才创建记录）；无变化不发请求；
   - 保存写入 `tables_json`（完整表结构），并按表头/行标签回写固定字段（`srv_os` 等）供其它文档获取；
   - 《产品技术要求》2.6、《自研软件研究报告》1.5：打开/刷新/导出时用当前运行环境**整表覆盖**（含增删行列后的结构）；文档内自动获取的正文与表格只读，章节标题可改、章节可删；
   - 《需求规格说明》2.4：打开/导出时用运行环境覆盖（单向同步，不再把 2.4 回写到运行环境）；文档内自动获取的正文与表格只读，章节标题可改、章节可删；
   - 《软件测试计划》《用户测试计划》《现场测试规程》《安装维护手册》《网络安全风险管理计划》：打开/导出时用当前运行环境**整表覆盖**对应「运行环境」章节（含增删行列后的结构与表标题；STP/UTP 第 5 张测试设备表不改）；文档内这些自动获取的表只读，不允许改单元格、增删行列或删表；章节标题可改、章节可删；
   - 保存成功后更新本地快照并 `message` 提示成功。

## 4. 核心规则 & 判定条件

- `get_prod_runtime_env`：`prod_id` 必填；无记录时回落模板默认值。
- `save_prod_runtime_env`：`prod_id` 必填，按 `prod_id` upsert（存在则更新、不存在则新建）；仅写入可编辑字段，不接受 `id` 覆盖。
- 一个产品唯一一条记录（`prod_id` 列 `UNIQUE`）。
- 权限：写操作 `prod_runtime_edit`，读操作 `prod_runtime_view`；默认与「产品版本管理」权限同步（有 `product_view` 者可查看、有 `product_edit` 者可编辑）。

## 5. 数据结构说明

表 `prod_runtime_env`（详见 [01_数据库表结构.md](./01_数据库表结构.md)）：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Integer PK | 主键 |
| prod_id | Integer NOT NULL, UNIQUE, index | 产品 ID（产品版本），一对一 |
| arch | TEXT | 架构说明（默认「软件为B/S架构」，可改） |
| tables_json | TEXT | 4 张表的完整结构（标题 + 二维 cells） |
| srv_cpu / srv_memory / srv_gpu / srv_disk / srv_nic | TEXT | 由表1 按行标签回写，兼容旧文档 |
| srv_os / srv_cuda | TEXT | 由表2 按列名回写 |
| cli_cpu / cli_memory / cli_resolution / cli_os / cli_browser | TEXT | 由表3 按行标签回写 |
| net_lan / net_wan | TEXT | 由表4 按列名回写 |

模板默认值（后端常量 `DEFAULT_RUNTIME_ENV`，与标准模板一致）：
- 服务器 CPU：主频至少 2GHz / 核心数 10 核及以上 / x86 指令集；内存 ≥64G；GPU 英伟达、显存 ≥8GB、FP16 14TFLOPS；硬盘 系统盘 ≥500GB、存储盘 ≥3TB；网卡 千兆 PCI-E（支持 Linux）。
- 服务器软件：Ubuntu 24.04LTS（64位）/ CUDA 12.6。
- 用户端：CPU 酷睿 i5 及以上 / 内存 ≥16GB / 分辨率 1920*1080 / Windows 10 专业版（64位）及兼容版本 / Chrome 137.0 及兼容版本。
- 网络：局域网 100Mbps 及以上 / 广域网 1000Mbps 及以上。

## 6. 异常场景 & 兜底逻辑

- 未选产品：内容区居中空态「请先选择产品」，顶部产品筛选即可，不发请求。
- 失焦无改动：不触发保存。
- 保存失败：`message.error` 提示后端 msg，本地快照不更新。
- 数据库异常：后端 `rollback` 并返回 `msg_err_db`。

---

## 7. 功能约束 & 修改红线

1. 保持默认 4 张表，不在此页增删整张表；行/列/标题可改。
2. `save` 不接受修改 `id`、不允许跨产品迁移（按 `prod_id` upsert）。
3. 默认值仅用于「未建记录」预填，不强制覆盖已保存数据。
4. 一个产品仅一条记录（`prod_id` 唯一）。
5. 已保存的 `tables_json` 优先于固定字段展示；固定字段仅作兼容回写。
6. 运行环境内容只允许在「产品管理 → 运行环境」改；消费文档内自动获取的正文与表格只读，章节本身可改标题、可删除。只读字段用正文色展示，不以禁用灰字显示。
