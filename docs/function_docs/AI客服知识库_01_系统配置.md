# AI 客服知识库（一）系统配置

> 本文件是给“AI 客服”使用的功能知识库，内容全部来自系统真实功能（功能逻辑文档 10–14、用户手册 91）。
> 每个功能按统一结构描述：界面位置 / 用户常见问法 / 是做什么的 / 解决什么问题 / 怎么用 / 相关功能。
> 目的：让 AI 既能“认识”每个功能（是什么、界面里叫什么），又能讲清楚“怎么用”。

---

## 模块总览：系统配置

系统配置是平台的"基础数据 / 后台管理"模块，菜单入口为「系统配置」，下设三个功能页：**角色管理**、**用户管理**、**产品线管理**。
它负责把“谁能用系统（用户/角色）”和“管理哪些产品（项目/产品）”这两件基础事配置好，是 SRS、SDS、风险、测试等所有业务模块的前提。

---

## 1. 登录与退出

- **界面位置**：登录页 `#/login`；登录后右上角用户菜单可退出。
- **用户常见问法**：怎么登录、怎么进系统、登不上去、怎么退出登录、怎么注销。
- **是做什么的**：用账号 + 密码进入系统，并在登录后按你的角色权限显示你能看到的菜单。
- **解决什么问题**：身份识别与会话保持，保证只有授权用户能访问对应功能。
- **怎么用**：
  1. 打开登录页，输入账号、密码，点「登录」。
  2. 成功后进入系统首页，系统自动加载你的权限并渲染左侧菜单。
  3. 退出：点右上角用户名 →「退出登录」，回到登录页。
  4. 忘记密码：系统不支持自助找回，请联系管理员重置。
- **相关功能**：修改密码、用户管理（重置密码）、角色与权限（决定登录后能看到哪些菜单）。

---

## 2. 修改密码

- **界面位置**：登录后右上角用户菜单 →「修改密码」。
- **用户常见问法**：怎么改密码、怎么换密码、修改登录密码。
- **是做什么的**：当前登录用户修改自己的登录密码。
- **解决什么问题**：首次登录后更换默认密码、定期更换密码以保证账号安全。
- **怎么用**：
  1. 点右上角「修改密码」，输入原密码、新密码、确认新密码。
  2. 提交保存，下次登录用新密码。
- **相关功能**：登录；用户管理里的「重置密码」（由管理员把别人密码重置为默认密码）。

## 3. 用户管理

- **界面位置**：菜单「系统配置 → 用户管理」。
- **用户常见问法**：怎么新建用户、怎么加账号、怎么给员工开账号、怎么改用户角色、怎么重置密码、怎么删用户。
- **是做什么的**：管理系统里的登录账号——新建/编辑用户、给用户分配角色、重置密码、删除用户。
- **解决什么问题**：让每个使用系统的人都有自己的账号，并通过“角色”决定他能用哪些功能。
- **怎么用**：
  1. 列表页可按账号/姓名/角色查询。
  2. 点「新增」填写：账号、姓名、角色（下拉选择）；保存后该用户初始密码为系统默认值，首次登录后应尽快改密。
  3. 编辑：可改姓名、角色；**登录账号不可修改**。
  4. 重置密码：把该用户密码恢复为系统默认值。
  5. 删除：可删除用户（不能删除自己、不能删除超级管理员）。
- **相关功能**：角色与权限（用户的权限由所选角色决定）、登录。

## 4. 角色与权限

- **界面位置**：菜单「系统配置 → 角色管理」。
- **用户常见问法**：怎么新建角色、怎么配置权限、怎么设置谁能看什么、角色权限怎么改、怎么删角色。
- **是做什么的**：查看和配置每个角色能访问哪些功能模块；用户通过被分配角色获得相应权限。
- **解决什么问题**：用“角色”统一管理一类人的权限，而不用给每个人单独配权限。
- **重要说明**：系统**不提供“新建角色”入口**，使用预置的 7 个固定角色：root（超级管理员）、dqa、qa、ra、产品经理、开发、测试。日常只能查看和调整各角色的权限范围。
- **怎么用**：
  1. 在角色列表页查看各角色的名称、创建时间、关联用户数。
  2. 点行内「权限范围」，在弹窗里勾选该角色可见的功能模块（root 权限固定为全部、不可改）。
  3. 点「确定」保存，该角色下的用户下次鉴权时生效。
- **相关功能**：用户管理（给用户分配角色）、登录（按角色权限渲染菜单）。

## 5. 项目管理（产品线）

- **界面位置**：菜单「系统配置 → 产品线管理」。
- **用户常见问法**：怎么新建项目、怎么建产品线、注册项目怎么加、怎么删项目。
- **是做什么的**：维护“项目（产品线）”，它是产品的上级归属；产品必须挂在某个项目下。
- **解决什么问题**：把产品按项目/注册国家归类管理。
- **怎么用**：
  1. 列表页可按名称查询，列表显示每个项目下的产品数量。
  2. 点「新增」填写：项目（产品线）名称、注册国家（下拉：FDA / NMPA / PMDA / CE / MDR）、备注。
  3. 删除：若该项目下还挂着产品，则不能删除，需先处理产品。
- **相关功能**：产品管理（产品归属到项目）。

## 6. 产品管理

- **界面位置**：菜单「产品管理 → 基本信息 → 版本管理」。
- **用户常见问法**：怎么新建产品、怎么加产品、产品档案怎么建、怎么编辑产品、怎么删产品、怎么导出产品。
- **是做什么的**：管理医疗器械产品档案（新建/编辑/删除/导出），产品是系统的核心实体。
- **解决什么问题**：产品是 SRS、SDS、测试集、图表、DHF、风险等所有业务数据的挂载点——先有产品，才能围绕它做需求、设计、风险、测试与追溯。
- **怎么用**：
  1. 列表页可模糊搜索，支持导出产品列表。
  2. 点「新增」填写：产品名称、所属项目（下拉选择项目）、类别、型号、完整版本、UDI、产品代码、适用范围、产品组成、备注。
  3. 编辑：可修改上述字段。
  4. 删除：若该产品下已有 SRS 文档 / 测试集 / DHF / 图表文件，则不能删除。
  5. 可见范围：超级管理员看全部；产品经理只看自己创建的产品；其他用户看与自己关联或自己创建的产品。
- **相关功能**：项目管理（产品的上级）、SRS/SDS/测试/风险/DHF（都挂在产品下）、产品追溯总览（查看产品的全链路追溯）。

## 7. 公司信息管理

- **界面位置**：菜单「通用配置 → 公司基本信息」。
- **用户常见问法**：公司信息在哪、怎么填公司信息、公司基本信息在哪、注册人怎么填、公司信息有什么用。
- **是做什么的**：管理公司基本信息（注册人、住所、受托生产企业、生产地址、生产许可证编号、联系电话、代表人/职位），供各文档导出时自动填充封面/页眉。
- **解决什么问题**：一次填写，所有文档导出时自动注入公司信息，避免每份文档重复填写。
- **怎么用**：
  1. 进入「通用配置 → 公司基本信息」，列表展示所有公司信息。
  2. 点「新增」填写注册人（必填）、住所（必填）、受托生产企业、生产地址、生产许可证编号、联系电话、代表人、职位。
  3. 编辑/删除：行内操作。
- **相关功能**：人员签名管理（导出时同时注入公司信息和签名）、文档导出（各模块导出 Word 时自动填充）。

## 8. 人员签名管理

- **界面位置**：菜单「通用配置 → 人员签名管理」。
- **用户常见问法**：人员签名在哪、怎么上传签名、印鉴怎么传、签字图片怎么上传、签名有什么用。
- **是做什么的**：管理人员签名与预留印鉴（base64 图片），供各文档导出时自动注入签名/印章图片。
- **解决什么问题**：一次上传签名/印鉴，所有文档导出时自动注入，无需每份文档手动贴图。
- **怎么用**：
  1. 进入「通用配置 → 人员签名管理」，列表展示所有人员签名。
  2. 点「新增」填写姓名（必填）、职务（必填）、上传印鉴图片、上传签字图片（仅 .png/.jpg/.jpeg）。
  3. 可设置状态（启用/禁用）和排序。
  4. 表格内直接预览印鉴/签字图片缩略图。
- **相关功能**：公司信息管理（导出时同时注入公司信息和签名）、文档导出（各模块导出 Word 时自动注入签名章）。

## 9. 版本命名规则

- **界面位置**：菜单「通用配置 → 版本命名规则」。
- **用户常见问法**：版本命名规则在哪、怎么改版本命名规则、版本号规则在哪设置、版本命名规则有什么用。
- **是做什么的**：全局单条配置，定义产品的版本命名规则，所有产品共享同一套规则。
- **解决什么问题**：统一全系统的版本命名规范，确保所有文档引用的版本规则一致。
- **怎么用**：
  1. 进入「通用配置 → 版本命名规则」，居中卡片展示当前规则文字内容。
  2. 点击文字内容直接进入编辑态，修改后失焦自动保存。
  3. 下方示意图固定展示，不可编辑。
- **相关功能**：产品管理（产品版本号）、版本更新历史（自动引用命名规则）。

## 10. 打印服务配置

- **界面位置**：菜单「通用配置 → 打印服务配置」。
- **用户常见问法**：打印机怎么配置、打印服务在哪、怎么添加打印机、怎么测试打印机连接、怎么设置默认打印机、一键打印怎么用。
- **是做什么的**：管理打印机配置，支持多台打印机（IPP/TCP9100 协议），支持测试连接和一键打印。
- **解决什么问题**：把系统里的文档直接发送到打印机，无需手动下载再打印。
- **怎么用**：
  1. 进入「通用配置 → 打印服务配置」，列表展示所有打印机配置。
  2. 点「新增」填写打印机名称（必填）、主机 IP（必填）、端口（必填）、协议（IPP/TCP9100）、打印机 URI、备注。
  3. 点行内「测试连接」生成 PostScript 测试页发送到打印机。
  4. 点行内「设为默认」设置全局唯一默认打印机。
  5. 一键打印功能在「全局视图 → 一键打印」中调用默认打印机。
- **相关功能**：一键打印（调用默认打印机）、文档整合导出。
